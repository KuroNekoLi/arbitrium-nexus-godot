# 創作研究紀錄｜我們從其他作品學到什麼？

> **作者與企劃閱讀｜2026-10-20**
>
> 本篇記錄設計方法的參考來源。**不將其他作品的人物、專有名詞、魔法公式、政治制度或劇情事件移植進本作**。玩家版 World Bible 應可以完全獨立閱讀，不必知道這些作品。

## 研究一：Brandon Sanderson 的魔法設計原則

**官方資料：**
- [Sanderson 的三條魔法設計法則](https://faq.brandonsanderson.com/knowledge-base/what-are-sandersons-laws-of-magic/)
- [魔法設計法則與講課整理](https://www.brandonsanderson.com/blogs/blog/guide-to-sandersons-laws-of-magic-lecture-notes)
- [關於時間泡泡能力的限制取捨](https://www.brandonsanderson.com/blogs/blog/annotation-the-alloy-of-law-chapter-twelve)

**我們借用的寫作原則：**
- 玩家越理解一項能力的基本規則，角色靠那項能力解決問題就越令人信服。
- 能力的限制、弱點與付費方式，比無止境增加新能力更能產生戰術與情節。
- 發展既有法則的用途，通常比不斷加入新的例外更容易保持世界一致。
- 時間魔法尤其要設定界線，否則任何困境都可能被「倒帶」輕易消除。

**本作的具體應用：** 完整詠唱花時間、Chantless 需要施術者負擔；時間學科先研究時效與資源預支，不立即允許撤銷歷史事件；24 學科共享一套術式原理。

**沒有照搬的東西：** 其他作品的金屬魔法、時間泡泡、人物、世界歷史與能力清單。

## 研究二：《FINAL FANTASY XVI》的社會化魔法與文明危機

**官方資料：** [FINAL FANTASY XVI — Story](https://na.finalfantasyxvi.com/story)

官方世界設定以晶體魔法、地區差異、能直接施法的人群及逐步擴大的環境危機，展示「魔法如何成為文明與權力的核心」。

**我們借用的寫作原則：**
- 魔法如果已融入生活，就應該影響交通、工作、醫療、社會階層與政治，而非只存在於戰場。
- 同一種魔法便利，對不同身分的人可能意味著完全不同的負擔。
- 世界級災難應讓人們的日常生活發生改變，才有真實重量。

**本作的具體應用：** 街燈、醫療所、修理師、學院與邊境防護共同構成魔法文明；一項公共術式故障可以成為比一場 Boss 戰更貼近居民的危機。

**沒有照搬的東西：** 晶體設定、Dominant、Bearer、各國名稱、疫災起因或作品劇情。

## 研究三：《Metaphor: ReFantazio》的旅途、群像與價值衝突

**官方資料：** [Metaphor: ReFantazio — 官方故事介紹](https://metaphor.atlus.com/index.html?lang=en)

該作以跨地區旅行、不同群體間的衝突與隊伍關係，讓世界不只是一段歷史旁白，而是一串玩家能遇見的人和選擇。

**我們借用的寫作原則：**
- 世界觀應從各地居民生活及人物價值差異中呈現。
- 旅途的每個地區都應提供新的問題，而不只是換一張地圖和怪物。
- 人物的分歧應源自可理解的理由，不只是為了製造吵架。

**本作的具體應用：** 蓮重視現場保護、朱音傾向尋求有效解法、紬優先考慮傷者；小鎮失蹤商隊和公共設施異常，可以讓三個觀點同時成立。

**沒有照搬的東西：** 王室、選舉、旅途目標、種族設定、角色關係與任何專有敘事事件。

## 這份研究導出的共同寫作檢查

| 檢查問題 | 理想回答 |
|---|---|
| 這個魔法能做什麼？ | 玩家用一句話就能理解 |
| 它有什麼限制？ | 至少存在一種清楚、可在故事中見到的代價或條件 |
| 普通人會用到它嗎？ | 若魔法已普及，要有生活化的實例 |
| 這裡的人真正在乎什麼？ | 有工作、家庭、恐懼、責任，而非只談魔法學派 |
| 危機如何被發現？ | 從可觀察的事件和逐步取得的證據開始 |
| 是否覆蓋舊規則？ | 不覆蓋既有戰鬥 Domain，也不把新候選寫成實作 |
| 是否洩漏未決真相？ | 玩家篇章不直接講述作者候選秘密 |

**創作原則：** 學會其他作品如何講故事，而不是把它們的故事放進本作。


## 2026-10-22 補充研究：限制、日常魔法與禁忌級共鳴封鎖

以下比較的是**創作方法**，不是將其他作品的法則併入本作。查閱日期：2026-10-22。

### 《鋼之鍊金術師 Brotherhood》：有規則，禁忌才有重量

[動畫官方介紹](https://fullmetalalchemistusa.com/introduction/)說明鍊金術建立在理解、分解、重構與等價交換之上，並把人體鍊成視為禁忌。**我們借鑑**：禁術的戲劇張力不只是傷害更大，而是碰觸世界的限制與人的倫理選擇。**不照搬**：等價交換的具體公式、人體鍊成、真理之門或該作劇情。

對本作的具體檢查：斷絕一個人與彼世建立共鳴的途徑，可以讓人失去自行施法的能力，因而具有禁忌級的倫理與社會後果；但其成功條件仍受合法術式結構、資源與維持方式約束。

### 《葬送的芙莉蓮》：讓魔法在生活與解咒中同樣成立

[動畫官方魔法一覽](https://frieren-anime.jp/special/magic/)同時收錄攻擊、防禦、生活用途、模仿、分析及解除類型的魔法。**我們借鑑**：已成熟的魔法文明應該不只有戰鬥能力；術式研究、保養、破解與解除都能成為人物專業。**不照搬**：任何原作術式名稱、運作法則或故事。

對本作的具體檢查：魔導路燈的自主運作、學院研究者解析未知術式、反運算與施術者級封鎖可以並存，但必須彼此區分。

### Sanderson 魔法設計法則：用熟悉的限制產生新故事

[作者官方 FAQ](https://faq.brandonsanderson.com/knowledge-base/what-are-sandersons-laws-of-magic/)及[第一法則原文](https://www.brandonsanderson.com/blogs/blog/sandersons-first-law)強調：越要用魔法解決核心衝突，越需要讓讀者理解其條件；能力的限制與代價能塑造戲劇性；先深化既有規則，再增加新系統。

對本作的具體檢查：共鳴封鎖不另創第五種魔法能源，而是由既存**彼世共鳴、術式結構、持續維持、反運算、魔導設備自主運作**推導出可檢驗的禁忌級應用。

### 《Fate》魔術回路作為反面辨析參照

[《Fate Side Material》非官方英文整理與翻譯](https://github.com/tmdict/tmdict/blob/main/data/content/fate-side-material/magic-circuit.en.md)描述特定作品中與施術者身體相連的魔術回路。**不能將這個二手資料當成我們世界的公理**：本作的「共鳴橋樑」只是便於理解的請求成立途徑，不要求人人都有固定先天回路、實體神經器官或唯一通道。

**結論**：深化可理解的法則及禁忌帶來的選擇，而不是複製任何作品的禁術、能力分類或結局。
