# 共通歷史與時間線｜同一世界，容得下不同故事

> **劇情規劃文件｜本版提案／未核准時間線**
>
> 此篇供寫作者與製作人參考。正式曆法、年代、政體、戰爭史以及各位主角的出生年都**尚未確定**。不要把以下的「先後關係」誤寫成既定年份。

## 世界歷史可以先分成五個相對階段

| 相對階段 | 可以確定或建議的世界變化 | 是否需精確年代 |
|---|---|---|
| **早期術式探索** | 人們發現特定媒介能使魔法更可控 | 待定 |
| **知識整理與教育** | 常見術式逐步標準化，研究與學院形成 | 待定 |
| **魔法公共化** | 醫療、照明、運輸與城防逐漸依賴術式技術 | 待定 |
| **邊境防衛體系** | 異形威脅促成哨站、防衛隊與研究合作 | 待定 |
| **當代冒險與調查** | 不同人物從學院、城市或邊境接觸世界變化 | 待定 |

這是一條**歷史建構骨架**，並非已核准的世界重大事件時間表。

## 跨故事共存的基本規則

共享同一個世界，不代表所有故事必須圍繞同一座學院或同一名英雄。

一部故事可能聚焦剛入學的學生，另一部故事則跟隨已經能參與危險任務的三人隊伍。兩者可以同時發生，也可以相隔多年。

重要的是：**一個故事裡真正改變過世界的大事件，必須對其他故事產生合理影響。**

若某城市真的毀滅，另一部同期故事就不能還把它寫成平靜繁華的城市，除非有明確的時間或資訊差異。

## 不預先確定兩部故事的先後

目前至少有三種可行方案：

| 方案 | 故事關係 | 優點 | 風險 |
|---|---|---|---|
| **同期不同地區** | 大致同一段歷史，但人物各自冒險 | 可以互留傳聞與小彩蛋 | 世界級事件必須同步處理 |
| **相隔若干年** | 其中一段旅途較早，另一段較晚 | 可以看到社會逐步變化 | 會限制部分人物年齡與事件結果 |
| **部分重疊** | 各自先展開，後期在特定事件相遇 | 有跨故事的期待感 | 需要更嚴格的時間線與角色位置管理 |

**推薦先維持「時間線相對位置未定」**，等雙方主角的第一段故事都成立再選；不因此假定平行宇宙、分裂世界或時間旅行。

## 時間魔法不是時間線編輯工具

世界裡存在時間研究，不代表劇本作者能在遇到矛盾時隨手寫一句「時間被改寫了」就解決。

如果未來真的使用時間朔行題材，必須先確定：

1. 能否改變已發生的事情？
2. 同一個人是否可能遇見過去的自己？
3. 改變事件是否需要付出代價？
4. 其他人物會留下什麼記憶？
5. 哪些事件是劇情必須遵守的固定點？

沒有確定這些規則前，不應用時間魔法處理人物消失、死亡、失衡戰鬥回合或劇情漏洞。

## 正史事件的最小記錄格式

新增重大事件時，至少寫清楚：

| 欄位 | 要回答的問題 |
|---|---|
| 事件名稱 | 發生了什麼？ |
| 相對時間 | 在誰的故事之前、之後或同時？ |
| 地點 | 哪座城市、哪個設施？ |
| 當事人 | 誰親眼看見，誰只聽過傳聞？ |
| 公開資訊 | 一般居民知道多少？ |
| 實際結果 | 哪些事真正改變，哪些只是誤解？ |
| Canon 狀態 | 已確認／本版提案／待定 |
| 跨故事影響 | 是否應在其他篇章提及？ |

## 當前不可直接確立的事件

某所學院的入學典禮、一次大規模施法失能、某位時間研究者的歸來，以及某個秘密研究室的成立，可能都在既有故事構想中有位置。

但在本版正式排出跨作品時間線之前，它們**不能被偷偷塞進三人旅途的既定前史**。

最後，無論某個故事發生得比較早或晚，它都應該先是一個能獨立成立的好故事，而不是只為另一部故事鋪設世界設定。
