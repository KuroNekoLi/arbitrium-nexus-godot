## 1. 值得保留的核心秘密候選：世界也在付費

在一般居民眼中，使用魔法的代價是施術者投入的魔力、時間與疲勞。

但深層研究者懷疑：改變世界狀態時，**除了施術者付出的魔力，世界本身可能也承受某種代價**。

我們可以先將它稱為「現實代價」（Reality Cost）。

這個概念不代表每次放火球都立即造成地震，也不代表能計算成新的戰鬥貨幣。它比較像一個逐步逼近的問題：**人們使用技術時，是否只算了自己看得見的成本？**

### 已正式選定的因果模型（2026-10-21 CONFIRMED；精確運作仍 TBD）

創作者已將下列惡性循環確認為**作者版世界因果骨架**：

**人類使用魔法（總量與強度提高） → 世界長期熵／無序傾向累積（The Fading） → 局部區域可能更失衡 → 世界的平衡／校正反應生成異形 → 異形增加並變強 → 人類為防衛而更加倚賴、研發更強魔法 → 形成回饋循環。**

**採 B：全域累積＋局部失衡（CONFIRMED）**。長期的世界負擔在全域累積；特定區域可能因密集／高強度魔法活動而更易失穩。這是有方向的風險與因果，不是每次施法必定立即在原地生成異形，也不等於局部失衡只能由當地魔法造成。

如果正式採用，這可以解釋世界為何形成難以逃脫的循環。

**故事基礎採用「異形是世界為求平衡所產生的校正反應」**。但世界是否有主觀意識、異形如何生成、是否存在其他例外或次生形態、局部失衡閾值、熵能否逆轉或恢復，仍屬 **TBD**；不可把「世界意志」直接定義成人格化神明。異形對人類危險，不代表它們在宇宙尺度上以傷害人類為目的。

推薦在劇情裡留給角色一段真正的研究過程，不讓教授講一次課就證明全部因果。

## 2. 世界危機候選：「褪色」

長年累積的異常，也許會在遙遠未來造成比區域性魔法故障更嚴重的問題。

「褪色」（The Fading）是**已正式確認的作者版世界失衡機制**：魔法使用使世界的熵／無序趨勢長期增加，世界以異形作為平衡反應。其可能造成的終局性災難、具體時間及能否避免仍未定。**Entropy 是架空世界中的秩序隱喻／設定概念，不承諾與現實熱力學熵使用同一數值公式。**

如果使用這條故事線，恐怖之處應該從很小的地方開始：

先是某些儀器無法校準，接著出現難以解釋的地區性故障，最後才讓人察覺影響可能擴大到文明。

**這段因果只供作者內部使用，不得寫入第一章玩家旁白或 NPC 的已知真相。**不能預設災難無可避免。

## 3. 秘密研究組織候選

可以保留一個隸屬重要魔導學院、專門研究無法公開問題的秘密小組，暫稱**零號研究室**。

它知道多少真相、為什麼選擇保密、是否已經產生內部分歧，都應留給後續劇情設計。

建議不要把整個組織寫成只會說謎語的反派。一位研究員可能真心認為「不公開尚未證實的災難推論」能避免恐慌，另一位則可能認為隱瞞使更多人失去選擇的權利。

組織正式名稱、成立年代、成員、政治影響力均**待定**。

## 4. 時間朔行者與魔法失能候選

一位來自災難未來的角色，可以相信：「只要人類還能施法，就會無止境地要求世界付出代價。」

她可能試圖切斷**人類將術式請求送達魔法系統的連結**，而不是刪除所有魔法法則、魔力或術式卡。

這樣的設計有一個戲劇性特點：即使人物記得詠唱、仍持有卡片，也可能突然無法執行魔法。

但這種構想**會大幅改變角色能力、社會運作與故事結局**，因此目前只能是重要候選，不可指派給某位尚未確立的人物，也不可宣稱她必定是本作最終敵人。

更不應為了展示這個設定，未經設計就臨時禁用玩家整套 SP 牌組；劇情中的「失能」與真正 Gameplay 可玩性，必須共同設計。

## 5. 避免設定變成神諭

我們建議建立四個真相層次：

| 層次 | 玩家／人物能接觸到什麼？ | 建議敘事做法 |
|---|---|---|
| **公眾認知** | 魔法改善生活、異形威脅聚落 | 日常生活、委託與城鎮公告 |
| **異常線索** | 某些故障無法以常見原因解釋 | 記錄、目擊、可再驗證的事件 |
| **研究推論** | 可能存在一種被忽略的世界代價 | 不同學者的爭論與實驗結果 |
| **經驗證的真相** | 真正的因果和可能的解決方案 | 必須靠劇情證據與人物選擇取得 |

第二層不應直接等於第四層。**讓玩家自己看懂證據，比讓 NPC 替玩家宣告真理更有力量。**

## 6. 一段示範性的線索鏈

- 一個村落的結界異常失效，普通維修方式無效。
- 另一個地區出現不同媒介同時故障，排除了單一設備老化。
- 研究者發現異常地點在時間上可能與某些高強度術式活動重疊。
- 有人提出「魔法本身會讓世界付出代價」的假說。
- 反對者指出：事件也可能與地質、異形活動、戰爭遺留裝置有關。
- 直到後續事件提供關鍵證據，玩家才需要面對更難的選擇。

這樣安排既保留了長線伏筆，也不會讓世界所有問題都只是同一個陰謀。

## 7. 不要讓深層真相壓垮三人主線

蓮、朱音與紬的故事應該先讓玩家在乎**眼前的人和實際旅途**。

秘密研究室、時間朔行者、世界代價都可以是未來候選，但不能第一章就要求三人分別代言某種宇宙哲學。

只有當玩家已經看過魔法如何救人、也看過它無法救下所有人，真正的倫理衝突才有重量。

## 9. 2026-10-21 已核准的 The Fading 作者真相與第一章對照

### CONFIRMED：機制與惡性循環

- **The Fading＝世界在魔法使用下累積的熵增／無序化**；以架空世界法則理解，不把 Entropy 誤當現實可直接測量的熱力學量。
- **全域累積＋局部失衡（B）**：魔法對世界造成長期整體負擔，而高密度或高強度魔法活動可提高特定區域的失衡風險；世界產生異形作為維持／重建平衡的反應。異形數量與威脅強度，隨人類魔法活動長期提高而可能增加。
- **文明的惡性循環**：人類為抵禦異形而創造更強魔法；更強的魔法使用反過來助長失衡與異形。這是作者掌握的深層因果，而非第一章角色已理解的知識。
- **第一章定案骨架**：星煌魔法學院的主角關係介紹；原本安全的訓練場；打倒一般訓練用怪物後，突然出現遠超主角群實力的異形 Boss；主角群無法獨力擊殺時，另一位**尚未設定身分的角色**介入並打倒 Boss。訓練場危機是局部失衡的可觀察案例；現階段**不得推定當天訓練施法就是唯一直接原因**。

### 第一章玩家認知（禁止劇透）

玩家能知道：訓練場理應安全、常規怪物可擊敗、不可預期的異形威脅真實存在、有人能在危急時扭轉局面。玩家**尚不知**世界熵增、校正機制、魔法與異形的完整因果；只能從當時不尋常的環境跡象提出疑問。
