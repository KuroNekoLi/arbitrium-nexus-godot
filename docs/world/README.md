# 世界觀閱讀入口

> **世界觀 v1 草案｜繁體中文｜2026-10-20**
>
> 本目錄是《Arbitrium Nexus》的世界設定。優先寫給玩家閱讀，也提供劇情、美術與關卡設計者共同使用。
>
> **已確認：** 作品共享同一世界的基礎法則，但可以有各自的主角、事件與時間線。**尚未確認：** 新地名、組織詳情、人物關係、深層世界真相，以及各篇提到的故事情節是否作為正式劇情。
>
> 世界觀不能自行取代 [現行戰鬥規則](../combat/README.md)。玩家看到的魔法現象可以很豐富，真正的卡牌能力仍必須遵守已核准的戰鬥規則。

## 星煌魔法學院與 Ruby 個人故事

本作主要校園故事舞台確立為**星煌魔法學院**（由星煌家族建立的世界頂尖私立魔法學院）。玩家可從 [學院與 Ruby 公開介紹](characters/STARGLORY_ACADEMY_RUBY_PUBLIC.md) 開始。

**編劇與製作內部**另有 [Ruby／Aqua 角色聖經](characters/RUBY_AQUA_WRITERS_BIBLE.md)、[完整悲劇劇情提案](characters/RUBY_AQUA_TRAGEDY_STORY_DRAFT.md) 和 [世界觀／戰鬥整合](characters/RUBY_AQUA_LORE_GAMEPLAY_NOTES.md)。**後三份包含核心身份、已故人物與重大劇透，不得公開在玩家入口或早期圖鑑。** 故事提案中的事故細節仍須使用者核准。

## 如何判斷一項設定已經確定？

| 標記 | 意義 |
|---|---|
| **已確認** | 使用者明確採納，或現行權威規格已確立的事實 |
| **本版提案** | 這次為了形成完整世界而建議採用的設定，等待後續劇情審核 |
| **保留謎團** | 故事刻意不向玩家說明，並不表示可以任意改寫已確認的法則 |
| **待定** | 地名、年代、人物關係或結局等尚未拍板的部分 |

**閱讀上的重要區別：** 世界觀說「有時間魔法」，不代表玩家已經能倒轉回合；世界觀說「魔法可以治療」，不代表每張治療卡都能復活失能者。

## 本版的故事承諾

讓玩家先看見魔法帶來的好，再逐漸發現它不能解決一切。

學院裡的一堂課、街角壞掉的路燈、一位被救回的人，都可以成為理解世界的起點。世界最深的秘密，應該由人物的行動與調查慢慢揭開，而不是在開場一次說完。
