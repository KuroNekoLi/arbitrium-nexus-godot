# 魔法究竟是什麼？｜從一顆火球說起

> **玩家可讀｜世界觀 v1 草案**。本篇說明魔法在故事裡如何運作，不代表新增任何遊戲戰鬥按鈕。

## 魔法是讓世界發生某種改變的方法

想像你把一盆水加熱。加熱前它是冷水，加熱後變成熱水。

魔法師做的事有點類似：**先決定希望發生的改變，再用正確的方法讓它完成。**

例如火球術：

- 先聚集足夠的能量。
- 把能量維持成可控制的火焰。
- 選定火球的去向。
- 在適當時機釋放。

每一步都可能成功，也可能失敗。這些有前後關係的步驟，被研究者稱為「術式結構」（Function Graph）。

你不需要學會畫出整張圖，才能在故事裡理解它：就把它想成一道有順序的料理。食譜寫得再完整，準備材料、控制火候的人仍可能犯錯。

## 為什麼需要詠唱？

因為一次施法往往不只是「有力量」就夠。

施術者需要同時思考位置、方向、威力、範圍與安全性。**完整詠唱（Full Chant）**就像把一部分繁複的計算交給有固定步驟的工具幫忙。

代價是要花時間，也更容易被對手看出正在準備什麼。

**破棄詠唱（Chantless）**則把更多工作留給施術者自己完成，能夠更快出手，但通常更吃重個人的理解、控制與精神負擔。

所以兩種方式沒有絕對高下：

| | 完整詠唱 | 破棄詠唱 |
|---|---|---|
| 玩家直覺 | 花時間，準備更完整 | 省時間，較快施放 |
| 強項 | 複雜術式、穩定輸出 | 瞬間反應、掌握先機 |
| 弱點 | 有被干擾的空檔 | 對施術者要求更高 |

真正厲害的魔法師，可以讓簡單的術式發揮驚人的效果；不需要每次都換上一個名稱更華麗的高階法術。

## 什麼是術式卡？

一張魔法卡可以理解成：**把經常需要的施法步驟提前整理好，讓戰鬥時不用每次從頭構築。**

它不像一次性的紙片。更接近一份已經準備好的術式模板：施術者仍需要在使用時投入力量、確認目標並完成施法。

學過一種魔法，不等於任何時候都能立刻把它準備到最適合戰鬥的狀態。這就像懂得做某道菜，不表示你隨身帶齊所有食材和工具。

但本作的**技能卡（SP）不全是魔法卡**。蓮的劍技、隊伍的防護技巧、需要默契的連攜，也可以有各自的卡牌表現；不必強行把所有劍法都說成魔法。

## 魔法如何變得更強？

同樣一顆火球，可以因施術者不同而呈現差異。

有的人體內可調動的魔力量很大；有的人用較少的魔力也能達到效果；有的人特別擅長維持準確的軌道，或能在混亂中看清術式的問題。

研究者常把這些能力概括為**容量、輸出、效率、控制、理解**。

魔法的階段或 Tier，可以用來描述同一種術式能開放多少操作空間，但不代表所有 Tier I 魔法都比 Tier III 弱。熟練的簡單術式，仍然可能勝過不熟練的複雜術式。

這是世界觀中的學習方式，**不是現在已確定的新角色成長系統**。

## 魔法做不到什麼？

它不能保證每次都成功，也不能隨意改寫一切。

施術者必須有足夠的能力與資源；某些效果需要合法的目標、準備時間或特定環境。沒有完整資訊，也可能無法把術式安全地執行。

尤其是時間、空間、生命或因果相關的法術，聽起來很強，但世界不應因為有這些學科，就允許人物輕易消除一切後果。

在現有戰鬥中，時間法術不代表可以倒轉已結算的行動；普通治療也不能無條件讓已經退出戰鬥的角色重新加入。

**限制不是魔法不夠有趣，而是讓每次施法選擇真正有意義。**

## 魔法師會如何辨識對手的招式？

受過教育的人，常能從手勢、詠唱節奏、魔法陣與光芒判斷熟悉的術式。

但看得出「這應該是火球」，不代表知道火球究竟有多大、飛得多快，或是否被加入延遲爆炸的改造。

遇到陌生術式時，有人會選擇後退防禦，有人會集中精神分析，有人則試著從對方的施法節奏尋找干擾時機。

「分析（Analysis）」的目的，是讓未知變成可以應對的情報；它不會自動讓所有敵人露出弱點。
