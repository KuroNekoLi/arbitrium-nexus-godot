# 世界觀小字典｜不用先背完也能開始冒險

> **玩家可讀｜世界觀 v1 草案**。這是一份隨劇情逐步開放的說明，不是要玩家在開場熟記全部名詞。

| 詞語 | 最簡單的意思 |
|---|---|
| **魔法** | 按照特定方法，讓世界發生可以描述的改變 |
| **術式** | 完成一種魔法所需的步驟與規則 |
| **Function** | 研究者用來描述術式如何運作的說法 |
| **Function Graph** | 多個有先後關係的施法步驟組成的結構 |
| **媒介** | 幫助施術者把意圖轉換成可執行魔法的手段 |
| **詠唱** | 借助有結構的步驟，完成較完整的施法準備 |
| **完整詠唱** | 依照完整外顯程序，協助整理術式與穩定施放 |
| **縮短詠唱** | 仍然保留部分詠唱，只省略可以省略的步驟 |
| **破棄詠唱／無詠唱** | **同一概念**：不念出外顯咒語，直接完成必要的術式構築與控制 |
| **術式卡** | 事先整理好、戰鬥時可以快速呼叫的魔法模板 |
| **技能卡 SP** | 遊戲內的技能表現方式，可能是魔法，也可能是劍技等 |
| **Mana／MP** | 用來建立、承受與操作魔法的資源；不必然就是火球的全部能量 |
| **標準術式** | 已經整理、驗證且預先設定許多步驟，讓使用者比較容易安全施放的魔法 |
| **術式參數** | 術式允許調整的條件，例如方向、目標或輸出規模 |
| **彼世** | 部分研究者用來稱呼魔法所涉及的未知另一側；學院仍在研究它的真正本質 |
| **彼世共鳴（簡稱共鳴）** | 彼世的合法作用能否有效在此世呈現；不代表所有魔法都在振動 |
| **共鳴容量** | 一次能承擔多大規模的魔法作用 |
| **共鳴效率** | 在條件固定下，術式預期的效果能實現多少 |
| **共鳴穩定性** | 魔法持續運作或受干擾時，能否可靠地保持正常 |
| **魔導設備** | 保存並執行術式的工具；合格設備不一定需要魔法師在場 |
| **術式解析** | 觀察、測量及推導其他人的魔法如何運作 |
| **術式破解** | 利用或改變對方術式的運作方式，不一定需要解除魔法 |
| **反運算** | 以合法方法干預仍有效的魔法作用，使它變弱、不穩或終止；不能抹去已經發生的普通物理後果 |
| **奧術** | 研究魔法本身的結構與製作方法的一門學問 |
| **魔法學科** | 用來整理不同研究方向的分類，不是固定職業 |
| **異形** | 對難以用一般生物知識解釋、可能威脅居民之存在的稱呼 |
| **失衡 Break** | 用符合條件的攻擊打亂敵人的行動節奏 |
| **暴露 Exposed** | 敵人露出一次可被合格攻擊利用的破綻 |
| **詠唱干擾** | 在魔法完成前，破壞那次施法的穩定性 |
| **護唱 Focus Ward** | 保護正在準備中的施法免受部分干擾 |
| **連攜 Combo** | 兩名角色真正合作、按各自技能條件完成的聯合作戰 |
| **終式 Last Spell** | 每場只能使用一次、完成後施術者退出本場戰鬥的極限招式 |

## 為什麼同時有「弱點」和「暴露」？

**元素弱點**是某名敵人受到特定傷害時比較不利，屬於攻擊相性的問題。

**暴露破綻**則是敵人在特定姿態或失衡狀況下，出現一次可供追擊的機會。

它們不是同一種東西。

## 如果有些名詞現在還看不懂？

沒關係。正式遊戲應該先讓玩家在實際場景中遇見一次，再出現簡短提示；想深入了解的人，可以再打開圖鑑。

像世界代價、遠古災難等**尚未在故事中揭露、或尚未核准的秘密**，不應預先放進玩家版辭典。

想看名詞出現在實際場景裡的用法，請讀 [魔法究竟是什麼？](01_MAGIC_AND_SPELLCRAFT.md) 及 [魔導設備、學院與解咒](15_MAGIC_ENGINEERING_AND_COUNTERMAGIC.md)。
