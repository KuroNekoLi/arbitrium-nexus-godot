# 學院、組織與不同立場｜誰來管理魔法？

> **玩家可讀｜世界觀 v1 草案**。組織功能可作為共通世界的設計基礎；正式名稱、權限、領袖與政治制度尚待後續核准。

## 為什麼需要學院？

因為會用魔法，不代表懂得安全地使用。

學院教學生辨認基本術式、控制力量、避免誤傷，也培養治療、工程、研究與防衛所需要的專業人才。

並非所有學生都能成為傳說中的大魔法師。有人畢業後修理街燈，有人走進研究室，也有人前往邊境服務。

學院的重要性不在於它能培育多少英雄，而在於**一座城市每天有多少不起眼的事情，需要有人把它做好**。

## 這個世界需要哪些組織？

| 類型 | 民眾希望他們做到什麼 | 可能面臨的矛盾 |
|---|---|---|
| **學院與研究所** | 教育、研究、安全檢驗 | 想研究新技術，卻不能讓學生承擔未知風險 |
| **城鎮防衛隊** | 保護居民、巡邏商路 | 必須選擇守住城門，或出去救尚未回來的人 |
| **公共術式管理者** | 維修醫療、供能、交通設施 | 安全、預算與每個地方的需求難以兼顧 |
| **工坊與技師團體** | 製作、維修合法術式設備 | 研究成果應該公開，還是由少數人保管？ |
| **地方議事機構** | 決定城市政策與救援資源 | 誰來決定哪些人先得到幫助？ |
| **民間救援團體** | 補足官方無法即時抵達的地方 | 善意與專業不足可能同時帶來危險 |

這些是**功能性組織範本**。正式國家、政府名稱與隸屬關係需要在城市地圖確立後再決定。

## 不是所有研究者都同意彼此

同樣希望保護世界的人，也可能做出相反的選擇。

一位醫師會認為：「有人正在失去生命，我們必須立刻使用能救他的術式。」

一位負責安全的研究者則會問：「這個術式還沒有完成檢驗。如果今天用在一個人身上，明天有沒有可能傷害更多人？」

兩人都可能真誠，都可能有道理，也都可能犯錯。

世界裡的衝突不應只靠「正派魔法師」對抗「壞魔法師」，還應包含不同責任、不同資訊與不同時間尺度造成的抉擇。

## 魔法應該屬於誰？

當只有少數人能使用高階魔法，社會勢必會問：誰有資格接受教育？誰可以研究危險術式？能救命的技術是否應該成為私人財產？

玩家可能在一個村子看到被禁止使用的土法術式，卻發現那是居民唯一能負擔的醫療方法。

這樣的故事比單純解釋某個組織善惡，更能讓玩家感受到這個世界。

## 組織設計的保留界線

- 不預設任何一座學院統治所有國家或魔法師。
- 不預設研究「虛無」「幽影」「情緒」的人一定是反派。
- 不讓秘密研究團體在第一章無理由向學生坦白最深層的世界謎團。
- 不替尚未存在於正式劇本的角色安排確定的教授、上司或家族關係。
- 公開知識與少數研究者掌握的機密，必須在故事中明確分開。
