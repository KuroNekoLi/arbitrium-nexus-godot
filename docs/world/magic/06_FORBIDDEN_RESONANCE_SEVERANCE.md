## 1. 一句話說明

**A 可以藉由合法的高階術式，切斷 B 與彼世建立有效請求所依賴的「共鳴橋樑」。只要封鎖仍成立，B 就無法憑自身施放任何需要建立彼世共鳴的新魔法。**

B 沒有失憶、沒有被抽乾 Mana，也沒有被禁止說話。他可以完整詠唱、縮短詠唱或完全不詠唱，甚至能正確構築全部術式結構；但在**請求成立的必要條件遭封鎖**時，魔法仍無法在此世成立。

> 「彼世接收不到 B 的請求」是角色可使用的直觀說法，**不是作者宣告彼世有一位會收信的意識體**，也不是暗示世界靠聲音傳遞咒語。

## 2. 「共鳴橋樑」是什麼？

**CONFIRMED 核心意圖／技術描述屬整合推論：** 橋樑是特定施術者能否建立、維持有效彼世共鳴的**法則性途徑或條件集合**。它不是必然肉眼可見的橋、固定經脈或每人只有一根的物理線路。

須分清：
- **術式結構**：魔法「應如何運作」的合法方法。
- **彼世共鳴**：那些方法具備條件、真正對此世產生有效作用的關係。
- **共鳴橋樑**：B **以自身為執行來源／維持來源**時建立上述有效關係所必須滿足的條件。

所以，B 可以知道正確的方法，卻因橋樑受封鎖而無法建立效果。共鳴容量、效率、穩定性仍是已建立的三種性質；橋樑封鎖**不是第四種通用魔力值**。

## 3. A、B 的案例：封鎖以前與封鎖以後

```text
封鎖前：B 選擇術式結構與參數 → 合法條件成立 → B 建立有效共鳴 → 施法成功
封鎖後：B 仍能構築同一術式 → 個人請求成立途徑受封鎖 → 無法建立新有效共鳴
```

A 的封鎖術自身也必須是一個**合法術式**：應具備來源、資源、可作用的對象、成立條件、維持方式、失效與反制途徑。**禁忌級**描述其罕見程度與危險倫理意義，不等於客觀法則為它開後門，也不等於 A 對任何人必然成功。

**使用者已確定的是封鎖可以使 B 失去自行施法能力；至於任何 A 能否不花成本瞬間命中任何 B，並未核准。**

## 4. 使用者選 C：維持方式決定既有魔法後果

**CONFIRMED：** 封鎖生效後，B 已有的魔法**不能統一假定全部立即消失，也不能統一假定全部繼續存在**，而要依其術式結構、目前執行階段及真正的維持來源逐一判斷。

| B 被封鎖時的情況 | 法則上應如何判斷 |
|---|---|
| B 準備施放新火球 | B 不能自行建立有效新共鳴，火球不成立 |
| B 已完成詠唱、尚未建立有效干涉 | 即使念完，也因必要個人請求條件被封鎖而無法成立 |
| B 正親自維持一面護盾 | 若必須不斷由 B 提供共鳴，便依原術式發生弱化、短暫殘留、安全終止或崩解 |
| B 施放過一次性加熱魔法 | 已在水中形成的熱量不會被倒轉 |
| B 已完成實際治療 | 已形成的普通生理改善不會因 B 失去能力而被逆轉 |
| B 啟動、但由合格獨立設備維持的結界 | 若設備不再依賴 B 的個人共鳴，封鎖 B 不會自動讓它失效 |
| B 按下自主魔導手電筒開關 | 若設備本身建立請求，按鈕操作不算 B 自行施法，原則上仍可亮起 |
| 需要 B 持續輸入共鳴的輔助設備 | 即使稱作「魔導設備」，仍可能因依賴 B 而停止 |

**術式級反運算**解除的是某個已有效的魔法結構；**施術者級共鳴封鎖**阻斷的是 B 個人提出／維持有效共鳴所需的條件。兩者可以同時涉及反制技術，但**效果範圍、時點與檢查項目不同**。

## 5. 第二個 C：封鎖自身也依術式維持

**CONFIRMED：** 封鎖術的生命週期由它自己的術式結構決定，可以設計多種合法形式；這是同一套法則的不同應用，不代表都已被角色掌握。

| 封鎖型態 | 允許的設計方向 | 不可以直接推論 |
|---|---|---|
| **有限時間** | 封鎖成立後依合法時間或資源條件結束 | 不是「時間一到必定毫無代價」 |
| **由 A 持續維持** | A 需提供必要共鳴、控制或資源 | 不是每一種封鎖都必須 A 現場維持 |
| **獨立維持的封印** | 合格設備、預存資源或其他合法結構承擔後續維持 | 不是零耗、不可解除或永久無限 |

它們都不能繞過客觀法則；A 若先行離開、倒地或死亡，封鎖是否失效必須由**實際維持條件**決定。

## 6. 魔導設備的邊界：封鎖魔法師，不等於禁用魔法文明

第十九題已確認執行者中立：合法自主設備可自行建立彼世共鳴。所以：
- **封鎖 B 本人的共鳴橋樑**，不意味 B 觸碰的所有魔導物品都被封鎖。
- 若設備只是由 B 按下開關，卻自己承擔施法，**B 仍可能使用**。
- 若一個裝置必須持續依賴 B 個人共鳴，**該裝置仍可能失效**。
- 若同時由幾名施術者協作維持，必須檢查 B 是否為**不可替代的依賴者**；其他人能否合法接手屬個案術式設計。

這帶來長篇劇情可用的重要問題：只剝奪個人施法能力，**不會自動解決已高度依賴自主魔導器的文明結構**。

## 7. 與 The Fading 的殘酷一致性

**作者秘密／已確認的大前提：** 魔法有效干涉在此世增加全球長期無序負擔，局部可能失衡；真正異形是此世非人格化校正反應。人類越依賴魔法抵抗異形，越可能陷入惡性循環。

未來某個角色可能判斷：**既然人類不願停止施法，就切斷人類使用魔法的可能。**

此動機**使用者已選定作為角色方向，身分與具體手段尚未設計**。需守住四個不可消失的反例：

1. **不能追溯減少既有 The Fading**：封鎖過去的大魔法師，不會清除之前累積的世界負擔。
2. **封鎖術本身也可能新增世界負擔**：如果它建立、維持有效跨世干涉，不能不算這份作用。低 Mana 消耗不等於低世界代價。
3. **個人封鎖不等於設備封鎖**：如果角色志在阻止文明繼續依賴魔法，單一施術者封鎖未必足夠。
4. **世界與人類利益可能衝突**：切斷魔法師可能使防衛失效、病人失去治療、公共設備難以維修；即使動機自認正當，手段的倫理代價仍是真實的。

**不能宣稱**這個計畫必能阻止 The Fading 的全部進程，因為負擔已累積而且異形仍存在；也不能宣稱一定無效，因為減少新的有效干涉可能改變未來增長，具體量化與社會反應仍 TBD。

## 9. 五個必要的設計與一致性測試

1. **無詠唱也無效？** 是；原因是個人新請求的必要條件受封，不是 B 沒學會。
2. **B 能否繼續使用自主設備？** 依設備真正執行來源判斷；獨立者原則上可以。
3. **B 的舊護盾是否立刻消失？** 依原護盾術式結構的維持、緩降與備援條件判斷。
4. **A 是否能不付代價永久封鎖全部人？** 不能憑「禁忌級」自動授權；範圍、代價、持續性及反制 TBD。
5. **封鎖成功是否能清除世界負擔？** 不能；停止新作用不等於倒轉既有 The Fading。
