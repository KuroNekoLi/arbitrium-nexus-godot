## 2. 每種設定都有狀態

- **CONFIRMED**：使用者明確核准；其中「異形本體論 V0.9 七條」是正式作者秘密。
- **SELECTED／DIRECTION**：使用者選擇或明確傾向的世界設計方向；可作 V1.0 工作模型，但沒有擅自聲稱所有推導細節逐字核准。
- **PROPOSAL**：合理補充、工程建議或尚未獨立核准的判準。
- **TBD**：不可自行填成定律的空白。
- **IN-WORLD THEORY**：故事中的教授可能使用的模型；不能直接當成作者已證實的全部真相。

**權威順序**：最新明確使用者決策 → [世界觀 Canon 決策](../13_CANON_DECISIONS.md) 及作者秘密已核准部分 → 此系列對已選模型的整合 → 玩家敘述。涉及戰鬥實際實作與數值，以 `docs/combat/` 的正式規格與程式為準。發現不一致先標記衝突，不能擅自修改 Gameplay。

## 3. V1.0 的八條核心規則

### 3.1 魔法受客觀法則約束

**CONFIRMED／DIRECTION。** 此世是角色日常生活所在；彼世是另一個真實世界。跨世界作用依可描述的規律成立，並非人格化神明看心情批准。彼世是否另有生命、文明、特殊構造 **TBD**；學院也沒有掌握全部真相。

例：某人喊出完美咒語但缺少成立條件，仍無法讓魔法成功；家族姓氏本身不是宇宙豁免證明。

### 3.2 魔法必須遵守術式結構

**DIRECTION。** 施法需要合法的操作結構及相應輸入，包括參數、能源或材料來源、維持與終止條件。已封裝的標準術式能讓初學者只操作少數參數；有能力使用不等於理解底層。

例：標準火球只讓學生調目標和力度；改寫追蹤邏輯需要更深入的術式理解。

### 3.3 知識與施法能力是不同條件

**DIRECTION。** 知道公式不代表擁有足夠 Mana、瞬間承載、材料、媒介、能源或控制能力；社會法律批准與物理上可執行也不相同。

例：研究生能推導大型結界，但他未必可以獨自提供長期運作所需的資源。

### 3.4 有效共鳴不是單一「威力值」

**第 25 題 C：SELECTED。** 跨世界有效干涉稱為**彼世共鳴（Resonance，簡稱共鳴）**。共鳴是法則映射的有效作用關係，**並非聲波、振動或所有魔法的固定頻率**。分為**容量**（當下能支持多大的負載）、**效率**（固定條件下效果實現程度）、**穩定性**（長期、過載或受干擾時是否可靠）。三者不是三種能量。當前負載是運行狀態。

例：大量 Mana 不代表能瞬間施放超大魔法；高效率也不能突破不存在的能源來源。

### 3.5 執行者中立

**第 19 題修正版 B：使用者認可。** 只要客觀的執行條件齊全，獨立魔導設備也能自行建立與維持術式，無須永遠依賴人類在場。

例：同一支自主魔導手電筒，誰按開關都一樣亮；除非它特別提供外部 Mana／參數介面。

### 3.6 術式可以研究、解析及模仿

**第 20 題：使用者明確主張。** 從觀察結果可能重現相同功能，天才甚至可以見過一次就構築合法模仿；但外觀相同未必證明已完整還原原始 術式結構。

例：兩種火球有同一軌跡，其中一種靠感知模組追蹤、另一種採預先計算路徑。

### 3.7 反運算不能撤銷歷史

**已確認的界線＋第 22 題 C DIRECTION。** 可合法干預仍在進行的跨世界作用、使其弱化、擾動或終止；不能直接抹消已經發生的普通燃燒、傷害、物質變化或已累積的世界負擔。

例：解除火球不會使燒掉的紙自動回復；詳見 [反運算](04_ANALYSIS_AND_INVERSE_OPERATION.md)。

### 3.8 The Fading 是獨立的世界代價

**CONFIRMED／作者秘密。** 此世因有效魔法干涉產生全域長期不可逆的無序負擔，可能有局部失衡；異形是此世的非人格化結構性校正反應。不可把 Mana 扣 10 直接寫成世界負擔扣 10。這不是在遊戲中新增熵計量表。

詳見下方秘密與 [作者秘密](../09_SECRETS_WRITERS_ONLY.md)。**玩家版不得直接透露**。

## 3.9 已確認的高階延伸：施術者級共鳴封鎖（禁忌方向）

**使用者明確選定：** A 能透過合法封鎖術式，切斷 B 作為施術者建立有效彼世共鳴的必要途徑（「共鳴橋樑」）。B 即使有 Mana、懂得術式結構、完成任何形式的詠唱，仍無法**親自建立新的有效魔法請求**；既有魔法**依術式維持方式 C** 決定會否停止，由獨立魔導設備運作的術式不因 B 被封鎖而必然失效。

**封鎖的維持亦選 C**：由封鎖術式本身決定，可能有限時、需要施術者維持或以其他合法資源獨立維持，絕非自動永久。此術定位為禁忌級；未來掌握者試圖藉此阻止 The Fading，**具體人物與能力上限 TBD**。詳見[禁忌級共鳴封鎖](06_FORBIDDEN_RESONANCE_SEVERANCE.md)。

**共鳴橋樑並非每人固定的物理電纜，彼世也不必是會接聽請求的意識體。** 封鎖不消除已造成的物理後果與既有 The Fading，也不等於新增現行戰鬥的全技能失能效果。

## 4. 施法與世界狀態之間的因果鏈

```text
合法術式 F ＋ 輸入參數 p
       ↓
資源 R、能源／材料來源、環境與控制條件成立
       ↓
建立有效彼世共鳴 K（容量、效率、穩定性）
       ↓
魔法效果在此世執行：一次完成／有限程序／持續維持
       ↓
結束共鳴；已成立的普通物理結果照常保留
```

**作者秘密並行負擔**：有效干涉的建立與持續運行可能增加 The Fading，並非只在施法結束時計費。若反運算也建立新干涉，它也可能增加負擔。

抽象記號 `Y = E(F,p,R,K,X)` 只是檢查「結果取決於哪些條件」，**不是 Godot 已實作的傷害公式**。

## 5. 必須分開的幾件事

| 容易混淆 | 正確區分 |
|---|---|
| Mana vs 魔法能源 | Mana 用於操作／承載跨世界干涉；熱、光、物質可能有別的合法來源 |
| Mana 儲量 vs 瞬間共鳴容量 | 長期可用資源不等於瞬間安全負載 |
| 高效率 vs 高理解力 | 前者善於實現既定術式；後者善於分析、調參或改寫方法 |
| 完整詠唱 vs 縮短詠唱 vs 破棄 | 破棄詠唱**就是無詠唱**；縮短詠唱仍有外顯咒語 |
| 持續魔法 vs 永久普通結果 | 可以解除前者，不能僅解除原術式便消除後者 |
| 詠唱干擾 vs 反運算 vs Break | 分別涉及成立前施法、已成立的干涉與戰鬥失衡；不相互取代 |
| 施術安全 vs 世界負擔 | 個人施法愈安全，The Fading 不一定愈少 |

## 6. 作者秘密：異形 V0.9 核准邊界

**CONFIRMED 七條**：真正異形共同源於此世的 The Fading 校正反應；無須世界有意識；主要使用此世既有物質與能量，熵不是原料；形成、死亡或討伐不直接清除全域負擔；形態、認知及生存模式多樣；校正不保證對人類有益、也不保證降低全球負擔；人類以更多魔法對抗異形又增大長期危機。

**不得衍生**：每次施法立即召怪、所有異形都有意識、異形都是彼世移民、討伐異形能清除熵、第一章教授全知、訓練當天的施法必然直接召出 Boss。
