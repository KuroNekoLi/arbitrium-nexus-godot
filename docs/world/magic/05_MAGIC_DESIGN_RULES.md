# 新魔法設計規範｜給編劇與 AI Agent 的一致性檢查表

> **作者／開發者限定｜V1.0｜可直接用於新術式提案。**
>
> 每次有人要求「設計一種魔法」「創造新的禁術」「讓 Boss 有獨特能力」，先讀 [總規格](00_MAGIC_SYSTEM_SPEC_V1.md) 和相關專項。**這份規範只約束世界設定，不代表已批准一張新卡牌。**

## 1. 先用一句白話說清楚效果

不要先寫「超越萬物的星辰破壞」。先寫：

「使用者在三秒內於前方建立能抵擋一定程度攻擊的護盾。」

玩家看到的是什麼？在什麼條件下有效？何時結束？效果的上限在哪裡？

## 2. 術式提案必填項

複製下面的表格；任何欄位若仍未知，標記 **TBD**，不可自行假裝已核准。

| 欄位 | 應回答的問題 |
|---|---|
| 名稱／用途 | 玩家能觀察到的效果是什麼？ |
| 狀態 | CONFIRMED／DIRECTION／PROPOSAL／TBD？ |
| 術式結構 | 這是已知標準術式、修改版，還是全新合法結構？ |
| 合法條件 | 必須滿足什麼目標、參數、距離、媒介與環境條件？ |
| 能源／材料 | 熱、動量、光、真實物質或其他效果由哪裡來？ |
| Mana 與負載 | 需要施術者／設備支付或承受什麼？是否可能過載？ |
| 共鳴維持 | 一次性、有限程序、持續作用？誰維持？ |
| 封鎖對象與作用層級 | 若是反制：針對一個術式、施術者級請求途徑，還是某個自主設備？ |
| 詠唱與控制 | 外顯詠唱有多少？是否具備無詠唱能力？允許中途改哪些參數？ |
| 終止／故障 | 正常如何結束？失穩、失去供能或控制時怎麼辦？ |
| 反制與備援 | 可能被何種合法方法弱化、擾動或解除？有沒有冗餘？ |
| 既成後果 | 魔法停止後哪些物理結果依然存在？ |
| 作者秘密 | 是否涉及 The Fading 或異形真因？要對玩家隱藏什麼？ |
| Gameplay 邊界 | 是否只有故事設定？若要實作，是否另有核准 ADR？ |

## 3. 一個合格的示例：星辰護盾（**PROPOSAL，不是現行技能**）

**玩家理解**：在施術者前方形成短時間防護，能承受符合條件的一定攻擊；防護不是無敵。

**術式結構**：改良既有防護 術式結構，提供合法的方位與負載參數；具體節點、定量數值 TBD。

**能源與承載**：需要可辨識的干涉資源與承載來源，不能只說「因為角色是天才」；護盾承受的作用如何處置仍需與術式來源一致。

**生命週期**：持續共鳴型，可由施術者維持，或另行設計設備版本；時間上限和維持成本 TBD。

**失效**：可能隨負載弱化，也可能達到門檻解除；選哪一個應由具體 術式結構 確認，不能一方面寫逐步減弱、另一方面毫無說明地瞬間永久存在。

**反制**：可能有相容的通用解除方法；特殊備援另行設計，不能宣稱完全免疫。

**世界秘密**：若它持續建立跨世有效干涉，可能增加 The Fading；玩家早期不必知情。

**Combat**：目前**不新增** 星辰護盾 SP、不設定 AP／MP、不新增 Buff 或 HUD；需要另案核准。

## 4. 五個一定要通過的邊界測試

1. **魔力很多就萬能？** 高 Mana 或容量不能取代合法 術式結構、材料或能源來源。
2. **天才不念咒就違法則？** 破棄詠唱＝無詠唱，但必要構築與條件仍不能省。
3. **既成結果被消除？** 解除火球不等於把已燃燒物體恢復。
4. **設備要綁定本人？** 自主魔導設備不必依賴原魔法師在場；若要綁定須說明具體介面與條件。
5. **研究學科被當成絕對權能？** 存在時間、生命或因果學科，不等於可自由倒轉時間或復活任何死者。

## 4.1 禁忌級共鳴封鎖的額外必查事項

若角色或 Boss 能封鎖別人的魔法，設計者必須回答：

- 封鎖的是**哪位施術者**的個人請求成立途徑，還是哪道已成立的術式？不能含糊。
- 封鎖後，目標**親自維持**的術式是否有緩降、備援或獨立供能？
- 封鎖術自身需不需要維持？依使用者已選 **C**，由術式結構決定，不自動永久。
- 目標是否能繼續操作真正**自主施法**的設備？
- 若角色想阻止 The Fading，封鎖本身的新干涉負擔怎麼計入？如何處理早已累積的負擔？
- 是否將尚未核准的永久性、範圍、反制或現行卡牌禁用偷偷寫成 Canon？

詳見[禁忌級共鳴封鎖](06_FORBIDDEN_RESONANCE_SEVERANCE.md)。

## 5. The Fading 與異形的作者級檢查

**禁止向玩家直接揭露的 CONFIRMED**：魔法干涉增加此世的長期全域負擔；局部可失衡；真正異形是此世的非人格化校正反應且有七條 V0.9 核准邊界。異形被殺不清除已累積負擔，魔法對抗異形可能形成惡性循環。

劇情不能直接宣告：
- 「當天的火球術立刻召出了這隻異形」；
- 「異形是彼世派來的侵略者」；
- 「打倒 Boss 就降低世界熵」；
- 「第一章全班學生早已知道真相」。

上述均需要新的、明確的作者決策，不能為了方便寫故事臨時補上。

## 6. Agent 寫作與開發流程

1. **讀**玩家版與作者版，辨認目前是要寫 NPC 對話、世界設定還是程式。
2. **列**已有的 CONFIRMED／DIRECTION 依據及 TBD，不混用候選與正史。
3. **構造**術式及資源、共鳴、失效和反制機制；至少一個正常案例、一個故障案例。
4. **審核**與既有魔導設備、詠唱術語、The Fading、人物知識分層的相容性。
5. **呈交**玩家可讀說明與作者技術備註，分別保存；作者秘密不可直接貼進玩家文件。
6. **若涉及玩法**，先檢查 Combat Rule Source of Truth，提出 ADR 或實作計畫；未得到指示不得自行修改。

## 7. 修改權威文件前的差異檢查

- 這次改動的是玩家敘述、作者法則、還是 Gameplay？
- 是否有更晚的使用者確認推翻舊決策？
- 是否把「示例百分比」「反運算第 23 題的提議判準」偷變成正式硬公式？
- 是否公開了本應留到後續章節的 The Fading 因果？
- 相關的 `docs/world/README.md`、`13_CANON_DECISIONS.md`、術語表是否需要同步？
- 本次是否真的有程式／測試證據？**只改文件不得宣稱遊戲功能已完成。**

**完成定義**：新的術式可以被玩家用一段白話理解，也能被編劇和 Agent 清楚指出合法條件、代價、限制、故障與可反制處，而且不與既有 Canon 和 Combat 正式規格衝突。
