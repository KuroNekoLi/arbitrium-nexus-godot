# Mana、彼世耦合與詠唱｜為什麼相同火球效果不同？

> **作者技術規格｜V1.0。** 第 24–25 題採 C；第 28 題 C 為使用者明確選擇；公式只作教學，不是正式 Gameplay。

## 1. 五個問題，不是五種同義詞

問一名學生「你的火球為什麼不夠大？」可能有五種答案：

| 問題 | 本作概念 | 水管類比 |
|---|---|---|
| 還能持續施法多久？ | **Mana 儲量**及其他可動用資源 | 水庫存量 |
| 一次能承受多大規模？ | **耦合容量／瞬時承載** | 管線最高流量 |
| 同樣的術式能實現多完整？ | **耦合效率** | 傳輸與轉換是否有效 |
| 長時間或受擾時會不會出錯？ | **耦合穩定性** | 管線與控制是否可靠 |
| 火球的熱量、物質從哪裡來？ | **效果能源／材料來源** | 水真正從哪裡來 |

水管只是類比：**不是所有魔法都傳送一股能量**。Function Graph 可以依法則改變此世物質與能量，或建立某種持續的特殊狀態。

## 2. 「耦合」究竟是什麼？

**第 25 題 C：SELECTED。** 彼世的合法操作能有效作用到此世的關係，稱為耦合（Coupling），可用「容量、效率、穩定性」三性質研究。這不是一根一定存在的實體電纜，也不要求彼世是有意識的意志。

- **容量**：在指定情境中可支援的負載上限；不要與 Mana 總儲量混淆。
- **效率**：在 Graph、參數、資源、環境和比較量都固定時，理想效果的有效實現程度。
- **穩定性**：對時間、擾動、控制誤差及接近負載上限時的可靠度。
- **當前負載**：術式正在要求多少干涉，是運作狀態，不是第四項天賦。
- **共振頻率**：可能屬於某些調諧術式，不是全部魔法都具備同一種頻率的核心公理。

容量提高，並不保證原本固定參數的火球自動變大；效率高，並不代表可跨越不存在的能源約束。

## 3. 單一火球的教學公式與限制

假設火球某一個可比較輸出量的理想值是 100，而執行條件允許，示意：

`P_actual ≈ η × P_ideal`。

若容量需要參與限制，可以在**同單位、穩定且單一輸出指標**的簡化情況寫成 `P_actual ≈ η × min(P_ideal, C)`。

**兩式都是比喻型簡化，絕非魔法的普適物理方程。** 火球溫度、體積、傷害、速度、存續時間不一定按照同一比例改變；失去穩定性可能導致突然失效。尤其不能直接寫成 Godot 傷害公式。

## 4. 同一份火球術的三類天才

假設所有人用同一份合法 Graph、同一參數與相同的能源條件：

1. **高效率型**：在其他條件相同時，更接近該術式的理想實現程度，或在實現相同效果時減少個人承載消耗。不能因此憑空創造熱量。
2. **高承載型**：能安全處理別人無法承受的高負載。若標準火球只要求固定小輸出，他不會自動變得更強；需調高合法參數及備足能源。
3. **高理解型**：擅長分析、調參、重寫或發明 Graph。**在 Graph、參數、資源、控制與耦合條件完全相同時，不會只因懂得多而自動獲得額外傷害。**

三種天賦可以並存，且專注、意念控制可經訓練改善。它們**不代表必須在遊戲角色資料中新增三個屬性**。

## 5. 詠唱真正的工作

詠唱是**常見的術式構築、意念整理與耦合校準輔助**，不是彼世的語音密碼：

| 名稱 | 確切定義 | 可能的取捨 |
|---|---|---|
| **完整詠唱 Full Chant** | 依完整外顯程序輔助構築、校準 | 較易穩定，通常較費時間 |
| **縮短詠唱 Shortened Chant** | 保留部分外顯咒語，只省略可省略的步驟 | 較快，可能損失效率、穩定性或控制範圍 |
| **破棄詠唱＝無詠唱 Chantless** | 完全不外顯詠唱，以內化程序完成合法操作 | 高手未必較弱；能力不足者可能失敗 |

**這是使用者明確糾正的定義。** 原先拿「破棄詠唱只有 65%」舉例的說法，應視為**縮短詠唱的示意**；65%、80%、99% 都不是核准的角色倍率。

世界法則允許天才無詠唱依然高品質，卻**不變更現行戰鬥設計**：遊戲裡破棄詠唱目前是立即較弱，完整詠唱是延後較強。這是該系統的平衡與操作契約，不能以本體論直接覆蓋。

## 6. 施術者、設備與長期結界

**第 24 題 C：SELECTED。** 維持成本由術式、負載和耦合條件共同決定：
- 由個人持續維持；
- 由預先儲存的資源維持；
- 由自主魔導設備維持；
- 在適當合法設計下，低耗維持；**低耗不等於免費無限**；
- 已完成普通物理變化的效果，可以不再保持耦合。

同一型號、同一設定的自主魔導手電筒，只要設備、供能、環境相同，誰按開關都應輸出一致；除非特別設計接受外部 Mana 或控制輸入。

## 7. 施術者安全不等於世界可持續性

**作者秘密。** `Mana 消耗`、`耦合負載`、`The Fading 負擔` 是不同帳本。提高 Mana 效率不必然等比降低此世的世界負擔；魔導設備普及甚至可能使總干涉量上升。The Fading 建立及持續干涉負擔的精確公式 **TBD**。
