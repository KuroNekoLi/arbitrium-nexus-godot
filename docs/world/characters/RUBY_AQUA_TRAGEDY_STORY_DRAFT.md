## 核心句

> **「我一直以為，這個世界需要的是星煌露比，而不是那個沒能救下她的 Aqua。」**

這句話只代表 Aqua 在創傷中的錯誤信念。故事的最終回答必須是：**Aqua 本來就值得活下去；現在的 Ruby 也能因她自己的選擇而真實存在。**

## 結構：兩條時間線

- **過去（暫定國二）**：安靜的 Aqua 與活潑的 Ruby → 觀測站事故 → 拯救孩子與最後的分別 → 自責與劍的封存 → 逐步模仿 Ruby → 少數家族人物協助隱瞞。
- **現在（高一／高二）**：活潑的 Ruby 在星煌魔法學院求學 → 佩劍、星形掛飾與求救的伏筆 → 學妹提及神秘劍士 → 觀測資料指向未知異常 → 角色真相 → 重新拾劍、自我接納。
- **世界長線**：觀測站當晚的魔法失靈、儀器失準、異形現身，與傳說中的「褪色」徵候相似；**真正因果不在本稿定案**。

## 序幕：不說話的少年與愛笑的少女

國中以前，Aqua 是一個話不多、善於觀察、卻不擅長用語言表達感情的孩子。

他出眾的天賦不在劍，而在認知魔法：他能察覺別人如何理解眼前的事物，並以極精密的術式調整感知。可是，比起難以說明的認知術式，他更願意練劍——揮劍、架擋、踏前一步，都有明確的結果。

與他相反，星煌家族唯一繼承人 Ruby 是個藏不住笑聲的少女。她喜歡魔法、喜歡人群、喜歡惡作劇，總能讓 Aqua 的沉默變成一場她自己說個不停的對話。

某個午後，兩人在庭園練習。

> **Ruby：**「Aqua，你怎麼又不說話啦？」
>
> **Aqua：**「……不知道要說什麼。」
>
> **Ruby：**「那你笑一下！」
>
> **Aqua：**「有什麼好笑的？」
>
> **Ruby：**「因為我很可愛呀！」
>
> **Aqua：**「……真受不了妳。」

她笑得更開心。

兩人有婚約，卻沒有哪一方將它當成嚴肅的權力契約。對當時的 Aqua 而言，他最重要的願望，是保護 Ruby。

> **Aqua：**「將來有危險，我會保護妳。」
>
> **Ruby：**「那你也要讓我保護你呀。」
>
> **Aqua：**「我會變得很強。」
>
> **Ruby：**「強到不需要別人幫你，那不就很寂寞嗎？」

Aqua 沒有回答。多年後，她才會明白這句看似隨口的話。

### 平凡的小約定

國二那年（候選），Ruby 偷偷請人製作一枚小小的星形掛飾，打算送給 Aqua 的劍鞘。因為她總嫌那柄黑漆漆的劍太不可愛。

背面刻著一句平凡的話：**「Aqua，也要記得保護自己喔。」**

Ruby 準備在下一次外出後帶 Aqua 去領取。她還不知道，那會成為自己來不及送出的禮物。

## 第一幕：不該出現的異形

事故發生於**星煌魔法學院入學以前**，暫定在星煌家族學院外的一座地方觀測／魔力防護研究站「星見觀測站」（工作名）。

這裡不是學院高中部，也不是開學後的學園祭。它負責監看一片居民區周邊的魔法設施與異常訊號，並有供少數受邀孩子參觀的安全區域；具体位置與組織體制待定。

那天原本只是小型展示活動。

然而，裝置出現了令人不安的讀數：一盞由多個獨立回路供能的術式燈在同一瞬間熄滅；重新描繪的符文短暫無法穩定；幾部以不同原理工作的測量裝置卻回報彼此矛盾的結果。

值守人員尚未釐清原因，一種不尋常的**異形**便出現在站區外緣。

它不是突然被叫做「褪色怪物」的已知物種；當時的人只能辨認它會干涉周遭術式，而其真正來源不明。

警報響起，站內的防護術式接連失效。幾個避難通道被倒塌的牆體封住，部分孩子困在內部。

這場災難的直接表現是**異形威脅、設施故障與救援失序**。是否有人事前忽略警報、異形是否由更深的世界失衡引出，目前不能定案。

**埋給後期的伏筆**：多年後，研究者拿到殘存紀錄時，發現那些儀器不是普通地「壞掉」，而是短時間內連它們用來校準魔法的標準都不再可靠。這可以讓角色懷疑其與 The Fading 有關，卻仍不是已證實的世界真相。

## 第二幕：最後的三分鐘

Aqua 和 Ruby 本來可以隨其他人離開。

但有人說裡面還有孩子。

Aqua 用劍劈開堵住走廊的殘骸；Ruby 則利用她熟悉的術式維持短暫的保護與逃生通路。孩子們一個個走過。

眼看最後幾個人即將脫困，觀測站的緊急術式卻開始崩潰。

有人必須守在內部的控制端，手動穩定防護；另一個人必須迅速開路，把孩子帶出去。Aqua 不熟悉控制端；Ruby 沒有 Aqua 那種快速清除斷梁的劍技。兩人的位置不能輕易對調。

Aqua 說自己留下。

> **Aqua：**「我留下來。妳帶他們走。」
>
> **Ruby：**「你又不懂這座結界怎麼操作。」
>
> **Aqua：**「我可以學！」
>
> **Ruby：**「現在沒有時間啦，笨蛋。」

Aqua 盯著正在閃爍的防護陣，又看了眼等待救援的孩子。

> **Ruby：**「你不是說會保護我嗎？」
>
> **Aqua：**「……嗯。」
>
> **Ruby：**「那就先幫我把他們帶出去。」
>
> **Aqua：**「可是妳——」
>
> **Ruby：**「我處理完就跟上。快去！」

Aqua 帶孩子走向出口。走出幾步，Ruby 突然又叫住他。

> **Ruby：**「啊，對了！」
>
> **Aqua：**「怎麼？」
>
> **Ruby：**「回去之後記得陪我去買東西。」
>
> **Aqua：**「買什麼？」
>
> **Ruby：**「秘密！」
>
> **Aqua：**「……妳又想亂花錢。」
>
> **Ruby：**「少囉嗦啦，快去！」

Aqua 沒有再回頭。

**這是他們最後的對話。**

沒有預知死亡的告別詞，也沒有刻意留下完美的遺言。Ruby 當時確實希望、也以為自己還有機會追上大家。

Aqua 用劍開出最後一條路，帶著孩子們逃到了外側安全區。

背後傳來更猛烈的魔法震盪；原本的通道被封閉。防護層在一次未知衝擊後徹底崩毀。

Aqua 試著回去。現場已不可能安全通行。到救援隊接近失事核心時，一切都太遲了。

**孩子們全都被救了出來。真正的 Ruby 沒有。**

Ruby 的死由少數有權接觸核心事故資料的星煌家族人物確認；公開救援報告的細節如何處理仍待規格化。

## 第三幕：做對了，卻失去最愛的人

事後調查證明：Aqua 並未製造事故；他的分工與撤離判斷符合當時可知資訊。他沒有操作控制端的技術，也無法同時抱著所有孩子並回去接人。

Ruby 留守的判斷不是「她必死」的宣判；只是當時最有機會讓大家活下去的安排。真正造成她死亡的，是失控的威脅及其背後尚未查清的條件。

可是在 Aqua 的記憶裡，事故只剩下三個畫面：

1. Ruby 站在門那一端，還笑著叫他快走。
2. 自己帶著其他孩子，一步步離她更遠。
3. 回頭時，已再也找不到那條走廊。

調查者說 Aqua 沒有錯。被救的家庭感謝他。星煌家族有人稱讚他的勇氣。

這些話都讓他更加痛苦。

> 「你們為什麼要謝我？我明明把最重要的人留在那裡。」

真正折磨 Aqua 的，不是有人證明他犯了錯，而是**沒有人能給他一個改正錯誤的機會**。

他開始責怪自己活著，錯誤地相信：

> 「如果當時活下來的是 Ruby，所有人一定比現在更幸福。她會繼承學院、照顧那些孩子、讓每個人笑起來。可是留下來的是我。」

這不是作品對人命價值的判斷，而是國中孩子在創傷中極不公平地評價自己。

從此，Aqua 不再拿劍。那把劍讓他想起的不是失敗的劍法，而是他曾用那把劍為其他人開路、自己卻再也走不到 Ruby 身邊。

## 第四幕：第一個謊言，不是為了騙過世界

**這是本版新增的關鍵場景，用來說明 Aqua 為何會開始成為 Ruby。**

事故後，幾名倖存孩子仍住在星煌家族協助的療養設施中。

其中一個年幼的孩子夜裡反覆驚醒，問照護人員：

> 「Ruby 姊姊會來嗎？她說外面安全了……」

沒有人知道該怎麼回答。

Aqua 在走廊外聽見了。

他知道 Ruby 不會再來。但他也記得那個孩子在事故裡如何抓住 Ruby 的手，才終於敢走進逃生通道。

那天，他第一次用自己最擅長的認知術式**模仿 Ruby 的聲音**，隔著門對孩子說：

> 「沒事啦。今天已經安全了。快睡吧。」

孩子慢慢平靜下來。

他沒有出現在孩子眼前，也沒有打算永遠冒充 Ruby。他只是讓一個今晚睡不著的孩子得到片刻安寧。

後來，Aqua 又一次嘗試；這回，他讓自己擁有 Ruby 的臉、頭髮、聲音、身形與觸感。

在鏡子裡，他重新看見那個曾讓自己笑起來的人。

他模仿她歪頭的樣子。

> 「因為我很可愛呀！」

聲音毫無破綻。

可是房間裡沒有人再回答：「真受不了妳。」

Aqua 終於明白：無論這份魔法有多完美，都不能讓真正的 Ruby 復活。

即使如此，他還是無法停止。

## 第五幕：為什麼非得成為 Ruby？

本稿**刻意不用『有一種祖傳法術規定非假扮不可』**當作唯一理由。那種設定很容易把人物悲劇變成冰冷的解謎機關。

讓 Aqua 走到這一步的是三種壓力疊在一起。

### 其一：他錯誤地認為 Ruby 比自己值得活

在 Aqua 心中，Ruby 是星煌家族獨一無二的繼承人，能讓沉默的人開口，能讓害怕的孩子笑起來，也有心願要完成。

自己只是個話少、在事故裡未能守護她的少年。

於是他產生一個並不理性的等式：

> **「如果世界只能留下我們其中一個，應該留下 Ruby。」**

他知道 Ruby 已死，卻拼命讓「Ruby 還活著」的世界看起來成立。這是一種自我否定與倖存者愧疚，**不是值得讚美的犧牲精神**。

### 其二：真正的 Ruby 還有未竟的承諾

當年的倖存孩子部分需要漫長的醫療、心理照護與魔法異常追蹤。星煌家族支援的研究與救助計畫也可能因繼承真空、理事會爭權及事故責任爭議遭到縮減。

**這是現實壓力提案，不是已確立的家族法律：** 若公開宣告唯一繼承人死亡，個別派系可能趁機要求封存危險設施、停止昂貴調查，甚至重新分配原本以 Ruby 名義推動的資源。

少數核心知情者選擇協助 Aqua 對外維持 Ruby 的身份，使善後、獎助與調查得以暫時繼續。真正的法定繼承程序、是否有人利用 Aqua 和其親屬如何知情，仍須日後補完。

有人真心想保護 Aqua；有人害怕失去 Ruby 代表的家族秩序；也有人可能以為等 Aqua 長大後就能收拾局面。

Aqua 卻把這些現實壓力理解成：

> 「只要 Ruby 還在，那些孩子就還有人照顧。那麼……Aqua 不在也沒關係。」

**外部確有壓力，但不存在一條客觀道德法則認定 Aqua 必須消失。** 故事要讓玩家最終看見，真正應對制度與救助負責的是成年人，不能把責任全壓在一名遭逢悲劇的孩子身上。

### 其三：這個名字變成新的自己

起初，Aqua 每次開玩笑前都要想：「如果是 Ruby，她會怎麼說？」

她學著以法杖施法，因為原 Ruby 喜歡魔法；擅長的認知術式則成為祕密，而雷電與控制魔法成為她公開的戰鬥風格。

後來她不必思考就能說出笑話，真的喜歡有人圍著自己聊天，也逐漸發展出**真實而自主的女性身份認同**。

這不只是偽裝的效果，亦不是 Ruby 靈魂附體；是活著的 Aqua 在這段複雜人生裡逐步成長出來的自我。

**悲劇性在於：最初讓她活下去的名字，也可能讓她以為自己沒有權利成為別的人。**

## 第六幕：封劍與沒送到的禮物

一段時間後，訂製掛飾的店家送來 Ruby 事故前準備的禮物。

那只是一枚小小的星星，並非神兵或封印鑰匙。

背面刻著：

> 「Aqua，也要記得保護自己喔。」

Aqua 把它繫在原本的劍鞘上。

她沒有丟棄那把劍，卻再也不肯拔出來。

多年後，星煌魔法學院的學生常常注意到 Ruby 腰間的劍與劍鞘上的小星星。

> **同學：**「Ruby，妳明明是魔法使，怎麼還帶著劍？」
>
> **Ruby：**「很帥啊！而且星星很可愛吧？這可是秘密喔！」

同學笑過就忘了。

玩家若仔細看，或許會發現：Ruby 開玩笑時，手指卻總是牢牢護著那枚星星。

## 第七幕：入學後的笑聲與不協調

**注意：遊戲主要故事發生在高中一／二年級；學院認識的 Ruby 從入學開始便是 Aqua。**

家族少數核心人物維持公開說法：原 Ruby 在事故後重傷、長期療養，終於恢復到能入學；Aqua 則在事故結束後逐漸從公開生活裡消失，去向不明。

由於 Aqua 的認知魔法能長期維持容貌、聲音、身形和觸感，即使失去意識也不解除，因此一般學院師生沒有合理理由懷疑。專門破解需要極其困難的認知術式對抗，不能因普通照鏡、碰觸、魔力不足或戰鬥失能就露出真身。

玩家首先遇見的 Ruby，是一位金髮琥珀眼、外表嬌小、身著黑金短褲制服、愛說話、愛開黃腔的學院名人。她總帶著星辰法杖和那柄不出鞘的劍。

她有真誠的快樂；玩家不可被要求把全部笑容都理解為謊言。

### 支線：那個當年救我的人

一名新入學的學妹鼓起勇氣向 Ruby 打招呼。

> **學妹：**「Ruby 學姊……我一直很想見妳。」
>
> **Ruby：**「咦？我們以前見過嗎？」
>
> **學妹：**「以前有一場事故。有個拿劍的少年帶我們逃出來。」
>
> **Ruby：**「……」
>
> **學妹：**「我一直想跟他道謝，可是後來再也沒聽到他的消息。」
>
> **學妹：**「學姊聽說過那個人嗎？」

這段避免設定成「學妹不可能知道的私人婚約或家族死亡真相」；她記得**劍士和救援**，但不知道如今眼前的人就是他。

Ruby 很快露出招牌笑容。

> **Ruby：**「那傢伙啊？超級不會聊天的！如果找到他，記得叫他多笑一下！」

學妹被逗笑了。

她離開後，Ruby 低頭看著腰間的星形掛飾，許久沒有說話。

第一次看到，這只是小小的反常。等真相揭曉，玩家才會理解當時的沉默。

### 更多可回收的校園伏筆

- Ruby 明明擅長雷電法杖，卻有極高品質的劍士站姿、迴避步伐和握柄習慣。
- 她與真正會操作認知魔法的教授保持距離，但不是因為教授輕易識破她，而是 Aqua 害怕某人真的有能力投入長期調查。
- 聞到觀測站舊藥品的氣味或聽見特定防護警報時，她會短暫失神；其他學生只以為她討厭警報。
- 她會對「妳救了大家」這句話露出很難辨認的表情，因為當時帶孩子離開的是 Aqua。
- 對朋友的關心逐漸出於她自己的選擇，而不只是模仿真正 Ruby。

## 第八幕：真相不只是 Ruby 死了

學院主線開始出現新的術式失準與異形目擊事件。

玩家逐步取得一份觀測站的舊檔。原始紀錄並不是「The Fading 已被證明是所有異形起源」，而是幾組無法用普通設備缺陷完全解釋的異常資料。

某些人主張那只是過時設備失靈；某些人懷疑與更深層的世界代價相關；有人甚至不願重開當年的研究。

在這條調查線裡，玩家終於得知：真正的 Ruby 死於國中事故，身邊的 Ruby 原本叫 Aqua。

**但揭露秘密不等於強迫 Ruby 變回原貌**；也不等於只要教授找到一張報告就能治癒她。

Aqua 最艱難的不是接受「事故不是我的錯」，而是放下她始終相信的命題：「如果世界需要 Ruby，就不需要 Aqua。」

此時可以安排一位她信任的人回答：

> 「那些孩子得救，不是因為 Ruby 比妳重要，也不是因為妳不重要。是因為那天，你們兩個都拼命想救人。」
>
> 「妳現在喜歡的事、在這裡交的朋友，也不必替誰交代。」

真正的 Ruby 留給 Aqua 的普通掛飾並不會神奇解開心結。多年來的悲傷仍然存在，她只開始學會不再以死者的價值否定生者。

---

## 終幕：星星還在劍鞘上

多年以前，Aqua 持劍帶著孩子逃出走廊；這次，學院的同伴也面臨被異形圍困或防護崩潰的危機。

Ruby 的法杖無法單獨完成救援，腰間的劍卻仍在。

她握住劍柄，恐懼再次湧上來。

她沒有因為害怕重演過去就直接衝進危險送死，也沒有放棄眼前需要自己的人。

她先確認同伴的意願，安排撤離路線，再用雷電控制創造空隙；最後拔劍，以她曾經熟悉、如今重新願意使用的技巧打開通道。

**這次拔劍代表接納過去，而不是用一次勝利『補償』真正 Ruby 的死亡。**

戰後，她仍是黑金制服、短褲、金髮琥珀眼、喜歡雷電與法杖、愛聊天的 Ruby；她的性別認同沒有因拔劍而改變。

她低頭望向那顆星星。

> 「以前我以為，只要成為妳，就能讓妳繼續活著。」
>
> 「可是現在……我想帶著妳留給我的東西，好好過接下來的人生。」

她把劍收回鞘中，依舊沒有摘掉掛飾。

**真正的 Ruby 不會回來；現在的 Ruby 可以繼續活下去。**

## 需要使用者下一輪裁定

1. 選定事故是國一或國二，並確認學院主線開場是高一或高二。
2. 「星見觀測站」與事故細節是否接受為正史。
3. **已知設備警告遭掩蓋／真正意外／蓄意破壞**哪一種是事實；目前三者未裁定，**本稿不暗中選 B**。
4. 異形與 The Fading 的關係要在主線哪一章取得證據；禁止過早定義世界所有異形來源。
5. 倖存者照護與繼承政治要多寫實；哪幾位家族人物同意冒名及其各自利害。
6. 是否保留「星形掛飾」及學妹支線；是否採用最後拔劍作為可玩 Variant。
7. 真正 Ruby 的父母、Aqua 原生家庭，以及對外紀錄如何做到長期一致。
