## 2. 認知偽裝的敘事邊界（已確認）

1. 形體、聲音、觸感都和原 Ruby 一致；任何普通檢查與接觸不會自動揭露。
2. Aqua 失去意識時仍維持 Ruby 的外觀。
3. 大部分人不會懷疑；若專家懷疑，破解仍極其困難。
4. 對其生效時間、魔力代價、極端反制、特殊法器等**尚未定案**，編劇不得因急需高潮而讓魔法隨機失效。
5. 若未來設計解密橋段，優先使用**事故檔案、行為證據、信件、熟悉劍技的人、知情者告白與 Ruby 自願坦白**，而不是讓某個臨時登場的學生直接看穿臉。

## 3. 建議角色戰鬥定位（尚非實作）

- 初期戰鬥形態：**雷電控制型魔法使**，使用星辰法杖；低階可以用感電降低威脅，進階麻痺需 Boss 個別抵抗規格與正式 ADR；法杖以原地施法為主。
- 隱藏敘事專長：認知魔法天才，不直接等同「戰鬥時每回合必定控制所有人」。
- 後期 Character Variant 候選：**魔劍複合型**。劇情中拔劍代表接納曾經的 Aqua，並非回到男性身份；戰鬥資格／SP／Last Spell／動畫／素材都要獨立設計、驗收。
- 不能因 Ruby 是家族天才就跳過 12 SP、共享 AP、個人 MP、雙詠唱、Combo／Last Spell 等現行 Domain 規則。

## 4. 角色 CG 與 Godot 素材規格

- **視覺基準**：金髮、琥珀眼、女性化容貌、約 145cm、黑金制服、男性剪裁外套、**短褲**、星辰法杖、腰間未拔的佩劍。角色設定以使用者實際核准的圖像為準；不因「認知魔法」理由擅自隨機換臉換服裝。
- **正常／失能 CG**：失能角色保留 Ruby 的外貌與聲音設定，不能在 HP=0 自動回到 Aqua 原形；失能與 Last Spell 耗竭退場不同。
- **CG 狀態集**：正常半身肖像／失能肖像／站立戰鬥全身／失能戰鬥全身。劍原則保持入鞘；不同情緒差分可以在公開笑容與內心壓力間製作。
- **原地施法攻擊圖集**：準備→舉杖→凝聚電荷→建立雷電術式→釋放→殘光→收杖，不需要劍士式的衝刺／貼身攻擊。製作逐格圖片時保持同尺寸、角色腳底錨點、姿勢方向與配件一致。
- **揭秘限定 CG**：Aqua 的原貌仍 TBD，**不可把推測的原貌當已定資料**；是否有變身解除動畫必須另行確認。
- **服裝限制**：既定正式校服為**短褲**，不是裙子或長褲；禁止重新把 Ruby 混同為先前獨立設計的西裝女性魔法使。
