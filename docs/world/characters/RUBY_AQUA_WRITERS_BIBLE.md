# 星煌露比（Ruby）／Aqua 人物聖經

> **編劇內部｜重大劇透｜2026-10-20｜Canon v0.4／故事提案另外標註**
>
> 本文保存使用者已確認的正史。劇情草案見 [〈在星光褪去以前〉](RUBY_AQUA_TRAGEDY_STORY_DRAFT.md)。**本文寫入 Git 不等於所有劇情候選均已核准**。
>
> 重要原則：原本的 Ruby 與現在以 Ruby 生活的 Aqua 是兩個不同的人。製作內部應有不同的角色 ID／劇透標籤，不能把「偽裝的過去」誤寫成「現在的女性身份不真實」。

## 1. 已確認 Canon：身份與家族

1. **星煌魔法學院**是世界最著名的私立魔法學院，由**星煌家族**創立，也是遊戲主要的校園故事舞台。
2. **真正的星煌露比（Ruby）**是星煌家族原本唯一的繼承人，與 Aqua 自幼相識，有青梅竹馬及未婚伴侶關係。
3. 真正的 Ruby 活潑、開朗、健談，是 Aqua 後來刻意模仿的言談與性格來源。她在過去的悲劇中**確實死亡**，沒有設定為假死或已經復活。
4. **阿奎亞（Aqua）**原本以男性身份生活、話少、內向冷靜、不擅長表達，原本擅長用劍；其性格不是一開始就陰鬱。Ruby 死後才長期陷於自責、逐漸封閉自己。
5. Aqua 因認為當時沒能保護 Ruby 而感到罪疚；但**造成 Ruby 死亡的責任實際不在 Aqua**。
6. Aqua 之後以 Ruby 的名字、外貌、聲音和活潑言行延續她的生活；**只有星煌家族少數核心人物知情**，其餘大多不知真相。
7. Aqua 在長期以 Ruby 身份生活的過程中**逐漸形成自身的女性身份認同**；她現在認同自己是女性，也喜歡女生。情感／性傾向與性別認同是兩件不同的事，不能把後者簡化為創傷、精神魔法副作用或男性角色的搞笑扮裝。
8. 真正 Ruby 的死亡發生在**進入星煌魔法學院高中部之前**，大致是國一或國二；故事現在為高一或高二。**確切學年尚未拍板**，可以在草案暫以國二／高一試排。
9. 未來 Ruby 克服過去的心魔後，才可能主動重新用劍戰鬥；**拔劍不等於放棄 Ruby 的名字、女性認同或恢復昔日的男性身份**。

## 2. 已確認 Canon：認知魔法

- Aqua 原本就是**認知類魔法的天才**，這不是悲劇後偶然得到的能力。
- 她的魔法可使自己長期維持與真正 Ruby **外貌、聲音、觸感、身體外形**一致的狀態；這不是只可騙過眼睛的粗糙幻術。
- **失去意識時也不會解除**；戰鬥 HP=0 的失能 CG 仍保持 Ruby 的樣貌。
- 一般人根本不會主動懷疑；即使起疑，要突破認知術式也須付出極大力量與努力。無法用一句「摸一下」「照鏡子」「昏倒」就破解。
- 魔法如何維持、合法診斷或其他超高權限術式是否有特例，仍待劇情規格化；不可擅自讓普通 NPC 識破。
- 此能力屬世界觀中的**認知（COGNITION）**魔法研究，與戰鬥時的雷電專精不同。不得推論她能隨意改寫任何人的全部記憶、現實歷史、血緣或法律關係。

## 4. 已確認的最新創作方向，但不是事故細節 Canon

- Ruby 的死亡希望與**異形**、**The Fading／褪色的世界謎團**產生關聯。
- 必須有足以說服玩家的「Aqua 為何要成為 Ruby」動機。使用者提出的重要心理方向：Aqua 可能以為「**比起自己，Ruby 活著對世界更好**」。
- **重要角色倫理界線：** 這個比較是 Aqua 在悲痛中的主觀、錯誤判斷，作品不能將其當成客觀事實；長期的人物成長是發現自己的生命有同等價值。

## 5. 作者用動機模型（具體內容仍屬提案）

> 「我不願意看見這世界失去 Ruby，卻留下只會逃走的 Aqua。」

**第一層：倖存者愧疚。** Aqua 帶領孩子成功撤離，但 Ruby 沒能活下來。她深信自己未完成「保護 Ruby」的承諾。她沒有責任，卻把正確決策體驗成背叛。

**第二層：價值錯估。** Ruby 是星煌家族繼承人，會讓人微笑、能鼓舞大家，還有未完成的救援與教育計畫；Aqua 自認沉默而無足輕重，錯以為「以 Ruby 的身份活下去」比「繼續當 Aqua」更能保護她珍愛的東西。

**第三層：少數成年人共同形成的現實局面。** 事故可能牽涉需要持續救助的孩子、失效術式與昂貴的長期調查。部分知情家族核心不忍孩子失去支持，也擔心繼承真空引發資金凍結、責任推諉，於是默許、扶持甚至利用這個身份。**並不是神秘魔法必然要求 Aqua 變成 Ruby**；這個「必要性」是創傷、權力與現實壓力合力構成的錯誤牢籠。

**第四層：身份逐漸自主。** 起初的模仿是為了不讓 Ruby 消失；後來的女性認同、友誼、笑容逐漸成為 Aqua 真實生活的一部分。最後不必「變回 Aqua」才能得到救贖。

## 6. 建議的劇情步調（非已定正史）

- **童年**：活潑的 Ruby 總讓沉默的 Aqua 忍不住回應；Aqua 練劍時希望保護 Ruby。
- **國中事故**：一座星煌家族的**學院外**研究／觀測設施，發生異形襲擊及術式異常。Aqua 與 Ruby 分工救援，Aqua 帶孩子逃出去，Ruby 維持屏障；Ruby 最後未歸。
- **國中後期**：Aqua 封劍；先模仿聲音，再模仿外貌，最終持續以 Ruby 生活。家族少數人知情、其他人不察。
- **高一／高二**：玩家先認識活潑的 Ruby，再從佩劍、小星形掛飾、舊事故、被救學妹及失控術式的異常，慢慢看見秘密。
- **後期**：她了解事故本來不是自己的過錯，面對可能與 The Fading 有關的線索，最後選擇為眼前的人拔劍；悲傷沒有消失，但可以繼續生活。

## 7. 必須保留的待決事項

1. 事故在**國一或國二**；當時真正 Ruby 和 Aqua 的具體年齡。
2. 「星見觀測站／天文塔」是否採用、實際位置、設施用途與涉事者姓名。
3. 異形為何出現；觀測到的異常是否真正由 The Fading 引起。**專案世界級因果仍屬候選，不可預設所有異形來自褪色。**
4. 是否存在已知卻被壓下的安全警報、管理疏失，或純粹不可預見的意外。**目前沒有選定 A／B／C。**
5. 原 Ruby 的魔法專長、她是否曾使用同一把星辰法杖；劍／星形掛飾是否為正式美術物件。
6. Aqua 的出身及其親生家人／監護人如何面對「Aqua 消失」；不以認知魔法自動解決所有文件問題。
7. 知情家族核心的確切人數與動機、繼承契約和學院董事會對身份的法律認定。
8. 玩家何時揭露秘密、能否取得錄音／信件、是否存在劇情分支、Ruby 最終公開身份與繼承安排。
9. 雷電的 SHOCK／PARALYZED、施法干擾、角色專屬 SP 和 Variant 的設計需走正式 Combat ADR，不得在此文件直接定數值。
10. Ruby 與其他角色關係**暫不寫死**，尤其不把 Demo 的 Ren／Akane／Tsumugi 當成固定劇情夥伴。
