# 世界觀與戰鬥規則｜故事怎麼說，遊戲就怎麼玩嗎？

> **劇情／戰鬥設計對照｜本文件不修改 Gameplay**
>
> 這篇讓寫作者、UI 設計者與開發者理解：世界裡「魔法能做到什麼」，和「這張卡在遊戲裡實際做什麼」，是兩件相關卻不同的事情。
>
> **戰鬥規則的權威來源：** [現行戰鬥系統總覽](../combat/README.md)，以及其連結的各篇正式規格。新版 Break 方案 C 尚屬獨立設計方向，不能在文件中冒充已經完成的可玩效果。

## 1. 所有技能卡都叫 SP，但不是所有 SP 都是魔法

蓮能夠使用破勢斬，朱音能夠施放火焰魔法，紬可以使用治療或防護術式。

在玩家畫面上，這些能力都可以透過「技能卡（SP）」呈現。

但在世界裡，**魔法術式卡**只是 SP 的一種。使用劍法時不必假裝角色正在把劍招變成魔法 Function。

| 世界觀說法 | 遊戲中的意思 |
|---|---|
| 已學會一種術式 | 人物懂得這項知識；不等於任意時候能使用所有相關 SP |
| 準備一張術式卡 | 對應合法卡片進入戰鬥可使用的配置 |
| 手邊暫時沒有適合的術式 | 沒有抽到、卡片不在手牌，或缺乏合法的施放條件 |
| 完整詠唱需要時間 | 卡片的 Full Chant 有規定的合法結算時點 |
| 蓮以劍技破勢 | 合法技能的 `break_damage`，不是施法干擾 |
| 朱音干擾敵方施法 | 作用於有效 CastingInstance 的 Casting Stability |

## 2. 不能因為世界觀好聽，就覆蓋現行戰鬥的六項硬規則

目前三人卡牌戰鬥具備以下已核准基礎：

1. 每名上場角色**恰好 12 張 SP**，個別維護牌庫、手牌、棄牌區與詠唱區。
2. 開場各抽 **4 張**；每個玩家階段**手牌少於 4 才補至 4**；手牌最多 **8 張**。
3. 全隊共享每玩家階段基準 **6 AP**；每個角色各自有 MP，MP 不會每階段自然回滿。
4. 合格的剩餘 AP 可在玩家階段末轉為全隊 RP，通常上限 **6**；RP 用於下一敵方階段的合法反應，之後清零。
5. 合法的完整詠唱需要等待指定時點並遵守 Concentrating、Casting Stability、Focus Ward 和中斷規則；普通技能沒有免費額外行動。
6. Last Spell 有獨立欄位，每角色每戰一次、強制完整詠唱。成功後角色**耗竭退場**，不能被普通治療帶回戰場。

此外還有已核准的換牌、合法配牌資格、Combo 真實雙人付費、Reaction 必須明確確認或 Pass 等規則，完整內容仍以 Combat 文件為準。

這些數字不是魔法世界的物理定律。它們是讓遊戲易玩、易平衡的戰鬥規則；**其他故事可以用不同戰鬥呈現方式，但不可在這部遊戲裡偷偷改掉已核准數值。**

## 3. 詠唱與術式反制：三種「破壞」不能混淆

| 玩家看到的字 | 白話意思 | 真正影響什麼 |
|---|---|---|
| **失衡 Break** | 打亂敵人的戰鬥姿態 | Boss 的 Break Gauge 與合格的下一個行動 |
| **暴露 Exposed** | 敵人露出一次可利用的破綻 | 下一張符合條件的追擊 SP |
| **詠唱干擾** | 打亂正在準備的法術 | **特定** CastingInstance 的 Casting Stability |
| **護唱 Focus Ward** | 幫助法術穩定完成 | 抵銷對該施法實例的合格干擾 |
| **術式反運算** | 試圖解除已形成的效果 | 目前是世界觀／未來能力候選，不是已完成的通用 Counter |

**重要版本界線：** 現行 master 的 Break 規則與最新選定的方案 C 還有差距。**方案 C** 的設計方向是：Break 歸零時壓制下一個合格 Boss 行動；普通行動可取消、重大招式降級，同時提供一次 Exposed。Boss 是否會主動露出弱點由個別行動模式決定。這個方向仍須配套 ADR、Domain、測試及 UI 才能宣稱已實作。

### 術語備註：破棄詠唱不等於縮短詠唱

2026-10-22 的魔法本體論 V1.0 已統一世界觀術語：

- **完整詠唱**：完整外顯輔助程序。
- **縮短詠唱**：仍念出部分咒語，只略去可省的部分。
- **破棄詠唱＝無詠唱**：完全不使用外顯詠唱，直接完成必要操作。

**但這不變更當前卡牌的數值與操作。** 現行 Combat 文件仍將破棄詠唱定義為立即施放、效果較弱；完整詠唱則是延後、效果較強。那是已核准的戰鬥選項，不能因作者世界法則允許高階人物無詠唱也能施放強大魔法，就私改卡牌係數。

術式解析、破解、反運算與 Spell Counter 在世界設定中有不同的涵義；現在是否可使用、何時可用，仍以 Combat Domain 為準。

## 4. 魔法學科不是元素相剋表

[二十四學科](02_MAGIC_DISCIPLINES.md) 供故事、圖鑑與術式設計使用。

它們**不是**二十四種 Damage Affinity，也不是二十四種 Debuff 或職業。

例如：
- 炎熱研究者施放火焰攻擊，實際是否對敵人弱點加傷由該敵人的 Affinity 決定。
- 時間研究者可以設計「讓接下來幾個玩家階段取得額外 AP」的**候選** SP，但研究時間本身不會自動獲得 AP。
- 虛無研究者懂得「消除」的理論，也不代表可以消除 Last Spell 的耗竭退場。

`ARCANUM` 研究學科（奧術）與 `ARCANE` 傷害共鳴是兩個不同分類，不能混成同一個程式值。

## 5. Mana Cost、APDebt 與 Reality Cost 分開

| 成本 | 故事理解 | Gameplay 現況 |
|---|---|---|
| **MP** | 施術者自身能調動的魔力量 | 個別角色持有與支付 |
| **AP** | 一段玩家行動窗口內，隊伍可分配的戰術資源 | 全隊共享 |
| **APDebt** | 特定技能透支未來的行動資源 | Overload 的合法還債機制 |
| **Reality Cost** | 世界是否因現實改寫承受長期代價 | **尚未成為已核准的 Gameplay 數值** |

不要把玩家每次使用 2 MP 就寫成「世界必定扣 2 點穩定度」。這既不符合目前程式，也會把仍待確認的故事秘密當作公開機制。

## 6. 一張牌應該怎麼寫世界觀說明？

以火焰 SP 為例：

**玩家版卡面短句：**
「聚集火焰，攻擊一名敵人。」

**圖鑑延伸句：**
「以預先準備的術式迅速凝聚熱量。完整詠唱可讓力量更充分地成形，但也讓施術者暴露在干擾風險中。」

**真正的遊戲效果：**
仍由該 `CardDefinition` 決定 AP／MP、Chantless/Full 倍率、命中、目標、額外狀態與結果事件，不能讓文案私下新增「灼燒」「破勢」或「暴露」。

這樣做，玩家讀起來有畫面，工程上也不會發生兩套互相矛盾的規則。


## 2026-10-22：名稱更新與禁忌級能力的玩法邊界

世界觀對魔法的正式說法是**術式結構**（舊研究曾使用 Function Graph），與術式卡、SP、詠唱區不是同一種資料結構；抽象式 `Y = E(F,p,R,K,X)` 中的 `F` 仍代表術式結構，**不是新 Combat API**。

作者已確認的「施術者級共鳴封鎖」可以讓目標**無法親自建立新的彼世共鳴**，不代表現行 Domain 已存在全面禁魔狀態、敵方不能採取其他行動、每張卡都要檢查新增狀態。**只有另經 Combat ADR 才能實作**。B 原有魔法與自主設備要依維持來源判斷，已完成的治療或火災不能倒轉。禁忌級角色及其試圖阻止 The Fading 的動機是作者秘密，不是此玩家對照文件可用於第一章的既知資訊。
