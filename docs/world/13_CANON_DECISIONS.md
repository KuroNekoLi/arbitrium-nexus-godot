# 世界觀 Canon 決策紀錄｜哪些已經確定？

> **世界觀製作規範｜2026-10-20**
>
> 同一世界可以容納不同主角與遊戲形式，但必須能區分「已確認的共同法則」「還在提議的設定」「遊戲現在實際有的功能」。
>
> **如果本檔與更晚的使用者明確決策矛盾，以較新的已確認決策為準；不能因本檔存在就自動將所有候選變正式 Canon。**

## 已由使用者確認

| 決策 | 本版權威邊界 |
|---|---|
| **共享同一個世界** | 可以有不同主角、不同地區、不同時間線段落；具體事件先後可重新編排 |
| **文件只使用本作自己的世界觀名稱** | 世界觀頁面不需要比較或直接提及另一個產品的名稱 |
| **文字容易理解** | 優先讓玩家看得懂，作者秘密與 Domain 對照另外拆檔 |
| **24 領域是研究學科，不是 24 套戰鬥機制** | 與已核准的戰鬥效果和元素抗性分開 |
| **戰鬥規則不能由故事私改** | 已確認的 12 SP、AP／MP／RP、雙詠唱、Combo、Last Spell 等不因本版設定變更 |
| **Break 方案 C 的高階方向** | 普通招式可取消、特殊大招降級並帶來一次 Exposed；細節尚待正式 ADR |

## 本版推薦成為共通世界法則，仍待內容審核

| 主題 | 建議 | 尚待確定 |
|---|---|---|
| 魔法的運作 | 透過合法媒介將意圖整理成術式，再完成世界狀態改變 | 魔法系統的最終本質 |
| 術式與學習 | Function Graph、Signature、標準術式、完整／破棄詠唱 | Tier 的正式敘事術語與教育分級 |
| 魔法文明 | 城市照明、醫療、交通、研究與防衛高度使用魔法 | 哪些地區普及、供能制度、成本 |
| 異形威脅 | 存在多種外形與行為的異常敵對存在 | 起源、種類、分布、生態 |
| 社會與組織 | 學院、公共維修、防衛隊、工坊及地方管理者 | 名稱、權限、國家版圖 |
| 24 學科 | 七群的研究方向 | 正式學派名稱、教材、學術史 |

## 必須先經重大敘事核准的候選

| 主題 | 為何不能直接定案 |
|---|---|
| **Reality Cost** 是世界必然承受的代價 | 會影響所有魔法、倫理與世界危機 |
| Entropy 必然造成所有異形 | 容易過早將一切未知縮減成單一因果 |
| The Fading 是已注定的未來 | 會限制各故事結局與時間線 |
| 秘密研究組織掌握全部真相 | 會影響學院形象及對外資訊 |
| 時間朔行者與大規模施法失能 | 會改變戰鬥、公共設施、角色能力與世界歷史 |
| 哪位角色是反派或救世主 | 需要完整人物動機、證據與事件驗證 |
| 具體城市、地圖、年代與家族關係 | 需要故事與美術共同審查，避免後續自相矛盾 |

## 文檔權限與讀取優先序

- **世界觀玩家敘事：** [WORLD_BIBLE](WORLD_BIBLE.md) 與 01～07，不可出現超出角色知識的「作者才知道的真相」。
- **時間線／作者候選：** 08～09，由劇情審查逐項決定是否轉正。
- **Gameplay：** [現行戰鬥規格](../combat/README.md) 為準；[世界觀對照](10_LORE_TO_GAMEPLAY.md) 只能解釋，不能改規則。
- **參考研究：** [研究紀錄](12_CREATIVE_REFERENCES.md) 只記錄創作方法，不提供外部作品設定的移植授權。

## 未來變更流程

1. 新想法先標記 **本版提案／待定**。
2. 說明它會改變誰的生活、哪些故事事件、哪些已核准規則。
3. 若涉及人物結局、時間旅行、世界危機或 Gameplay，先做專項決策與相容性 Review。
4. 明確核准後更新本檔與相關玩家篇章；若改戰鬥，另外走正式 Combat ADR／Domain／測試。
5. 保留舊版本紀錄，不在沒有理由的情況下讓後來寫出的段落推翻先前已發生的事件。
