# 世界觀 Canon 決策紀錄｜哪些已經確定？

> **世界觀製作規範｜2026-10-20**
>
> 同一世界可以容納不同主角與遊戲形式，但必須能區分「已確認的共同法則」「還在提議的設定」「遊戲現在實際有的功能」。
>
> **如果本檔與更晚的使用者明確決策矛盾，以較新的已確認決策為準；不能因本檔存在就自動將所有候選變正式 Canon。**

## 已由使用者確認

| 決策 | 本版權威邊界 |
|---|---|
| **共享同一個世界** | 可以有不同主角、不同地區、不同時間線段落；具體事件先後可重新編排 |
| **文件只使用本作自己的世界觀名稱** | 世界觀頁面不需要比較或直接提及另一個產品的名稱 |
| **文字容易理解** | 優先讓玩家看得懂，作者秘密與 Domain 對照另外拆檔 |
| **24 領域是研究學科，不是 24 套戰鬥機制** | 與已核准的戰鬥效果和元素抗性分開 |
| **戰鬥規則不能由故事私改** | 已確認的 12 SP、AP／MP／RP、雙詠唱、Combo、Last Spell 等不因本版設定變更 |
| **Break 方案 C 的高階方向** | 普通招式可取消、特殊大招降級並帶來一次 Exposed；細節尚待正式 ADR |
