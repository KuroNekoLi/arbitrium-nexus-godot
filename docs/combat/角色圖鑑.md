# 角色圖鑑｜初始三人隊伍

> **核准邊界**：主角初期固定劍士、未來 Variant 解鎖轉職，以及全員皆可配置通用基礎攻擊／治療／防護魔法，為已確認玩法方向。**人物姓名、數值、被動和以下技能內容仍是候選設計**；但目前 Lv40 Demo 確實使用這三個人物 ID。

## 朝霧蓮｜Asagiri Ren
- `character_id=ren`；初始 `variant_id=ren_swordsman_v1`；職能標籤 `SWORDSMAN`／`VANGUARD`。
- **定位**：物理劍技、Break、抓敵弱點 Exposed、連攜起點、援護隊友。也能裝通用攻擊魔法 U01、屏障 U02、治療 U05。
- **候選被動 `REN_P01 蓄勢劍路`**：每玩家階段蓮的首張真正命中且造成 Break 的 SP 額外 +2 Break，每階段最多一次。
- **終式**：終式・蒼天一閃，單體斬擊／Break；成功後耗竭。
- **故事／養成邊界**：主角初期只開劍士職能，以後才透過解鎖 Character Variant 切其他職能，不是開局選任意職業。

## 九條朱音｜Kujou Akane
- `character_id=akane`；`akane_burst_mage_v1`；職能 `BURST_MAGE`／`ARCANE`。
- **定位**：瞬發與完整詠唱取捨、高爆發魔法、Casting Disruption、中後段 Combo Finisher。
- **候選被動 `AKANE_P01 強詠決心`**：成功釋放 Full Chant SP 時，只對該張符合條件的魔法 HP 傷害 ×1.10；不強化 Break/Disruption、不默認作用在終式。
- **終式**：終式・紅蓮星墜，敵方全體輸出。
- **專精並非限制**：能持 U05 救同伴，但每次都需真實手牌、AP與自己 MP，會壓縮輸出資源。

## 白石紬｜Shiraishi Tsumugi
- `character_id=tsumugi`；`tsumugi_healer_v1`；職能 `HEALER`／`SUPPORT`。
- **定位**：高效率單體與全體回血、HP Barrier、Focus Ward、MP支援，還有攻擊技能 T09/T10。
- **候選被動 `TSUMUGI_P01`**：每玩家階段第一次合格治療 SP +60 治療量候選；紬用 U05 也可以受益，不限T系卡。
- **終式**：終式・白銀之誓，治療與團隊屏障；不復活 HP0。
- **專精差異**：其他角色會基本治療，但紬的專屬卡有更高治療量和支援效用。
