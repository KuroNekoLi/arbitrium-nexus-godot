# 戰鬥基本規則
> 文件定位：**現行戰鬥規則**。明示「候選」的角色內容及數值尚非正式平衡；規則生效狀態以 [總覽](README.md) 為準。

這是一款以**三人隊伍、各自技能牌組、共享行動點**為核心的回合制 RPG。玩家每次選一位可行動角色，使用不需抽牌的基本指令或自己手上的技能卡。三人並非各自擁有一輪 6 AP。

## 戰場組成
- 我方：初版三位角色；各有 HP、MP、牌組、手牌、戰鬥形態與終式。每場可以對戰單一 Boss。往後五人候補／主動換位仍是擴充議題，不是現在默認的玩家移動指令。
- 敵人：有 HP、防禦、弱點、可預告的攻擊意圖；特定敵人有 Break Gauge，法術另有 Casting Stability。
- 全隊資源：玩家階段 AP、敵方階段 RP。
- 個人卡區：每人自己的 draw／hand／discard／casting；不共享手牌。

## 玩家能做什麼？
| 操作 | 需要從手牌抽到？ | 概念 |
|---|---|---|
| 普通攻擊 | 不需要 | 物理攻擊；每人每玩家階段**首次**成功合法普通攻擊可按配置回復 MP |
| 主動 Guard | 不需要 | 玩家階段的防守命令；實際費用、效果仍須獨立內容定義 |
| 使用 Item | 不需要 | 需有道具、目標合法，候選有 AP 成本 |
| 使用技能卡 SP | **需要在該角色手牌** | 按卡片花 AP／MP，可能瞬發、詠唱、治療、援護或干擾 |
| Analyze | 不需要 | 全隊每場限2次的免費情報指令；情報 UI 與完整內容尚待實作 |
| 免費換牌 | 需持可棄卡 | 每角色每玩家階段至多1次，合法時棄1再抽1 |
| 終式 Last Spell | 不需要 | 獨立能力槽，每角每場一次；強制完整詠唱 |
| 敵方反應 Guard／Protect | 不需要 | 使用預留 RP；特殊反應技能才需要手牌 |

職能決定擅長什麼，不代表劍士不能治療：三人皆可**裝備並抽出**通用魔法攻擊、防護及治療卡。

## 四種容易搞混的狀態
**ACTIVE** 能依法行動；**CONCENTRATING** 正維持完整詠唱，禁止一般主動指令；**INCAPACITATED** 表示 HP=0，失去行動資格；**EXHAUSTED** 表示終式成功後的耗竭，戰鬥剩餘期間不能再發起動作，但不是 HP=0。完整行動效果與 UI 對照見 [終式與耗竭系統](終式與耗竭系統.md)。

## 怎麼贏？
完成合法行動與隨附事件後判斷。敵人全倒就勝利，即使我方同一結算也全倒；敵仍活而我方全失能時敗北。**所有人耗竭但仍有 HP、敵人未死**是待決終局邊界，不許引擎自動猜結局。
