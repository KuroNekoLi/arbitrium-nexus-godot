# 詠唱與魔法干擾系統
> 文件定位：**現行戰鬥規則**。明示「候選」的角色內容及數值尚非正式平衡；規則生效狀態以 [總覽](README.md) 為準。

## 同一張魔法卡的兩種施放方式
| | 破棄詠唱 Chantless | 完整詠唱 Full Chant |
|---|---|---|
| 速度 | 合法出牌後立即結算 | 通常延到下一個玩家階段規定的施放時點 |
| 威力 | 通常較低 | 通常較強 |
| MP | 同一張牌**預設兩模式同費** | 提交時一次扣 AP/MP，釋放時不重扣 |
| 角色 | 不進入 Concentrating | 維持 Concentrating，至多同時一個 |
| 卡區 | 結算後進 discard | hand→casting→依結果進 discard |

不是所有技能都有兩模式：瞬間防護與支援可能只有 INSTANT；**終式一定只能 Full Chant**。模式與威力由各張卡決定。

## 集中、穩定度與干擾
維持完整詠唱時，該角色不能再執行一般普攻、出技能、道具，也不能再開始第二次 Full Chant；只有明示 `CAST_COMPATIBLE` 的例外反應才有資格參與。隊友可以保護、治療或增加專注護符。

施法實例有自己的 `Casting Stability`；敵人可用 `Casting Disruption` 扣減，`Focus Ward` 先吸收這類干擾。一般法術穩定度歸零會中斷尚未完成的法術；這跟削減 Boss 本體的 Break Gauge 完全不同。

### Full Chant 中斷退款
只有被**合法 Casting Interrupt** 明確中斷的普通完整詠唱，才在中斷事件成立時部分退還 MP；退款比例（例如50%）是候選設定，**AP 不退、Overload 債務不取消**。施法者自己 HP 歸零而失能、目標消失、玩家取消等不可錯套同一退款。普通 Full Chant 沒有免費通用 Cancel。

## Boss 施法與資訊公平
Boss 法術公開施放意圖、目標類型、蓄力與可干擾條件；玩家必須有可理解的應對窗口。Spell Counter（已完成施法、尚待釋放時的反制）與 Casting Interrupt 是**不同機制**，目前 Counter 的完整牌卡與實際窗口仍未完成；不可把「可干擾」全部寫成 Counter。

## 終式例外
終式遭一般干擾走專用的失衡→延遲／削弱，而非普通法術「一次中斷即取消」。**唯一強制優先的例外：施術者在成功釋放前 HP=0，立刻取消尚未釋放的終式；費用與使用次數不退。**詳見 [終式](終式與耗竭系統.md)。

## BKC-01 與新 Break C 的交集（待實作設計）

Break 對 Boss **本體的失衡量表**生效，並可能取消一次普通行動／降級一次重大行動，建立 Exposed；Casting Disruption 對單一有效 `CastingInstance` 的 Stability 生效，且 `Focus Ward` 先吸收干擾。兩者**不可互算**。當同一法術在同個事件邊界同時受到 Break 和真正的 Casting Interrupt，必須由一個 Domain Action Resolution 決定唯一的取消／降級結果，不得反覆取消、免費移向下一行動或悄悄更換公開 Intent。候選優先序與測試 Gate 見 [ADR-BKC-01](adr/ADR_BKC_01_BREAK_C_20261020.md)。BKC-01 不更動普通 Full Chant 的部分 MP 退款、Last Spell 專用干擾規則。
