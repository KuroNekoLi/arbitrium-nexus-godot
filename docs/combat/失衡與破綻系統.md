# 失衡與破綻系統
> 文件定位：**現行戰鬥規則**。明示「候選」的角色內容及數值尚非正式平衡；規則生效狀態以 [總覽](README.md) 為準。

## 已確認的新方向：Break 簡化方案 C
**玩家把 Boss BreakGauge 削至零時**，Boss 的下一個合格且尚未開始的普通行動應取消、重大招式按預先公布的分支降級，**同時創造一次單份 Exposed**。Boss **不必自行**露出弱點，額外的核心開啟／特定行為暴露由 Boss Profile 自主決定。這是 2026-10-20 使用者批准的新版設計方向；實作驗收狀態及推薦防連鎖細則見 [BKC ADR](engineering/BKC_BREAK_C_ADR_20261020.md)。

## 兩種不同的「打斷」資源
**Boss Break Gauge** 是敵人本體的失衡值：透過有 Break 效果的技能扣減；在方案 C 下歸零後使下一次**符合條件、尚未開始**的普通行動取消、特殊大招按已公佈分支降級，並建立一次 Exposed，不能反向取消已經執行的攻擊。**Casting Stability** 是某一次施法的穩定度；受 Casting Disruption 攻擊，歸零可能打斷那一次法術。造成6 Break，不代表造成6 Disruption，更不代表造成6HP。

一張多 hit 的卡，**先完成整張技能必要效果**，再正式判定 Break 觸發；不可在第1 hit 就擅自停止後面合法的 hit。Boss 公開的 `Intent` 包含行動、目標範圍、執行時機、是否可反應或失衡；除非預告合法分支，不能偷換。

## 破綻 Exposed
Exposed 是由**Break 成功**或敵人定義的特定弱點條件、SP、姿態或事件建立的一次性戰術機會，**不是所有普通攻擊都能免費製造**，Analyze 也不等於自動上 Exposed。建立 Exposed 的那一張 SP **不能自己立刻吃掉自己的 Exposed**；後面另一張合法 SP 才能利用。成功利用後消耗；失手則按指定政策保留。有效期限由當前配置與規則定義，**現有 Exposed 不能直接疊層／無限刷新**。

例如 Boss 露出「祕紋核心開啟」姿態時，蓮的破勢斬或戰隙誘引可建立 Exposed；姿態不存在時，該專屬卡不會透過姿態直接製造破綻，**但仍可透過 Break 歸零創造 Exposed**。**Exposed 與 Combo Opportunity 是不同狀態**：依使用者 2026-10-17 明確更新，蓮的 R01/R07 命中可在核心未開放時建立攻擊連攜機會，但不因此建立 Exposed。

## 顯示與測試
HUD 至少明確區分 Break Gauge、Casting Stability、Focus Ward、Exposed 的剩餘有效時機與下一次Boss Intent。測試需含多 hit、錯誤目標、Break與施法同時發生、已公開意圖、下一次合格 Boss 行動 fallback 及固定 seed 回放。
