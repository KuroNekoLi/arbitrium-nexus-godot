## 特別留意

1. **角色槽位不是角色身分**。`party_order=["A","B","C"]` 是本場資料；從 roster 讀 `character_id`、`variant_id`、`name_key`、`appearance_path`、12 張 loadout、被動與終式。改名不代表新技能和翻譯已存在。
2. **M1～M5 不是舊八卡引擎**。已退役的 `scripts/domain/card_catalog.gd`、`deck_profile_store.gd`、`scripts/main.gd` 不存在，禁止用歷史 docs 當理由恢復。
3. `scenes/ui/hero_roster_item.tscn` 雖來自舊期 UI，但現被 `scripts/battle/ui/components/party_status_panel.gd` preload；其 P4 legacy-named regression 實際在測現行 HUD 元件，故不刪。
4. 本次沒有更動引擎規則：仍須區分 **失能 HP0 留場**與 **耗竭 UI 退場**；目前 Domain 的耗竭者仍可被鎖定（按既有規則），五人後備替補／AP 換位／VC 尚未落實。
5. `BALANCE_PROVISIONAL` 及 `CONTENT_PROVISIONAL` 數字只屬 Lv40 Demo；截圖、Headless、Replay 與真人可玩驗收不是同一種證據。
