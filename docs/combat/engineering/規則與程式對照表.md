## 特別留意

1. A/B/C 是戰鬥槽位，不是固定角色身分；roster 指向 `CharacterDefinition`，由角色定義提供身分、Variant、名稱、外觀路徑、能力、12 張牌、被動與終式，卡牌資格另由 eligibility JSON 驗證。
2. M1～M5 是現行引擎，不是舊八卡原型。`hero_roster_item.tscn` 雖來自舊期，仍是現行 HUD 共用元件；其名稱含 `legacy` 的測試必須保留。
3. HP0 失能者留場；成功施放終式而耗竭者真正退場，新配置下不再可受擊、治療、復活、Buff 或 Protect。Boss 存活且我方無存活在場者判 DEFEAT；敵全滅優先 VICTORY。舊錄影內嵌配置保留歷史語義。
4. `BALANCE_PROVISIONAL`、`CONTENT_PROVISIONAL` 數字只屬 Lv40 Demo；Headless、截圖、Replay 與真人試玩是不同證據。
