### 工程驗收規則

- 每項功能以 **RuleID → Domain 命令／事件 → 拒絕負例 → Replay → UI 投影與雙語 → CI** 串起來。
- 快速迭代先跑 `CI Fast`、`CI Integration`、`CI P4 UI Contracts`，畫面變動時跑 `CI Visual`；`CI Full` 仍是 nightly／release／明確手動驗收。
- 只有真實測試輸出才能標註 VERIFIED；規格、候選內容和歷史成功紀錄均不能取代新提交的驗證。
