# 終式與耗竭系統
> 文件定位：**現行戰鬥規則**。明示「候選」的角色內容及數值尚非正式平衡；規則生效狀態以 [總覽](README.md) 為準。

## 終式（Last Spell）的承諾
每個解鎖的 Character Variant 有自己的**獨立終式欄位**，不佔12張普通技能卡、不需要抽到；每角色每場最多**啟動一次**，只能完整詠唱。正式提交前 UI 要顯示所需 AP/MP、預期施法時間、受干擾可能延遲或削弱、成功後不可再動，並允許確認前取消。

提交後立即付 AP/MP、標記本場額度已用，進入 Concentrating；**沒有玩家可主動中途取消**的通用按鈕。

## 專屬狀態流程
```text
UNUSED → CASTING ──合法普通干擾──→ DESTABILIZED（延遲／削弱，候選係數）
              \                         /
               \                       /
                → 合法釋放 RESOLVED → EXHAUSTED
                  （施法前HP=0則不能到此）
CASTING／DESTABILIZED ──施法者釋放前HP=0──→ INVALIDATED
```
- **干擾≠直接消失**：終式受一般魔法干擾遵守自身失衡／延遲／削弱流程，非普通 Full Chant 的中斷退款。
- **HP0強制失效**：施法者釋放前歸零，立即 `LastSpellInvalidated(CASTER_INCAPACITATED)` 並取消預定效果。**不退 AP、MP、Overload；不返每戰一次額度**；日後復活也不恢復該次終式。
- **成功後耗竭**：一旦合法釋放成功，效果不因後續HP下降而回溯取消，施法者進入 `EXHAUSTED`，本戰不能新出牌、普攻、道具、Reaction或Combo。

## 失能與耗竭要有不同的演出
**INCAPACITATED（失能）**：HP變0，角色仍在戰場的展示位置，卡片／CG改成失能狀態，卡區凍結。**EXHAUSTED（耗竭）**：終式後角色退出可操作戰鬥位置，角色欄可灰階／打叉，明確寫「耗竭／本戰不能行動」，不是把HP改0。這是新版**UI呈現方向**。
