# 傷害與異常狀態系統
> 文件定位：**現行戰鬥規則**。明示「候選」的角色內容及數值尚非正式平衡；規則生效狀態以 [總覽](README.md) 為準。

## 每一下傷害如何算？
先驗合法性與資源 → 若有 Protect 先重新指定承受者 → 需要時判命中 → 適用時判暴擊 → 按物理／魔法攻擊、防禦、敵人逐個元素弱點／抗性算原始 HP 傷害 → Guard 減傷 → HP Barrier 吸傷 → 最終扣 HP → 處理附加狀態、Break／Exposed 等合法時點。

普通機率命中採百分比方向，一般值限制在5–95%；不是 d20 也不是 Nat1/Nat20。具體 BaseHit、能力係數、元素倍率、暴擊與浮動皆為**版本化平衡候選**，特殊必中或不可暴擊要由技能標註。核准工程預設最終傷害 `floor(max(0,final_unrounded_damage))`，最低可能是0，**不能私自保底1**。數值處理順序要能用事件重播與解釋。

## HP、Barrier、Focus Ward
- **HP**：角色生命；超過上限的普通治療無法變成護盾，0 HP 立即失能。
- **HP Barrier**：吸收適用的 HP 傷害，有獨立到期／覆寫／疊層政策；不抵擋直接施法穩定度干擾。
- **Focus Ward**：指定有效施法實例的干擾保護，只吸收 Casting Disruption；不是普通 HP Barrier。

## HP=0 與普通治療
HP 歸零當場 `INCAPACITATED`；角色失去主動操作及反應，原有卡區凍結，普通敵方單體不能再選他，除非明示特殊目標資格。**沒有 Revive 標記的普通治療不能把HP0角色救起**。就算有治療卡，目標資格不合格也不能先扣 MP 然後讓治療量變零。普通 Full Chant 未釋放時因施法者 HP0 失效，不視為 Magic Interrupt MP 退款。

## 異常狀態
每種 DoT／HoT／Buff／Debuff 必須明示：`tick_trigger`、`expires_at`、`stacks`、`stack_policy`、`priority`、`dispel_tags`。同一時點依優先度、穩定 instance ID 排序；不會全員每輪隱形扣一樣的血。候選「紅蓮餘燼」有兩次 Enemy Phase 結束各45 HP的 SCORCH_TEST，**這是該卡個別候選值**，非 DoT 全域公式。不同狀態要分別處理命中時套用、傷害後觸發、失能/解除及事件順序。

## 展示規則
UI 顯示預估、血條、Barriers、狀態、失能等，但**HP扣除與結算只有Domain有權做**；動畫快慢不改RNG或傷害。
