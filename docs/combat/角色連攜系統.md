# 角色連攜系統
> 文件定位：**現行戰鬥規則**。明示「候選」的角色內容及數值尚非正式平衡；規則生效狀態以 [總覽](README.md) 為準。

## Combo 是兩個人的合作，不是免費多打一張
前一位角色用真實 SP 達成 **Setup**，引擎建立 `ComboOpportunity`；**另一名不同角色**真正持牌、合法付費且執行符合條件的 Finisher，才會觸發連攜效果。第二張卡需要正常支付自身 AP/MP；Combo Bonus **額外 AP = 0**。不允許同一人出兩張冒充雙人連攜，也不能讓第一張自己產生／消耗自己的 Exposed。

```text
NONE → OFFERED（setup結算） → READY（存在合法搭檔／卡／目標）
                                      ↓
                               CONSUMED／EXPIRED
```
機會附帶 setup 來源角色、目標、允許的搭檔/技能 tag、到期點、已消耗標記和事件 ID。機會過期、目標失效、搭檔倒地或無可用牌時就不能觸發。

## 三種連攜方向
- **攻擊 OFFENSE**：一人製造弱點／破綻，另一人追擊，可能強化 HP 傷害、Break。
- **防禦 DEFENSE**：一人真正施放支援 SP，另一人再施放合法防護 SP；普通 Protect 按鍵不會冒充技能卡。
- **詠唱 CASTING**：一人建立完整詠唱實例，另一人透過 Focus Ward／強化效果護持；**不因此把完整詠唱立即結算**。
