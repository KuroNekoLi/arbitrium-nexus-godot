# 卡牌圖鑑｜全部通用與角色技能

> **本圖鑑是可供 Agent 實作的「最新候選內容」，不代表最終角色強度和平衡數值已核准。** 已確認的是：三人每人配置**恰好12張SP**、開手4、每階段不足4補至4、手上最多8、通用基礎攻擊／治療／防護魔法三人都能裝備。圖鑑包含**31種普通卡片定義**（5通用＋8蓮＋8朱音＋10紬），外加[另頁的3種終式](終式技能圖鑑.md)。持有同一卡定義的不同角色仍各有自己的 `CardInstanceID`。

## 如何閱讀卡表？
「AP」由三人共享的當期 AP 池支付，「MP」由出卡者個別支付。「RP」只在**合法 Enemy Reaction Window**使用，且**該反應SP必須已在該角手牌**。DUAL是同一卡兩種施法：破棄詠唱瞬間發動、完整詠唱延後發動；預設兩模式MP相同。倍率是PAtk/MAtk的技能倍率，實際傷害還會經過命中、防禦、抗性、Guard、Barrier、最終取整。普通治療不帶Revive就**不能復活HP0角色**。

## Agent資料與驗證注意
每張卡定義 `card_id/name_key/description_key/eligibility/type/cost/targeting/casting_modes/effects`；技能實例另有 `card_instance_id/owner_id/zone`，不可複製。事件記錄支付、命中、效果與移區順序，seed replay 必須確定性。所有 zh-TW/en 名稱取 i18n，不以顯示文字當邏輯鍵。**不要直接相信這張圖鑑每個候選技能都已接進Godot：**當前 `lv40_content.gd` 僅建立 Starter 24種 SP 定義；剩餘R04/A08/T02/T07/T08仍需獨立驗證與實作，詳見[規則與程式對照表](engineering/規則與程式對照表.md)。
