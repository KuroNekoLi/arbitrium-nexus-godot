## 1. Phase 2 傷害／命中／暴擊（P2-D01～D07）

| 決議 | APPROVED（使用者核准的契約） | 未定 / 註記 |
|---|---|---|
| **P2-D01** | **混合型分類命中**：普通攻擊及部分 SP 採隨機命中；魔法由技能定義；重要完整詠唱、連攜及魔法打斷優先採條件／可預測判定。Combo 本身不增加無理由的獨立命中骰，相關前置 SP 仍須依自身規則命中。 | 技能命中模式清單及詳細適用性仍待實作設計。 |
| **P2-D02** | 一般隨機命中用**百分比制**，非 d20；Accuracy/Evasion 可受屬性、裝備、技能影響；採可重播 seeded RNG、預覽最終命中率。 | 不得引用原 d20/Nat1/Nat20 為現行規則。 |
| **P2-D03** | 一般隨機命中率下限 **5%**、上限 **95%**；明文特殊效果可覆寫為 0%／100%。必中仍受合法目標、免疫等條件限制。 | 特殊效果優先級細節待定。 |
| **P2-D04** | Accuracy/Evasion 為**獨立數值屬性，採線性差值轉換成命中率**；非線性模型僅保留日後平衡候選。 | 候選：`clamp(BaseHit + k*(Accuracy-Evasion), 5%, 95%)`；`BaseHit`、`k` 非核准數字。 |
| **P2-D05** | **混合型 HP 傷害公式結構**：`(Attack * SkillMultiplier + FlatBonus) * K/(K+Defense)`；物理攻防與魔法攻防分開；不同 SP 可有不同倍率與平加。 | `K`、係數、元素、結算順序、取整未定。Casting Stability/Break 不直接使用 HP 傷害公式。 |
| **P2-D06** | 一般 HP 傷害具有**小幅隨機浮動**，命中與浮動分開判定，使用 seeded RNG。 | **±5% 為 PROVISIONAL**，非鎖定正式值；不自動套至 Casting Disruption / Break 傷害；取整未定。 |
| **P2-D07** | **混合型暴擊**：角色有 Critical Rate、Critical Damage；符合資格的普通攻擊命中後可隨機暴擊；SP 可調整暴擊率或在明文條件下保證暴擊；魔法是否可暴擊由技能定義；保證暴擊≠必中。 | 暴擊率上下限、倍率、修正、結算順序及多段判定尚未於 D08 核准。 |

### P2-D07 的防止跨系統溢出規則
一般暴擊只作用於明文具有暴擊資格的 **HP 傷害**；不自動提高 Break Gauge 傷害或 Casting Disruption，不自動觸發 Exposed／Combo，不產生免費 AP/RP。帶「利用 Exposed 時保證暴擊」的技能若 Miss，沒有暴擊也不消耗 Exposed。以上不禁止未來**明文卡牌效果**的其他收益，但必須另外核准，不得直接推定。

## 2. 敵人情報與獨立解析（P2-S02～S08）

| 決議 | APPROVED |
|---|---|
| **P2-S02** | Analyze（解析）是**獨立戰鬥能力**，不屬於 SP、不需抽牌、不占每人 12 張牌組。Enemy Intel 免費查看已取得的情報。主動解析只取得情報，不直接創造 Exposed 或 Break；弱點標記／破甲／詠唱干擾等改變戰場局勢的是 SP。 |
| **P2-S03** | 主動解析 **0 AP、0 MP**，每場使用次數有限；不靠新的 Analysis Charge。 |
| **P2-S04** | 玩家**自行選擇情報類別**再解析，不隨機、不由 AI 擅自決定。候選四類：元素／防禦／行動／特殊弱點；分類名稱／細目仍可整併。已完全掌握的類別不能白耗次數。 |
| **P2-S05** | 已發現敵人知識**永久保存**；HP、施法、Exposed、Break 等即時狀態每場按規則重新計算；敵人變體可有不同情報，不以固定數字快照誤導。 |
| **P2-S06** | 全隊**每場共用 2 次**主動解析，下一場重置；未用完不累積。 |
| **P2-S07** | Analyze 可以在 **Player Phase** 及合法 **Reaction Window**（反應佇列確認前）使用；**0 RP**，也不算角色的 Reaction 次數。不能在行動效果結算中途插入，不能重開窗口、不能改寫已提交敵方行動。 |
| **P2-S08** | 所有隊伍能解析；分析型角色可以透過被動能力取得額外**情報效率優勢**；不自動增加共用 2 次配額。 |

## 3. 分析型角色被動觀察與資訊呈現（P2-S09～S12）

| 決議 | APPROVED |
|---|---|
| **P2-S09** | 分析型角色專長選**Passive Observation（被動觀察）**，不用 SP、不耗 AP/MP/RP、不占兩次 Analyze；自動獲得符合條件的未知情報。未核准其因已知情報獲得額外增傷、Break 等戰術被動。 |
| **P2-S10** | **事件驅動**：敵人出現指定行動、姿態、命中反應等證據，才解鎖對應情報；不使用累積回合數作通用觸發。 |
| **P2-S11** | **證據充分即刻解鎖**；若在開啟 Reaction Window 前證據成立，先結算被動觀察、更新 Enemy Intel，再開窗口，讓玩家可以當次使用。不可提前揭示尚未發生的實際結果。 |
| **P2-S12** | Enemy Intel 預設**簡短描述＋標籤**，玩家可展開精確數值；只展開已解鎖情報。UI 需與引擎相同資料來源；Boss Intent 必要防禦決策資訊（例如目標、Protect 合法性）**不要求解析才能看**。 |

## 4. Exposed 核心定位（P2-S13、S17～S24）

| 決議 | APPROVED |
|---|---|
| **P2-S13** | Exposed 是**獨立於 Break 的短暫戰術破綻**；由敵人弱點／特定行為／明文卡牌條件觸發；不必先 Analyze；不是所有敵人都必須有；不自動提供全體或全傷害增益。 |
| **P2-S17** | **每次只提供 1 個利用機會，具有期限**。在 Player Phase 觸發：可當下利用，**至觸發後的下一個 Player Phase 結束**失效；在 Enemy Phase 觸發：至隨後下一個 Player Phase 結束失效。不得因玩家尚未抽到合格 SP 而無限延期。初版 Exposed 不疊加。 |
| **P2-S18** | 利用獎勵由**實際利用的合格 SP 自行定義**：可為 HP 傷害、額外 Break、符合時序的詠唱干擾、合乎既有規則的 Combo Opportunity 等。Exposed 不直接發 AP/RP、不自動啟動 Combo。 |
| **P2-S19** | **成功利用才消耗**：需命中或達成 SP 明文指定的有效利用條件。Miss、未達條件、目標失效不消耗；嘗試失敗仍按一般卡規付費，不延長期限。 |
| **P2-S20** | **以整張 SP 作為一次利用單位**，而非每段攻擊分別消耗；多段 SP 的加成作用範圍、有效命中門檻由卡牌明定。所有段 Miss 不消耗。 |
| **P2-S21** | 新的 Exposed 必須有**敵人專屬合法觸發條件**；同一事件不得重複觸發，已消耗或失效後須重新符合條件；無全域每回合硬上限。 |
| **P2-S22** | 目標**已持有 Exposed** 時，新的 Exposed 觸發**忽略**：不新增、不刷新、不替換；觸發 SP 其他正常效果仍結算。 |
| **P2-S23** | **同一張 SP 不可觸發並立即利用自己創造的 Exposed**；必須由後續**另一張 SP** 利用，允許同角色後續出牌；Combo 仍須不同角色，不能混為一談。多段同張 SP 的後段也不能消耗本張新建機會。 |
| **P2-S24** | **Exposed 與 Break 可獨立共存**、互不清除、不自動追加組合傷害；保留各自已核准的有效期限與判定方式。 |

> **P2-S14 是討論過但未核准的舊問法，已由 P2-S17 的正式決策取代。P2-S01 曾提供方案，但未由使用者單獨核准。** 不得錯標為 APPROVED。

## 5. 魔法反制與詠唱打斷的分工（P2-S15～S16）

| 決議 | APPROVED |
|---|---|
| **P2-S15** | **Casting Interrupt / Spell Interrupt** 是施法完成前削減 Casting Stability；**Spell Counter** 是施法完成但魔法效果尚未結算前，在**合法 Reaction Window** 使用符合條件的 Reaction SP 取消該效果；**Guard/Protect/Barrier/Dampening** 則是合法情境下的減害手段。Spell Counter 不用 Casting Stability 判定、不能回溯取消已結算魔法。遵守既有 1 actor/窗口 1 Reaction、共享 RP、MP、佇列排序與後續失效跳過規則。 |
| **P2-S16** | **成功 Spell Counter 的基本回報只有取消符合條件的魔法**；不自動造成 Break／Exposed。特定卡牌或 Boss 明文效果才可以提供額外 Break、Exposed 等獎勵。RP/MP 費用、可取消招式分類、失敗處理未定。 |

> Phase 1 的 Protect 只攔截可保護的**單體物理／魔法攻擊及命中附帶詠唱干擾**；直接指向 `casting_id` 的獨立詠唱干擾不受基本 Protect 攔截。AoE／真多目標不可基本 Protect。

## 6. Break 的觸發／行動降級／恢復（P2-S25～S31）

| 決議 | APPROVED |
|---|---|
| **P2-S25** | **整張 SP 完整結算後**才正式觸發 Break（Gauge 可在中途達 0，標記 Pending）；同卡後段不因中途歸零而享有新的 Break 效果。死亡、中斷、失效等仍由專屬事件規則處理，不能硬逼無效目標承傷。 |
| **P2-S26** | Break 的主要獎勵是**削弱／限制 Boss 下一次行動**，不保證跳過完整 Enemy Phase，不自動取消正在詠唱的魔法，也不自動降低防禦（此點尚待定）。 |
| **P2-S27** | 具體採**行動降級**：下一次合格 Boss 行動替換成事前定義、可預測、明確顯示的 `BreakFallbackAction`，不直接跳過。Boss Intent 必須說明合法替代；不能在玩家已確認 Reaction 後偷偷改招。 |
| **P2-S28** | Break **不影響已經開始的施法**；它只降級**下一個**符合條件的 Boss 行動。玩家應使用詠唱打斷、施法完成後的 Spell Counter 或防禦處理當前施法。 |
| **P2-S29** | 降級權益**保留到 Boss 下一次合格戰鬥行動**，非固定 1 回合失效；階段轉換、演出等不算合格行動，不消耗。一次 Break 只降級一次。 |
| **P2-S30** | Break 正式觸發後 **Gauge 鎖定**，鎖定期間額外 Break 傷害不累積、不預存；降級行動結束後 Gauge 回到最大值、解鎖，開始下一輪。最初「必須完成」字義由 S31 精確修正。 |
| **P2-S31** | **已正式開始的 BreakFallbackAction** 不論完整成功、被 Spell Counter 取消、合法中斷，都在**行動結束**時消耗降級權益、恢復滿 Gauge、解除鎖定。若根本沒有開始合格行動，繼續鎖定；戰鬥結束清除。 |

### 非魔法與特殊時序不得遺失
- 只在**合法行動決策邊界**套用 Break Fallback，不修改已提交、已開始施放、已鎖定反應佇列的敵方動作。
- 已確認的敵方 Intent 與 Reaction 必須遵守 Phase 1 的 Guard／Protect／RP 與確認序列語義。
- P2-S25 的整卡 Break 結算邊界與 P2-S20 的整卡 Exposed 利用單位相容；下一張 SP 才使用新增 Break 狀態。
