# 卡牌與抽牌系統
> 文件定位：**現行戰鬥規則**。明示「候選」的角色內容及數值尚非正式平衡；規則生效狀態以 [總覽](README.md) 為準。

## 最重要的四個數字
| 欄位 | 現行規則 |
|---|---|
| 每人出戰牌組 | **恰好12張 SP 卡片實例** |
| 戰鬥開局手牌 | **4張** |
| 每玩家階段正常補牌 | **不足4才補到4** |
| 手牌硬上限 | **8張** |

**12張是「整副牌組大小」，8張是「同時能拿在手上的最多張數」**，兩者並不衝突。若階段開始手牌5張，就保留5張且不抽；手牌3張則補1張；手牌上限8不是每次都抽到8。

## 各人分開管理
`draw` 為尚未抽的牌、`hand` 為可選技能、`discard` 為使用／棄掉的牌、`casting` 是正在完整詠唱的卡。即時技能完成進棄牌；完整詠唱期間卡留在施法區，到正式完成或合法中斷才依該卡規則移動。抽牌堆空時可以把可重洗的棄牌按固定 seed 洗回，但**不複製卡片實例**。

`CardDefinitionID`（如 U05）可以由不同角色各裝一張；`CardInstanceID` 是某張真正存在的牌，任何時點只能在一個區域。卡片歸屬與合法裝備資格都要先驗證。

## 每人每階段一次免費換牌
在玩家階段，合法可行動角色可不花 AP／MP，把**手中的1張牌先棄再抽1張**：
1. 先檢查除原卡實例外有沒有合法替代牌。沒有則不執行、不浪費當次額度。
2. 有則暫時隔離棄卡，觸發正式棄牌事件與其效果，再從當前合法池抽牌；**這次不能把剛棄的同一個 CardInstance 抽回**。
3. 若棄牌事件意外改變牌庫而抽不到卡，記錄 `CardDrawFailed(POOL_CHANGED)`；已發生的棄牌不回滾，當次換牌額度消耗。可抽到同名的**另一個實例**。

被打至 HP0 的角色保留但凍結原有卡區，停止補牌、主動換牌及出牌。完整詠唱與耗竭角色的移區/補牌必須走 Domain 合法性，不因 UI 強制加動作。

## 裝牌規則
可混搭 UNIVERSAL 通用卡、符合職能標籤卡、角色專屬卡、Variant專屬卡。缺牌、資格不符、卡不存在則 `ValidateLoadout` 失敗，不能偷偷塞空白牌。目前**沒有已核准的全域同名卡最多2張、稀有度或職能比例上限**。終式、普通攻擊、Guard、Protect、Analyze 都不在12張中。
