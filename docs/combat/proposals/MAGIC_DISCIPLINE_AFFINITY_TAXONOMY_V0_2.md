## 1. 使用者確認的核心方向（2026-10-19）

> **魔法的理論體系可以完整且複雜；實戰呈現應盡可能參考其他卡牌／策略遊戲，保持簡單易懂。**

具體設計原則：

1. **一張卡一個主要目的。** 可以有明示的次要效果，但不能因高階學科而塞入大量不易閱讀的例外規則。
2. **魔法學科不自動賦予特殊效果。** 火焰學科不代表每張火卡都燃燒；時間不代表跳回合；因果律不代表逆轉已結算事件。
3. **優先重用既有機制。** 在合法範圍內複用 `DAMAGE`、`BARRIER`、`HEAL`、`STATUS`、`CASTING_DISRUPTION`、`BREAK`、`COMBO` 與合法條件觸發；不必為每種學科獨立開發一套 Domain。
4. **卡牌正文簡明；深入的學理、複合術式與世界觀放在圖鑑與進階說明。** 玩家不必理解分類學才能出牌。
5. **只有帶來新決策的機制才值得增加。** 若已有機制能表達，先用原有機制。任何新機制仍需獨立 ADR、QA 與使用者核准。

六大實戰效果閱讀群（候選 UI 分組，不是 Domain enum）：**傷害、防護、治療、強化／弱化、干擾、延遲／條件效果、戰術支援**；後續可以按體驗測試調整分類數量。Break、Reaction、Last Spell、Full Chant、Casting Stability 等已有獨立規格，不能因「簡化」而被合併抹除。

## 2. 三層架構（方向已確認）

| 層 | 主要問題 | 玩家可見程度 | 資料影響 |
|---|---|---|---|
| 世界觀／學科 | 魔法操縱什麼？ | 角色背景、圖鑑、術式研究 | 24 學科為候選分類；可複合學科 |
| 既有 Domain 機制 | 這招做了什麼？ | 清楚的標籤與回饋 | 只使用已核准的傷害、治療、護盾、異常、干擾、事件 |
| 玩家卡牌與操作 | 現在打這張卡會怎樣？ | 最優先：目標、AP/MP、詠唱模式、主要效果與限制 | 不額外改動事件順序、合法性或支付規則 |

### 與 Affinity 的關係

沿用 v0.1 「學科、傷害共鳴、效果」各自獨立的研究方向。具體共鳴屬性仍為候選；不設全域固定剋屬性表，保留現行逐敵人弱點／抗性規則。 `ARCANUM` 是候選「純魔力結構與符文術式」學科，既有 `ARCANE` 戰鬥標籤與效果不變。

## 3. 24 學科／7 學派群（**分類提案，非逐項核准**）

基於 v0.1 的 18 學科，保留六個擴充候選：

| 7 個學派群 | 學科（候選） | 數量 |
|---|---|---:|
| 物質與自然 | 炎熱、水流、寒霜、風氣、地脈、雷電 | 6 |
| 光與影 | 光輝、幽影 | 2 |
| 生命與靈魂 | 生命、靈魂 | 2 |
| 時空法則 | 時間、空間、因果律 | 3 |
| 心智與感知 | 認知、感覺、情緒、夢境 | 4 |
| 構造與規約 | 奧術、契約、秩序 | 3 |
| 形上與可能性 | 命運、虛無、存在、混沌 | 4 |
| **合計** | | **24** |

邊界：
- 夢境（內在體驗／潛意識）≠ 感覺（感官輸入）≠ 認知（解讀、推理、記憶）。
- 命運（未來可能結果的傾向）≠ 因果（條件與結果的依賴）≠ 時間（順序、持續）≠ 混沌（變化與不可預測）。
- 虛無（消散／缺席／抹除）≠ 幽影（遮蔽／暗度）≠ 存在（身份／性質／本體狀態）。
- 秩序（規律／穩定）≠ 契約（約定／交換／約束）≠ 奧術（魔力結構與符文）。

所有形上能力一律受現行戰鬥合法性與 Replay 邊界制約：**不倒轉既有事件、不偷偷修改 RNG、不取消已結算支付、不繞過失能／耗竭／Revive 規則、不憑空創造棋盤位移。**

## 4. 同一個哲學，簡單的戰場卡牌文字

下列僅作 UX / 機制示例，**不是新增正式 SP**：

| 學科 | 候選卡片 | 玩家第一眼該看到的主效果 | 背後需要重用的概念 |
|---|---|---|---|
| 火焰 | 焰痕 | 「對一名敵人造成傷害。」 | 原有 HP 傷害 |
| 空間 | 界域屏障 | 「給一名隊友護盾。」 | HP Barrier |
| 時間 | 刻之延續 | 「延長一項可延長的強化效果。」 | 既有 Status 到期機制；需 ADR 才實裝 |
| 因果律 | 應果之印 | 「下次合法命中時，獲得護盾。」 | 顯式預約條件觸發；需 ADR 才實裝 |
| 夢境 | 夢幻之幕 | 「為一名隊友提供防護。」 | 既有護盾或已核准 Status |
| 認知 | 明晰 | 「強化下一次合法的情報行動。」 | Analyze 限額／權限不變；需 ADR 才實裝 |

UI 必須顯示實際合法目標、確定成本與效果；不使用含糊「可能操縱命運」作為實際效果敘述。若一張卡的說明需要長篇描述觸發順序，先評估能否簡化或拆卡。

## 5. 參考遊戲的設計方法（參考結構而非複製效果）

- **Slay the Spire**：一眼可讀的攻擊、防禦與狀態卡；策略難度主要來自卡組和順序的組合。
- **Monster Train**：由少量可重複使用的效果及大量卡片／升級組合產生深度，不要求每卡有新引擎。
- **Into the Breach**：使用公開意圖引導防禦與反制選擇。本專案應繼續尊重合法公示的 Boss Intent。
- **Clair Obscur: Expedition 33**：元素弱點可協助技能選擇，但不代表需要全域固定相剋環。

以上是**高層設計借鏡**，並非主張這些遊戲的實際卡牌公式或資訊揭露細節與本專案完全相同。

- **一句話核心身份**；
- **一個可用現有機制表達的基礎卡範例**；
