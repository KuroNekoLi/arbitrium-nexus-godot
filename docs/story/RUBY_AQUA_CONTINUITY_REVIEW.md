# Ruby／Aqua 劇情邏輯檢查與待決問題

> **作者內部／重大劇透**。供編劇、世界觀、戰鬥、CG、美術和 AI Agent 在實作前檢查；不增設玩法。

## 1. 為何「必須變成 Ruby」能說服玩家？

**不是客觀上 Aqua 必須消失。**角色主觀感到非如此不可，劇本必須依時間逐漸建立這個判斷，而不能只用一句「太傷心了」帶過。

| 層次 | 事件中的可見證據 | 她的主觀誤解 | 後期劇情的回應 |
|---|---|---|---|
| 存活者自責 | Aqua 帶孩子們離開、Ruby 留守 | 「是我決定丟下 Ruby。」 | 沒有已證明的兩全辦法；她作了救人所需的選擇 |
| 價值錯置 | Ruby 曾帶給身邊的人希望、也是唯一繼承人 | 「她的生命比我的有價值。」 | Aqua 原本的生命與孩子們的存活同樣有價值 |
| 第一個模仿契機 | 模仿聲音曾短暫安慰倖存孩子 | 「Aqua 不能帶來希望，Ruby 才可以。」 | 那份安慰出自 Aqua 的善意與能力，並非她必須自我抹除 |
| 乾爹乾媽失女的悲傷 | Aqua 自幼就把 Ruby 的父母當作家人；父母難以接受唯一女兒離世 | 「若停止扮演，我又要讓他們失去 Ruby 一次。」 | 父母必須承認 Ruby 已逝，並讓 Aqua 知道她不須藉自我抹除換取家人的愛 |
| 家族的共犯沉默 | **正式確認**只有 Aqua 與真正 Ruby 雙親知情，其他所有人均不知；雙親默認繼承身份繼續 | 「連家人也希望 Ruby 活著而不是我。」 | 即使悲傷與欺瞞有因果，也必須承認其倫理後果；不能用親情完全免責 |
| 漸進的生活慣性 | 新的校籍、朋友、承諾都以 Ruby 名字形成 | 「承認 Aqua 就會毀掉全部。」 | 承認過去不必放棄現在的名字與女性認同 |

**劇作的兩個必答問題：**（1）當初她第一次使用 Ruby 外貌時，是想救誰、安慰誰，還是想安慰自己？（2）家族何時從單純容忍跨越成主動維持對外謊言？本文選擇「第一次聲音安慰倖存者」作為候選錨點；仍待創作者核准。

## 2. 親情新決策與「只有雙親知道」的相容性

**CONFIRMED：**真正 Ruby 的父親、母親分別是 Aqua 親近的乾爹、乾媽；父母失女後長時間無法接受事實。Aqua 曾是他們深愛的乾親孩子，不是事故後才為了繼承權收養的工具。

**CONFIRMED：**除 Aqua 本人外，知道她正以 Ruby 身份生活的人**只有原 Ruby 的父母二人**；家族其他成員、理事、管家、心腹與外人一律不知。若父親或母親兼任家主，可另外決定其職位，但不能自行多加第三名知情者。

1. 因為已確定只有雙親知情，後續仍必須提出**合法文件與實際死亡事實**如何被保密的合理流程；認知魔法能影響識別與感官，不應瞬間替代醫師的死亡證明、現場證人與所有既有文件。
2. **Aqua 本人的原生家庭／監護人**尚未設定；有乾爹乾媽不能推出她是孤兒。若 Aqua 親生父母仍健在，必須解釋他們如何看待孩子從公眾生活中消失；不可不經核准宣稱他們同意。
3. **Ruby 的父母知道是 Aqua**，仍可能本能叫出 Ruby 的名字：這不是毫無辨別能力，也不是認知魔法讓父母完全失憶，而是清醒與悲傷互相拉扯。
4. **家庭倫理**：父母即使無意施壓，也會在 Aqua 身上造成「你一定要讓我們繼續看見 Ruby」的壓力。後期若要修復關係，他們必須承認自己也傷害了 Aqua，而不只是讓 Aqua 自行釋懷。
5. **事故的世界觀真相**可以與異形／The Fading 關聯，但父母知情不等於父母是事故肇事者或掌握世界終極真相；責任調查與身份掩蓋應分離。

## 3. 國中事故的具體物理／魔法邏輯

1. 事故**發生在星煌魔法學院入學以前**；星見天文塔是**家族私人研究設施的暫名**，不是學院校區。
2. 觀測核心異常與異形入侵同時發生，**未核准彼此真正因果**；不能先宣稱是 The Fading 直接創造異形。
3. 只有 Ruby 有能力在當下安全操作特定備援結界；只有 Aqua 能及時清理、護衛、帶孩子撤離。兩人並非無謂輪流犧牲。
4. 救援目標、路線、剩餘時間與異形攻擊的順序須在劇情分鏡中可被玩家理解，**不要靠看不見的突然規則逼角色死去**。
5. Ruby 當時**相信有機會生還**，不應被寫成有預知能力或必定赴死。
6. Aqua 無責任；真正責任可能是不可預測的事故、已知隱患遭隱瞞或蓄意破壞，選項 A/B/C 都未獲核准。
7. 禁止讓 Aqua 的認知能力既能完美修改外形、又能任意修復崩塌的世界狀態；研究學科有區別。
8. 官方事故資料如何確認 Ruby 「倖存」、Aqua 「失蹤」、遇難者身份如何處理，還需要明確的證據與制度方案；**不能偷渡驗屍紀錄全被認知魔法改寫**。

## 5. 為何認知術如此強，仍能保留懸念？

- 人的**直覺與感官**幾乎無法看破，不表示舊物證、家族經濟紀錄、失蹤檔案、劍鞘掛飾等全數不存在。
- **昏迷不解除**，所以失能演出不能當作廉價的揭穿方法。
- 一般人沒有理由懷疑，也不會把好端端的同學天天當作犯罪嫌疑人檢查。
- 真正能逼近秘密的應是**時間軸矛盾、關係、證據與少數知情者的選擇**，不是比魔力值大小的偵測鏡。
- 沒有正式核准的破解技術、時間上限與反制代價，不能由關卡或 AI 自行發明。

## 6. Fading 與異形：四層揭露，不搶跑世界觀真相

| 層次 | 可說的話 | 不可說的話 |
|---|---|---|
| 入學初期的官方公開版 | 多年前某研究設施出現異形、魔法結界失常；傷亡紀錄有保密部分 | 「The Fading 就是兇手。」 |
| 支線調查 | 記錄中有跨裝置時間異常、資料空白、術式不穩定 | 「所以異形一定由高耗魔造成。」 |
| 研究者假說 | 一些研究者懷疑與被稱為 The Fading 的未知現象有關 | 「已證實所有異形源於世界熵增。」 |
| 後期確認（需另核准） | 由玩家所見證據確立具體因果與責任 | 不靠作者口述直接將候選冒充正史 |

角色私事可以和世界主線**共享線索**，但不能因要讓 Ruby 的故事悲傷，就替整個宇宙作出不可回收的終極設定。

## 7. 倫理、性別與人物尊嚴

- Aqua 主觀以為「Ruby 比我值得活」，不是作者或玩家必須接受的價值觀；**劇情要逐步反駁**。
- 她的女性身份認同逐漸形成，是她現在的一部分；角色圓滿不等於「變回男生」。
- 原 Ruby 不只是讓 Aqua 受創的劇情工具；必須有自己的願望、害怕、玩笑與求生意志。
- 家族知情並協助隱瞞可包含愛，但仍有欺瞞、身份權利和事故正義方面的後果。
- 和她交朋友的人有權利因為被欺瞞而感到痛苦，劇本不能以「她很可憐」要求所有人立即原諒。
- 不把角色的痛苦與女性認同作因果上的病理等同。

## 8. 與 Godot 美術和 Domain 的邊界

1. 對話表情差分以現在 Ruby 的正常外貌呈現；情緒崩潰不等於身形變回 Aqua。
2. 在戰鬥中 HP=0 是 **INCAPACITATED（失能）**：站位留場、Ruby 外貌持續，切失能 CG。
3. Last Spell 後 **EXHAUSTED（耗竭）** 是不同狀態，原則上退場；不得混淆為身份偽裝解除。
4. 劍術 Variant 的真正上線需 CharacterDefinition、卡牌資格、動作／美術、Domain 和版本化測試，不因劇情提案自動生效。
5. SHOCK 降 Accuracy 的候選、PARALYZED 的未來硬控制、Boss Resist／CONVERT、公開 EnemyIntent 等遵守 [魔法 v0.7](../combat/proposals/MAGIC_SYSTEM_UNIFIED_V0_7.md) 和已核准 Combat SoT。
6. 劇情 CG 需要正常 Ruby、獨處時 Ruby、童年 Aqua／原 Ruby、事故回想、星形吊飾、拔劍高潮等獨立規劃；不能假設現成 CG 就是劇情完整素材。

## 9. 下一步最小決策集合

- **事故發生國一還是國二？**國二較能讓兩人有共同回憶與時間進行偽裝。
- **事故責任採 A 純意外、B 隱瞞警訊，或 C 人為破壞？**目前 B 較能與家族政治連動，但仍是推薦。
- **The Fading 只是相似徵兆、已知局部類型，還是確有因果？**應待世界觀正式決策。
- **已確認知情者僅 Aqua 與原 Ruby 的父母**；仍待設計雙親是否兼任家主／理事長、如何獨力處理入學與繼承文件，不能因此擴增知情者。
- **Aqua 的原生家庭／監護人**在什麼地方？是否知道她後來的生活？
- **餐桌場景與母親無意間叫出 Ruby 的名字**是否保留？雙親是從何時開始知道 Aqua 的認知術假扮？
- **真相揭露後是否公開保留 Ruby 名字？**與女性身份認同分開決定。
- **是否保留普通未領取禮物與星形劍鞘掛飾？**有利於情感象徵，但尚未確定。
