## 2. 新增核心：人造生命、好奇心與未理解的溫柔

### 2.1 人造生命不是機器人（CONFIRMED）

- 創作者明確設定他是**伊凡諾維奇家族花費數百年研究創造的人造生命**，並非一般自然出生的人類；但**身體在物理上與人類相同**。不能擅自寫成金屬骨架、自動機械、固定指令控制的人偶，也不能從外觀判斷他沒有生命。
- 別人經常說他「像機器人」，原因來自他的**說話方式、嚴謹態度與過度分析**，而不是他真的是金屬機械。
- 他不是缺乏感情；他的內心**非常溫柔**，只是**難以理解與命名「溫柔」這份感情**。他可以做出體貼行為，再真誠地困惑自己為什麼會這樣做。
- **對真相的好奇心是天性**；研究不是必須源自事故、內疚或責任感。先前「他因重大事故而研究反運算」僅為被新正史取代的舊提案，不能當成既定背景。
- 他**理論極強卻常因過度思考而考試超時**，這是性格型缺點，不代表智力差。不得把他寫成凡事瞬間算出答案、萬能無缺的人工智能。

### 2.2 語言與日常節奏（CONFIRMED）

- **「考倒我了」**：真的遇到無法解答的情境；可包含情感問題，說得認真而不丟臉。
- **「原來如此」**：理解新事實、同伴行為或術式關鍵後的自然反應；可以帶有少見的興奮。
- **「我不明白……」**：理論上知道事件，卻不理解對方心情、理由或不符合預期的選擇。

台詞基調：**真誠、字面精確、不刻意搞笑，卻經常因認真的表達而有意外笑點**。熟悉後讓玩家發現他可以溫柔、有幽默感，並非永遠一張冷漠面孔。

### 2.3 人造生命的法則相容性：未完成之處維持 TBD

1. **創造方式 TBD：** 他已被創造出來，並非授權「所有家族都能輕易製造生命」。必須另外交代數百年研究的術式結構、材料、能源與合法條件。
2. **創造結束後如何延續生命 TBD：** 推薦方案（PROPOSED）是魔法參與創造**真實、能自行維持的生物性身體**，而非靠單一持續施法強行保持形體。這可與「完成的物理結果不會因原術式解除而消失」相容；但生物起源、意識來源及生長機制都還不能擅自定案。
3. **被反運算或封鎖後會怎樣 TBD：** 不能無依據宣稱「解除任何魔法就能殺死他」，也不能直接保證他對所有反制免疫。若生命運作本身仍需共鳴，必須另有具體機制及風險。
4. **彼世共鳴適性是 PROPOSED：** 創作者提出『可能因由魔法創造，與彼世共鳴超乎常人』。優先研究**效率**或**穩定性**是否異常；**容量**是否也高、Mana 儲量、實際施法輸出、比較方法與負擔均 TBD，不能統一成神祕的固定共鳴百分比。
5. **The Fading 邊界：** 高共鳴效率不會自動讓施法免付世界負擔，也不保證成本為零。製造生命所造成的過往世界負擔尚未定義；不把人造生命的存在直接推成 The Fading 的起源或無解悖論。

### 2.4 詠唱信念不等於世界法則（CONFIRMED／角色觀點）

- **完整詠唱 Full Chant：** 他主張依完整程序逐步構築、校準術式，這與重視正確性的性格相稱。
- **縮短詠唱 Shortened Chant：** 仍有外顯咒語，與完全無詠唱不同；他對這種折衷形式的容忍程度 TBD。
- **破棄詠唱＝無詠唱 Chantless：** 他主觀視為『邪魔歪道』，可以因此與他人爭論。**正式本體論明確允許高手以無詠唱合法而完整地施法**，不能因個人偏見修改魔法規則。
- 現行戰鬥中的完整／破棄詠唱差異屬既定 Gameplay 契約；他是否有專屬完整詠唱加成、是否能在戰鬥中使用破棄，**皆待獨立設計與核准**。

## 3. 術式解析與反運算：必須遵守世界法則

參照 [〈魔導設備、學院與解咒〉](../world/15_MAGIC_ENGINEERING_AND_COUNTERMAGIC.md) 與 [魔法作者規格](../world/magic/00_MAGIC_SYSTEM_SPEC_V1.md)：

1. **術式解析**：觀察魔法效果，推導其術式結構、參數、依賴與維持條件；**看懂不等於解除**。
2. **破解／干涉**：利用發現的限制或脆弱點，改變對方的運作；不必然等於反運算。
3. **反運算**：在具備合法作用能力及必要條件時，讓**仍由魔法維持**的作用失效或被針對性抵銷；不是讓時間倒退，不會自動回復已完成的普通物理傷害。
4. **施法干擾 ≠ 已成立魔法的解除**。不可因角色擅長解析就寫成無成本、全知、必中、無條件取消任何敵人的魔法。
5. 反運算可能面對未知結構、保護措施、備援、承載限制、資源消耗與時間壓力；實際能否成功仍由世界法則與具體劇情情境決定，**不是本檔新增戰鬥判定公式**。

## 5. 待討論的人物深化提案（全部 PROPOSED）

以下是供作者挑選或改寫的候選，不是已發生的劇情：

- **角色內在矛盾：** 他喜歡追究所有事實，卻無法輕易理解同伴的情緒；成長不是把情緒化約成數據，而是發現自己早就在關心別人。
- **戰鬥氣質：** 先觀察、遵循完整詠唱程序，重視精確反制；緊急情境下可能因過分堅持程序而面臨取捨。不能預設他永遠沉默或從不犯錯。
- **視覺動作：** 原地用藍金色的術式軌跡解析目標，再引導反運算；維持黑框眼鏡、長髮、長褲、法杖，避免與 Ruby 九格動畫混淆。
- **與奏的對照：** 奏擅長「怎麼把結界設計出來」，伊凡諾維奇擅長「怎麼看穿並解除已存在的術式」。同一學科可以有不同成熟度，不能抹去奏的天賦。
