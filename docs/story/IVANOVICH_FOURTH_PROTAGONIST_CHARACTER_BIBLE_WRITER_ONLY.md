## 1. 目前採納的角色外觀

以下以創作者持續修正並表示滿意的立繪為**美術設計方向**，不是聲稱該圖已完成透明背景、動畫或 Godot 導入驗收。

- **男性高中生**，臉部必須稚嫩、青澀，不能畫成成熟教授或成年人；神態偏嚴肅。
- **黑色長髮**，原始要求為及肩；現有立繪呈現肩下長髮，**精確長度待美術定裝確認**。不得任意變成短髮。
- **黑框眼鏡**為重要辨識元素。
- **星煌魔法學院黑金制服**，白襯衫、深色領帶、星辰紋飾、金色滾邊；**本角色保留長褲**，與 Ruby 已採用的短褲造型區分。
- **手持法杖**；已接受視覺方向為深藍星核、金屬環繞天體儀式杖頭及藍色魔法光效。與 Ruby 橙金色的法杖和效果作清晰辨識。
- 角色立繪和九格施法圖集屬美術草稿。高解析度、透明背景、比例對齊、腳底基準、視線朝敵人、佩飾一致性、動畫連貫及資產來源清單，均須由正式素材流程另行驗收。
- **身高、精確體格、瞳色標準值、校徽、法杖正式名稱**尚未單獨定案；不從單張插圖推定固定數值。

## 2. 術式解析與反運算：必須遵守世界法則

參照 [〈魔導設備、學院與解咒〉](../world/15_MAGIC_ENGINEERING_AND_COUNTERMAGIC.md) 與 [魔法作者規格](../world/magic/00_MAGIC_SYSTEM_SPEC_V1.md)：

1. **術式解析**：觀察魔法效果，推導其術式結構、參數、依賴與維持條件；**看懂不等於解除**。
2. **破解／干涉**：利用發現的限制或脆弱點，改變對方的運作；不必然等於反運算。
3. **反運算**：在具備合法作用能力及必要條件時，讓**仍由魔法維持**的作用失效或被針對性抵銷；不是讓時間倒退，不會自動回復已完成的普通物理傷害。
4. **施法干擾 ≠ 已成立魔法的解除**。不可因角色擅長解析就寫成無成本、全知、必中、無條件取消任何敵人的魔法。
5. 反運算可能面對未知結構、保護措施、備援、承載限制、資源消耗與時間壓力；實際能否成功仍由世界法則與具體劇情情境決定，**不是本檔新增戰鬥判定公式**。

## 4. 待討論的人物深化提案（全部 PROPOSED）

以下是供作者挑選或改寫的候選，不是已發生的劇情：

- **角色內在矛盾：** 他相信「任何問題都能先看懂再解決」，但第一次遇到明知原理也救不了的情境，開始理解分析能力與人的選擇是兩回事。
- **戰鬥氣質：** 平常話少、先觀察再行動；強調冷靜判斷與針對性反制，而不是以更強的破壞力輾壓所有敵人。
- **視覺動作：** 原地用藍金色的術式軌跡解析目標，再引導反運算；維持黑框眼鏡、長髮、長褲、法杖，避免與 Ruby 九格動畫混淆。
- **與奏的對照：** 奏擅長「怎麼把結界設計出來」，伊凡諾維奇擅長「怎麼看穿並解除已存在的術式」。同一學科可以有不同成熟度，不能抹去奏的天賦。
