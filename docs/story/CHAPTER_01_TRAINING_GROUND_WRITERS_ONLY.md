- 勝利之後，訓練場**出現原本不應在此的異形 Boss**，其戰力顯著超出當時主角團能力。這不是學生可按常規技能獨力打倒的敵人。
- 主角群陷入無法獨立擊敗 Boss 的危機時，**一位尚未設定的神秘人物出手，打倒異形**。其身份、性別、戰力根據、師生／組織關係、後續作用均 **TBD**；不得用現有角色擅自代入。
- 第一章的訓練場異形事件**與 The Fading 的局部失衡相關**，但角色當下不理解真正成因，也不能武斷宣稱「那天三人施法直接創造了那隻異形」。

## 4. Boss 戰 UX／Gameplay 相容性（PROPOSED）

- **避免腳本式無效必敗戰**：不要讓玩家反覆打 Boss 長條血後，才宣告任何行動都無效。
- 優先將勝利條件設為**撐住攻擊、保護某人、等待撤離／救援窗口**等可完成任務。玩家能用既有防守反擊、雷電控制、治療卡達成目標，再進入神秘人救援過場。
- 超規格 Boss 的「玩家無法擊殺」與任務可成功必須同時在 UI 說清楚；若發生失敗，重試條件和演出需公平。
- **沒有核准具體回合數、卡牌、Boss 數值、技能、Break 與 Exposed、救援觸發條件、強制戰敗腳本。**日後依 [Combat 現行規則](../combat/README.md) 設計 ADR 與測試。不可在故事文件私改 AP／MP／RP、耗竭和失能規則。

## 5. 世界深層因果（作者秘密；CONFIRMED）

`人類魔法使用增加 → 世界總熵逐步累積 → 局部區域可能失穩 → 世界產生異形作平衡回應 → 異形的數量及威脅提高 → 人類加強魔法研發與使用 → 失衡進一步惡化`。

此處 Entropy 是**設定用的無序化概念**，不直接等於現實物理學公式。**異形是「世界校正反應」而非確認有思想的神明使者**。是否全部異形共用同一起源、魔法強度如何量化、失衡恢復方式，均 TBD。詳細規格見 [作者版世界秘密](../world/09_SECRETS_WRITERS_ONLY.md) 和 [Canon 決策紀錄](../world/13_CANON_DECISIONS.md)。
