## 2. 《無法治癒的一切》：已選擇深化的主題（DIRECTION_APPROVED）

**核心提問**：當一個人具備減輕痛苦的能力，是否就必須救下所有人？當她做到了「治療傷口」，卻無法解決讓對方不斷受傷的原因，她應該如何理解自己的責任？

要避免的兩種極端是「魔法什麼都能治」與「治療魔法完全沒用」。角色的努力和治療成效都是真實的，但仍可能面對**資源限制、長期後果、當事人意願、制度障礙或人際衝突**。這些挑戰只是故事設計候選，不等於本世界已出現特定疾病、醫療制度或禁忌法術。

**主題底線**：
1. 她是故事的**行動者**：在艱難時仍必須做出選擇、付出代價並主動修正，不是被安排「治不好某人」後只留下愧疚。
2. 以尊重當事人意願、合作而非替他人決定一切作為成長方向；**不把患者的拒絕或病痛當作她需要征服的關卡**。
3. 治療術式的敘事極限與 **Combat Rules** 的 `HEAL`／`HOT`／狀態恢復是不同層次；此文件**不能自行限制戰鬥回復、創造免費復活或忽略既有 Last Spell／Exhausted 規則**。
4. 與律的受虐經歷可以產生價值衝突，但**她不能單靠施放魔法消除律的創傷或家庭問題**；Ruby 的秘密也不能被第三人「治好」或提前揭露。

## 3. 三條不同的個人夢想＋背景起點（皆 PROPOSED）

### A／推薦：讓治療不只屬於少數人

- **背景候選**：成長於普通且相對支持她的家庭；曾在社區的基礎照護／治療活動中接觸各式求助者，親眼見到「治得好」不等於「能持續獲得照護」。
- **個人夢想**：想讓難以取得治療協助的人，也能得到穩定、可靠、可持續的治療服務；可能希望建立社區治療網絡、流動治療站，或改良低門檻治療術式，**三者尚待選**。
- **弱點**：容易把每一個無法照料的個案歸咎於自己，過度承擔；不是因家庭施虐，而是因理想和責任感失衡。
- **劇情力量**：她有**不依附雨宮律或 Ruby 的社會性課題與長期目標**。是否存在明確的學院資源歧視、相關規章、家庭職業均尚未建立。

### B：追求突破治療術式上限的優等生

- **背景候選**：在學習氛圍認真、期待很高但不必暴力的家庭長大；習慣靠成績證明自己，初期把治療視為可逐步優化的技術。
- **個人夢想**：研究目前尚無法穩定處理的傷害後果，想證明治療魔法也能像其他學科一樣開拓未知領域。
- **劇情矛盾**：當「最有效的技術」與「當事人實際需要的生活」不完全一致，她必須學會重新定義成功；**不預設發現逆轉死亡、解除任何詛咒的神術**。

### C：從受助者走向治療者

- **背景候選**：曾經被人真誠幫助或治癒，因此仰慕醫者；其事件可以平凡而非重大悲劇。
- **個人夢想**：想成為當年幫助自己的人那樣可靠，讓下一位需要幫助的人不再孤單。
- **劇情矛盾**：她把「被感謝」與「成功治療」誤認為必須一起發生；遇到拒絕、誤解或無法介入的情況時，學習尊重不同人生選擇。

三條路線均未決定；**A 為優先推薦，不能自行升格 Canon**。可以混合部分元素，但必須由創作者選擇。

## 4. 五階段個人主線提案（以 A 為工作範例，PROPOSED）

| 階段 | 故事節拍 | 她真正面對的問題 |
|---|---|---|
| 第一幕「總能幫上忙」 | 她在學院表現可靠，主動參與某種基層治療協助，對自己要求很高 | 逐漸把「能不能幫所有人」當成自身價值 |
| 第二幕「治好了，為何還會痛」 | 她完成一次有效治療，但接受者仍因缺乏後續支援而陷入困難 | 魔法的成功不等於問題的終結 |
| 第三幕「有限的選擇」 | 多個求助者、有限時間及可用資源令她不能同時處理所有需要 | 她必須決定優先順序，並與他人合作承擔 |
| 第四幕「好意也會傷人」 | 她出於保護欲試圖替他人安排選擇，對方清楚地拒絕 | 她能否承認自己越界，理解協助需要同意與信任 |
| 第五幕「比一個人更大的治癒」 | 她建立可以持續運作的協作方式，不再將所有人寄託在一名英雄身上 | 不是放棄救人的理想，而是讓幫助變得可持續 |

**重要：**具體患者身分、地點、案件、學院協助程度、結局成敗與任何角色死亡都屬 TBD。不為了製造痛點強行讓她治療失敗造成死亡。這一章必須由她自己做出無法代勞的關鍵選擇。
