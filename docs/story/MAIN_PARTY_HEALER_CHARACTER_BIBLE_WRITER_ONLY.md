## 2. 《無法治癒的一切》：已選擇深化的主題（DIRECTION_APPROVED）

**世界觀與主線的必守前提（CONFIRMED）**：創作者明確指出本作**每個人都會基本的治癒魔法**。因此第三位主角**不是**要替大眾發明、教授或獨占初級治療；她關心的是當基礎治療仍不足以解決需求時，如何讓人獲得**更專業、更可靠、能延續的照護**。世界上到底有哪些進階治療服務、照護制度或匱乏原因尚未定案，不能擅自宣稱「只有貴族能治療」「一般人沒有魔法」「治療師可以無視傷害規則」。

**她的正式夢想（CONFIRMED／A）**：讓有需要的人**更容易取得可靠的專業治療及持續照護**。她的理想是改善可及性與持續性，而非宣稱基礎治癒術稀有。具體方案與人生經歷仍是 PROPOSED／TBD。


**核心提問**：當一個人具備減輕痛苦的能力，是否就必須救下所有人？當她做到了「治療傷口」，卻無法解決讓對方不斷受傷的原因，她應該如何理解自己的責任？

要避免的兩種極端是「魔法什麼都能治」與「治療魔法完全沒用」。角色的努力和治療成效都是真實的，但仍可能面對**資源限制、長期後果、當事人意願、制度障礙或人際衝突**。這些挑戰只是故事設計候選，不等於本世界已出現特定疾病、醫療制度或禁忌法術。

**主題底線**：
1. 她是故事的**行動者**：在艱難時仍必須做出選擇、付出代價並主動修正，不是被安排「治不好某人」後只留下愧疚。
2. 以尊重當事人意願、合作而非替他人決定一切作為成長方向；**不把患者的拒絕或病痛當作她需要征服的關卡**。
3. 治療術式的敘事極限與 **Combat Rules** 的 `HEAL`／`HOT`／狀態恢復是不同層次；此文件**不能自行限制戰鬥回復、創造免費復活或忽略既有 Last Spell／Exhausted 規則**。
4. 與律的受虐經歷可以產生價值衝突，但**她不能單靠施放魔法消除律的創傷或家庭問題**；Ruby 的秘密也不能被第三人「治好」或提前揭露。
