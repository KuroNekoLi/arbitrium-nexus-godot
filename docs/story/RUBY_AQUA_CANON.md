# 星煌露比 Ruby／阿奎亞 Aqua｜角色正史與作者秘密

> **編劇內部／重大劇透**｜Canon 記錄 2026-10-20。每條決策均標記 CONFIRMED / PROPOSED / TBD。後續創作者新決策優先。

## 1. 一句話人物核心（CONFIRMED）

**真正的 Ruby 已在高中入學以前死亡。**昔日與她青梅竹馬、訂有婚約的 Aqua，因未能保護她而深陷自責；儘管事故並非 Aqua 的責任，Aqua 仍以自身認知魔法的天賦完美重現 Ruby 的外貌、聲音、身形和觸感，刻意模仿她活潑開朗的性格，並以她的名字進入星煌魔法學院。現在的 Ruby 自我認同為女性；這份認同是在延續 Ruby 人生的過程中逐漸形成，**不能等同於單純的假扮或需要被治好的創傷**。

## 2. 已確認的世界背景

1. **星煌魔法學院**：本作主舞台、世界最著名的魔法學院、**私立**，由星煌家族建立。
2. **真正的 Ruby**：原本的星煌家族唯一繼承人；與 Aqua 是青梅竹馬且有婚約。原 Ruby 活潑開朗、健談，為現在 Aqua 模仿的原型。
3. **死亡時間**：事件在進入星煌魔法學院前，**國一或國二**；國二為故事提案、尚未鎖定。
4. **遊戲時間**：主要劇情在高一或高二。主線開場的 Ruby **早已是 Aqua**；不能讓真正 Ruby 在學院主線開始後才死亡。
5. **家族知情**：只有星煌家族的**少數核心人物**知道現在 Ruby 的身份。**已確認**：Aqua 與真正 Ruby 的父母原本有親密的**乾爹／乾媽、乾親子女關係**；Ruby 的父母在女兒過世後承受強烈悲傷，難以接受她已死亡。**CONFIRMED（本輪正式核准）**：除了 Aqua 本人，**全世界只有真正 Ruby 的父親與母親知道目前的 Ruby 是 Aqua**。星煌家族其餘成員及其他外人均不知情；不得再自行添加家族長老、心腹、僕役、學院人員或調查者作為知情者。繼承合法性、掩護方式仍待定。
6. **角色關係**：Aqua 自幼與 Ruby 的父母情同家人，是他們的乾兒子／乾親子女（現今 Aqua 自我認同女性，可依時期使用適當稱謂）；Ruby 的父母同時也是 Aqua 深愛且不願再失去的長輩。朝霧蓮、九條朱音、白石紬只是目前戰鬥示範人物；**不將三人寫成 Ruby 的已確認朋友、同班生或見證者**。

### 美術識別與製作原則

- 現在 Ruby：金髮、琥珀眼、約 145 cm，黑金色系、男性剪裁校服和**短褲**，保持稚氣、纖細與不強調胸部的既定角色畫風。
- 星辰法杖為平時主要武器，腰間長劍通常連鞘佩戴。
- **失能／昏迷仍維持 Ruby 樣貌**，不因 HP=0 切回 Aqua 原貌。
- Aqua 真實原貌、真正 Ruby 生前全部服裝細節、變身解除時的 CG 尚未正式定案。
- 後期拔劍不是「恢復男性身份」，而是能面對自己作為 Aqua 的過去；是否仍採 Ruby 名字與女性身份，應尊重角色如今的自主選擇。

## 4. Aqua 的性格與轉變（CONFIRMED）

- 在悲劇**之前**：話少、內向冷靜、不善表達，但不等於本來就陰鬱。
- 在悲劇**之後**：因自責而逐漸封閉自己，不願再拔出原本擅長使用的劍。
- 為延續真正 Ruby 的人生，Aqua 刻意模仿她的笑容、語氣、健談與開朗。
- 現在的 Ruby：活潑、開朗、健談、愛開黃腔、喜歡女生。
- 女性身份認同於長期延續 Ruby 人生的過程**逐漸形成**；不是在意外前就已確定，也不能將最後的「接受自己」寫作否定女性身份。

## 5. 高階認知魔法的確定邊界（CONFIRMED）

- Aqua 原本就是**認知類型魔法的天才**；不是事故後因冒用身份才突然獲得才能。
- 技術可維持原 Ruby 的**外貌、聲音、身體外形與觸感**，不是只換臉的簡單幻術。
- 一般人不會刻意懷疑；即使有懷疑，突破這個術式也需要**很大的代價或努力**，無法靠普通接觸與隨便一次偵測就揭穿。
- **施術者失去意識時仍然維持效果。**這點適用於戰鬥失能演出。
- 維持機制、成本與是否存在極少數可靠破解方法尚未定案；不可額外創造「每晚必須補充一次」等強制限制。
- 這是故事層級的認知／身形偽裝能力；**不代表已經在 Godot Domain 設計一套無限控制 NPC 思想的戰鬥技能**。

## 6. 乾爹乾媽的悲傷、知情圈正式確定（CONFIRMED）

### 已確認 Canon
- **Aqua 從小與真正 Ruby 的父母關係極好，彼此有乾爹、乾媽的親密關係**；她原本就是這個家庭願意接納和疼愛的孩子，不是悲劇後才被星煌家族收留的陌生人。
- 真正 Ruby 過世後，**Ruby 的父母也非常痛苦、始終難以接受女兒已死亡**；他們的悲傷不是政治上的假動機，而是獨立而真實的親子喪失。
- **真正的知情圈現在正式定案為三人：Aqua 本人＋真正 Ruby 的父親＋真正 Ruby 的母親。**其他家族成員、老師、學生與外人完全不知這項身份真相。

### 已確認：只有雙親知情，其他所有人不知
- **CONFIRMED：**除 Aqua 本人之外，知道「學院裡的 Ruby 其實是 Aqua」的人**只有真正 Ruby 的父親與母親**。兩人既是失去親生女兒的父母，也是原本就愛著 Aqua 的乾爹乾媽。
- **其他任何人物都不知道替身秘密**：即使有長老、管家、醫師、理事長、僕役、家族心腹或事故調查者在場，也不能讓他們知道 Aqua＝現在的 Ruby。若後續需要新知情者，必須先取得創作者新的明確批准。
- 雙親**知道 Aqua 不是死而復生的 Ruby**；他們可能在某些時刻本能地叫出親生女兒的名字，卻也知道眼前的人是 Aqua。這個清醒與逃避交錯的狀態比「被魔法騙到不知道女兒死了」更有層次。
- 父母**不必主動命令** Aqua 成為 Ruby；可以由一次不經意的聲音模仿開始，父母因悲傷而依賴，Aqua 因愛與罪惡感反覆配合，最後三人共同陷入長期的沉默。
- **三人都各有責任與選擇**：Aqua 的偽裝並非被強制綁定，也不是因「只有 Ruby 有價值」而真的合理；父母的悲傷可被理解，但若他們藉此對 Aqua 施加壓力、欺瞞其他人，仍必須在後期面對後果。
- **父母的差異（候選）**：母親更難停止叫出 Ruby 的名字；父親更常提醒自己「眼前是 Aqua」，卻也無法親手終止欺瞞。勿把一位寫成愚昧、另一位寫成純粹操控者。
- **後期情感核心**不是父母選擇「Ruby 還是 Aqua」二選一，而是學習承認：親生女兒 Ruby 已逝，但他們還可以真心愛著活在眼前、已經成長為自己樣貌的 Aqua／現在的 Ruby。

### 需要補上的世界觀與劇情邏輯
1. **除 Aqua 以外只有雙親知情時，為何仍能長期保密**：事故現場遺體、死亡證明、舊學籍、醫療及繼承文件是否存在？哪些人只知道官方版本？不可一句「認知魔法」就抹除歷史物證。
2. **原 Aqua 的親生父母或監護人在哪裡**？乾親關係不等於 Aqua 沒有親生家庭；此事尚未決定，不得臆測孤兒設定。
3. **Aqua 是否知悉父母其實知道真相**？本版優先提案為三人彼此明白但避免說破，是否完全相互坦白尚未拍板。
4. **繼承與身份能維持多久**：出生紀錄、法定家族成員資格、特殊魔法驗證與事故公報仍須後續設計。

**身份秘密僅有 Aqua 與真正 Ruby 的雙親知情**不等於所有檔案、法定親屬或魔法系統都已被合法替換。後續故事要決定：公開事故檔如何記載 Aqua 的去向、繼承權如何處理、哪些同時熟悉兩人的人仍有記憶，以及如果身份揭露，Ruby 如何面對被欺瞞者的合理情緒。

## 8. 武器、術式與未來成長

- Aqua 擅長**劍術**，但是現在 Ruby 的公開形象是**魔法使**，主要使用星辰法杖。
- 公開雷電術式可用「感電 SHOCK／麻痺 PARALYZED／Casting Disruption」來思考戰鬥特色，但細節仍屬 Card／Domain 提案。
- 認知與雷電是不同**研究學科**；跨學科不自動增加傷害、控制機率或無條件提供 Combo。
- 在個人故事後段克服內疚心結後，才會重新**拔劍戰鬥**；可規劃法杖＋劍術的 Character Variant，並非已實裝功能。
- [魔法統一 v0.7](../combat/proposals/MAGIC_SYSTEM_UNIFIED_V0_7.md) 區分 SHOCK（候選降低命中）與 PARALYZED（未來硬控制候選，需 Boss 抗性／防連鎖保護）；任何明確數值與卡牌均未由本文件核准。
