## 0. 戲劇核心：她不是要騙過所有人，而是無法接受自己被留下

Aqua 當年救出了孩子，卻沒有救回真正 Ruby。事故在客觀上不是她的責任，然而在她內心，「我守護大家」與「我丟下 Ruby」成了同一件事。再加上 Ruby 是星煌家族的繼承人、熱愛魔法、能帶給所有人笑容，而 Aqua 只是話少的少年，她陷入了扭曲卻可以理解的判斷：

> 「如果那天回來的是 Ruby，所有人都會開心。活下來的為什麼偏偏是我？」

星煌家族少數成員的悲傷與繼承壓力，使她的想法獲得外在支撐。第一次冒用也許只是想讓一個哭泣的孩子安靜下來；第二次是為了讓 Ruby 的家人能再聽見她的聲音；第三次已經是以 Ruby 身份接受所有人的問候。後來 Aqua 逐漸形成真實的女性身份認同與真實的日常快樂；**角色成長不是「變回男性／Aqua」，而是學會不用以自我懲罰作為活著的理由。**

## 1. 童年——一個安靜的人與一個話多的人

**時間：幼年至國中初期。**真正 Ruby 是星煌家族唯一繼承人，明亮、話多、愛開玩笑。Aqua 沉默寡言，對其他孩子不知如何搭話，卻對劍有執著，並展現出難以想像的認知魔法理解力。

兩人是青梅竹馬兼婚約對象。婚約由何而來未定，但不是要用婚約取代兩人真正的感情。

在庭院練習後：

> Ruby：「Aqua，你怎麼又不說話？」
>
> Aqua：「不知道說什麼。」
>
> Ruby：「那就笑一下啊。」
>
> Aqua：「有什麼好笑的？」
>
> Ruby：「因為我很可愛呀！」
>
> Aqua：「……真受不了妳。」
>
> Ruby：「嘿嘿。等我們進了學院，我可是要成為最厲害的魔法使。」
>
> Aqua：「那我呢？」
>
> Ruby：「你當我的護衛！不准免費離職喔。」
>
> Aqua：「……妳只是想找個免費護衛吧。」

Ruby 也曾說過，Aqua 不必永遠只想保護她，應該找到自己真正喜歡的生活。少年未把這句日常叮囑放在心上。

**伏筆：**真正 Ruby 用玩笑掩飾關心，Aqua 依賴她的笑容，卻誤以為對方比自己更值得活下去。

## 2. 國中事故——星見天文塔（暫稱）

**提議時間：國二。**發生在高中入學之前，並非星煌魔法學院校內事故。星煌家族的一座離校私人研究設施「星見天文塔」（名稱 TBD）舉辦面向家屬與少數少年訪客的術式安全觀測。

現場正在觀察一道保護研究區與外部撤離通道的結界。突如其來的異常讓本應穩定的魔法陣出現斷續，照明顛倒閃爍，觀測儀顯示不可能的讀數；護欄外出現一隻具有「干涉術式」特徵的**異形**（類型、數量、來源均 TBD）。

- 人們一開始以為只是設備故障，等發現異形時部分通道已封閉。
- 當時有孩子被困在防護區內；成人防衛／救援人員正在別處疏散或阻止危險，無法瞬間到場。
- Aqua 與 Ruby 都接受過基本安全教育，不是任意闖入危險地區的無能英雄；兩人有能力協助，但沒有能力單獨平息整場事故。
- Aqua 以劍術清開瓦礫、保護前進中的孩子；Ruby 懂得緊急結界的操作，能在短時間保持撤離通道穩定。
- **那時的 Aqua 雖有認知魔法天賦，也不能靠認知術直接修好崩潰的防護核心。**認知魔法不能無代價取代所有物理／奧術技能。

**The Fading 伏筆（MYSTERY，非宇宙因果定案）：**有幾秒鐘，監測畫面上的星星像是被人從圖上擦去；不同觀測裝置同時給出互相矛盾的時間戳記。事故調查可將它暫稱「局部穩定性異常」，部分研究人員聯想到一個後來被稱為「The Fading」的研究假說，但**不能現在斷定**它是直接死因、異形誕生原因，或已被星煌家族完全掌握。

## 3. 最後的三分鐘——兩個人都相信還有明天

現場的備援通道只能從控制室持續維持，且必須有人帶孩子們穿越瓦礫才能安全抵達外側。Ruby 熟悉控制端，Aqua 熟悉清障與近身護衛。兩人的工作不能即時交換。

> Aqua：「我留下來。妳帶他們走。」
>
> Ruby：「你看得懂這座結界的控制式嗎？」
>
> Aqua：「我可以學。」
>
> Ruby：「現在沒時間了，笨蛋。」
>
> Aqua：「那就一起走。」
>
> Ruby：「我一鬆手，通道就會關起來。那幾個孩子怎麼辦？」
>
> Aqua：「……」
>
> Ruby：「你不是說要保護我嗎？那也幫我保護他們。」
>
> Aqua：「……妳會跟上來吧？」
>
> Ruby：「當然啦。」

Aqua 帶孩子通過最後一段通道。Ruby 忽然在後方叫住她：

> Ruby：「啊！出去之後記得陪我去取東西！」
>
> Aqua：「又買什麼？」
>
> Ruby：「秘密。先去救人啦！」

少年回頭看了她一眼，繼續往前。這不是一場知道自己即將殉難的莊嚴告別；兩人都以為只差一點就能成功。

就在最後一名孩子越過防線之際，異形的攻擊與結界異常疊加，備援防護失敗。控制室被封閉，第二波結構崩塌。Aqua 嘗試折返，卻已沒有可安全通行的路。救援者趕來時，真正 Ruby 已死亡。

### 客觀事故判準（劇本必須說得通）

- Aqua 把孩子們帶走，不是丟下 Ruby 偷偷逃命，而是在 Ruby 可知的判斷與雙方的明確分工下完成撤離。
- 若 Aqua 放棄孩子回到控制室，不會有已被證實能救出 Ruby 的方法，反而可能讓所有人陷入危險。
- 即使劍術再強，也不能在當時的時間與結界狀態下完成全部救援；其認知天賦不能逆轉已發生的結構破壞。
- Ruby **當時原本有理由相信自己能離開**；最後的崩塌屬不可合理預見的突發變化，而非「Ruby 自願赴死」的簡化情節。
- 事故責任是否包含上層隱匿缺陷尚未定案。可以確定：**不是 Aqua 的錯。**

這一段最殘忍之處：**Aqua 一生最成功的保護行動，恰好與她失去 Ruby 的瞬間重疊。**

## 4. 她的罪惡感不是邏輯題

調查者告訴 Aqua：安全裝置失效、異形干擾與最後的結構崩塌不是她造成；她的撤離行動挽救了孩子們。

Aqua 沒有反駁證據。她只反覆問：

> 「如果我那時候回頭呢？」
>
> 「如果我的劍更快一點呢？」
>
> 「如果那天我沒有帶他們走呢？」

別人看到「孩子們活下來」，她想到「Ruby 沒有回來」。她不是經過公平理性計算後得出自己有罪，而是把**我活下來**誤解成**我沒有資格活著**。在這個年紀，「只要我承擔責任，世界就可以有理由」比接受無人能控制的失去還容易。

她放下劍，因為那把劍最後一次被使用時，她正帶著孩子們離 Ruby 越來越遠。

## 5. 沒有領取的禮物——劍鞘上的一顆星

Ruby 生前偷偷為 Aqua 訂了一枚不起眼的**星形劍鞘掛飾**，玩笑說她的劍太冷冰冰，要替它掛顆可愛的星星。事故那天說的「出去之後陪我去取東西」，就是它。

掛飾背面刻著：

> 「Aqua，也要記得保護自己喔。」

這只是事故前準備的普通禮物，**不是預知死亡的遺言，也不是死者解除罪惡感的魔法指令**。

Aqua 在事故後拿到掛飾，把它繫在劍鞘上，從此不再拔劍。玩家初見 Ruby 時也能看到這顆星；她總笑著說：「很可愛吧？這可是秘密。」在真相揭露之前，這只是角色設計上的小裝飾。

## 6. 第一次成為 Ruby——從一句安慰變成一個牢籠

**本段新增核心動機提案：**事故後，一名被救出的年幼孩子久久無法平靜，詢問「Ruby 姊姊還會回來嗎？」Aqua 無法回答。她下意識以認知魔法重現 Ruby 的聲音，說了句「別怕，現在安全了」。孩子終於止住哭泣。

那不是拯救全世界的神蹟，只是一瞬間：**自己的聲音不能安慰任何人，Ruby 的聲音卻可以。**Aqua 開始相信，自己存在只會讓人想起災難，而 Ruby 的存在能帶給人希望。

這是一個**受創少年對自己與 Ruby 價值的錯誤判斷**。編劇不能將它寫成作者認證的「Aqua 一無是處」。

之後某夜，她在真正 Ruby 的房間裡試著模仿她的聲音：

> 「Aqua，你怎麼又不說話啦？」
>
> 「……」
>
> 「因為我很可愛呀！」

她調整外貌、體態、聲音、觸感，一遍遍演練 Ruby 愛笑的語氣。鏡子裡的人與 Ruby 幾乎一模一樣。

唯一做不到的，是讓真正的 Ruby 回答她。

### 為什麼不能「偶爾扮演」，而必須一直是 Ruby？

1. **自我價值錯置**：Aqua 認為 Ruby 本該活著，而自己「偷走」了本該屬於 Ruby 的生存機會。讓 Ruby 的名字、夢想與笑容繼續出現在世界上，成為她對自己設定的懲罰與償還方式。
2. **起初有可見的回饋**：失去 Ruby 的孩子、家人甚至旁人，在看到「Ruby」的笑容時感到安慰；Aqua 把這種短期效果誤認成自己應永遠消失的證明。
3. **家族制度與共犯沉默**：星煌家族的繼承人已死，少數核心人物出於保護、悲傷、聲譽或權力考量默許她延續 Ruby 的身份；一旦公開，牽涉家族、學院、事故紀錄與所有被欺瞞的人。
4. **身份慣性**：從第一次謊言到長期生活，校籍、生活圈、對外責任和家族期待逐漸都寫上 Ruby 的名字；Aqua 越是想退出，就越覺得自己會讓 Ruby「第二次死去」。
5. **情感逐漸超越偽裝**：與日後真實形成的女性身份認同及自身的交友快樂交錯。她不能一鍵「停止扮演」就恢復成以前的自己，也不應被要求那樣做。

這些理由構成了**人物主觀認為「必須」**的可信鎖鏈，而非世界法則真有「不扮演就會死」的強制術式。真正的成長是知道她有權選擇，仍可使用 Ruby 名字而不必否定 Aqua 的存在。

## 7. 家族知道了——悲傷與制度的共同沉默

星煌家主或另一位高層發現 Aqua 的身份（**具體知情者待定**）。第一次見到那副 Ruby 的笑容時，對方不是立即接受，而是幾乎崩潰。

> 知情長輩：「你知道自己在做什麼嗎？你不是她。」
>
> Aqua：「……我知道。」
>
> 長輩：「那就停止。」
>
> Aqua：「如果 Ruby 還在，所有人都會比較幸福。」
>
> 長輩：「……」
>
> Aqua：「至少請讓我把她沒能做完的事做下去。」

一位長輩可能想保護她，另一位心腹則害怕唯一繼承人逝世引發家族與學院動盪。雙方沉默的動機不同，**不表示家族所有人同意**。

**對外版本提案**：事故公報宣稱星煌露比倖存、需要長期休養；少年 Aqua 下落不明或行蹤不公開。這個版本必須在正式寫劇本前與目擊者／診療紀錄／家族繼承程序作一致性檢查；認知魔法不能自動抹去所有紙本檔案。法定繼承怎麼處理尚未核准。

## 8. 國中後期至高中入學：從模仿笑容到真正生活

三個時期必須分開演出，而非在葬禮當晚瞬間完成：

- **逃避**：停止劍術、避開熟人、對鏡子的原貌感到無法承受；偶爾用認知魔法重現 Ruby 的聲音。
- **模仿**：練習 Ruby 的語氣和笑容，鑽研她喜歡的魔法，逐漸以法杖取代長劍。原本擅長認知術使外貌、聲音、體態、觸感高度穩定，就連失去意識也不解除。
- **生活**：進入星煌魔法學院時，所有新朋友都認識她為活潑開朗的 Ruby。她真心享受某些日常時刻，又會因為「自己竟然快樂」而愧疚。女性身份認同在長期生活中逐漸形成，這不是偽裝能力的附帶效果，也不是需要被矯正的錯誤。

原 Ruby 的具體雷電專精待定；現在 Ruby 公開使用雷電控制術，Aqua 隱藏的真正強項仍是認知術。

## 9. 高一／高二的日常伏筆：學妹與劍鞘

入學後某天，一位年幼時曾在事故現場獲救的學妹向 Ruby 道謝。

> 學妹：「我以前在一場事故裡被一個拿劍的人救過。」
>
> Ruby：「哦？聽起來很帥耶。」
>
> 學妹：「我一直想親口跟他說謝謝，可是再也找不到他了。」
>
> Ruby：「……這樣啊。」
>
> 學妹：「Ruby 學姊，妳的劍上也有顆星星耶。」
>
> Ruby：「很可愛吧？這可是秘密喔。」

**連續性注意：**這名學妹不必知道當年 Aqua 的全名或與 Ruby 的婚約，也不應無緣無故認出已被認知術完美覆蓋的 Aqua。她可以只記得當時少年帶她逃生時的手、劍與沉默。Ruby 短暫失語後轉移話題；玩家初見只是以為她怕尷尬。

這種伏筆可散落於課堂、醫療室、雷電法術訓練、失能 CG 與寄回家族的信件中；**不能**讓隨便一個低階偵測術當場破解身份。

## 10. 中後期調查：異形與尚未證實的 The Fading

玩家調閱星見天文塔舊檔，找到**相互矛盾的記錄**：

- 有異形侵入的目擊與傷害證據，但既有結界在侵入前還是後失效，紀錄不一致。
- 部分研究裝置在事故同時出現「不合理的空白」與時間記錄錯亂；技師提出術式故障、外來干擾、人為維護疏失三種解釋。
- 少數研究者懷疑這屬於後來被稱為 **The Fading** 的異常前兆，但資料無法排除其他原因。
- 家族對外公報和保密附件不一致；最重要的不是「誰是終極反派」，而是**究竟還有誰當年做了可以改變結果的選擇**。

這條世界危機線是一個**可驗證的劇情提案**，不是宇宙起源定案。作者若日後核准 Reality Cost、The Fading 與異形因果，可以將該事故視為早期案例；若改採其他世界解釋，也無須改掉 Aqua／Ruby 的感情核心。

## 11. 真相揭露：不靠一封方便的遺書來赦免她

中後期玩家發現：學院裡的 Ruby 是 Aqua。這時的 Ruby 可以坦承：

> 「我知道那天不是我的錯。」
>
> 「可是如果那天回來的是她……你們現在認識的，就會是那個真正的 Ruby。」
>
> 「她有那麼多想做的事。」
>
> 「我什麼都沒有。」
>
> 「所以我想，把我的人生還給她。」

同伴沒有必要立刻原諒欺瞞，也不能說一句「妳很棒」就治癒多年創傷。有人可能因信任受損而生氣，有人想陪她找舊檔，有人需要時間。劇情要容許倫理後果存在。

**不以原 Ruby 臨終錄音或完美遺言把 Aqua 直接洗白。**可以只讓 Aqua 重新讀懂生前那枚普通劍鞘吊飾上的話：「也要記得保護自己喔。」

## 12. 最後拔劍：不是變回 Aqua，而是不再判自己有罪

新一場危機讓 Ruby 再次面臨撤離與救援抉擇。她不再追求「只要我死就能補償當年」，也沒有因悲傷而不顧其他人安危。她接受同伴合作，在可行撤離計畫中重拾劍術，配合雷電法杖創造逃生時機。

她拔出劍，劍鞘上的小星星依舊留著。

> 「我不是妳。」
>
> 「我也不是當年那個連一句話都說不出口的人。」
>
> 「可是我會記得妳，也會繼續活下去。」
