## 正式主角與隊伍狀態（2026-10-27）

目前角色企劃已確立主角群四人：**雨宮律（劍士）／星煌露比 Ruby（雷電控制）／橘澄花（治療）／伊凡諾維奇（術式解析與反運算）**。伊凡諾維奇的家族強化藥劑與救贖篇章已核准主要方向；完整姓名、具體章節、入隊時間與治癒術式細節仍 TBD。

**雨宮奏**是律的妹妹，有獨立重要劇情和術式解析／結界構築天賦，**不是已確認的第一章初始隊員**。第一章既有的律、Ruby、澄花三人與神秘救援者的劇情骨架不因主角群擴充而改變；Godot 目前仍為三人上場原型，且保留舊示範角色資料。

## 決策標記

- **CONFIRMED / 已確認**：使用者已直接決定的角色、學院及時間線設定。
- **PROPOSED / 故事提案**：供討論的一條完整可演出路線，**不是**既定死亡真相。
- **MYSTERY / 待揭露**：故事可以埋設線索，不應現在作出唯一宇宙因果斷言。
- **TBD / 待定**：須由創作者另行決定，不由 Agent 暗自升格正史。
