## 1. 這個反派家族的核心悲劇

家族最初問的是：「人類明明可以互相理解，為何仍會傷害彼此？如果創造更能理解彼此的生命，能不能減少戰爭？」

研究數百年後，他們創造凡凡。**他不是家族失敗品，而是最值得驕傲的證明。**家人可以真心疼愛、關心他的成長；家族內部也可以有人反對中期人體強化試驗（具體名單 TBD）。

但家族的後繼者可能逐漸把「人人不再受傷」與「人人應該變得更強、更符合研究預測」混為一談。起初自願的魔法增幅療程真的讓一些人受益，於是社會、研究經費與家族榮譽都與計畫綁在一起。當病例出現，部分領導者更怕停止研究會讓已服藥者失去救治機會，遂不願正視資料或停止擴大使用。

**家族由此成為反派不是因為「愛凡凡是假的」，而是因為有人開始凌駕受試者的自主權、隱瞞風險，為所謂長遠善果正當化眼前的傷害。**凡凡既要阻止他們，也要面對愛與責任可以同時存在的現實。

## 2. 強化療程、異形化與恢復：與世界法則的相容方式

### 2.1 已選敘事效果與尚未核准的機制

**已選效果：** 部分接受家族強化藥物／術式的人力量提升，後續逐漸出現異形化；此種異形化**可透過凡凡最終找到的方法恢復人類**。

**重要區分：** [魔法本體論](../world/magic/00_MAGIC_SYSTEM_SPEC_V1.md) 已確定「真正異形」的共同來源是世界對 The Fading 的校正反應。此篇可以由**玩家或社會**把外觀劇變者稱為「異形」；**在作者分類上**先暫記「藥劑誘發的人類異形化」，**不自動宣稱它與世界自然生成的真正異形完全同類或推翻其起源法則**。究竟是否涉及世界校正反應介入人體、兩類是否有可驗證的交集，屬 **TBD**。若未來確定有真正異形參與形成，需另走世界觀 Canon 審核。

**可採的工作假說（PROPOSED，非既定法則）：** 強化療程建立某種長期有效的魔法干涉／體內共鳴調整，提升部分人的施法承載或效率；累積負載、控制失準、特殊身體條件或局部失衡可能引發異常形態與生理變化。沒有足夠資料時不可寫成「每劑藥必出一隻真正異形」或「超高共鳴率必定變怪物」。Mana、容量、效率、穩定性、能源和 The Fading 負擔仍是**不同概念**。

### 2.2 恢復人類的硬邊界（CONFIRMED 結果；操作法 PROPOSED）

**最重要的故事承諾：人能被救回來。**凡凡需要在角色成長後，真正找到對異形化有效的恢復方法，並親自參與救助，不以一句「研究已完成」代替整個高潮。

可用的合法技術路線：
1. **術式解析**：分析個別病患仍在運作的變化機制、增幅藥物依賴與失效程序；即使有共通病因，不保證所有人同一體質。
2. **反運算／安全停機**：有條件地終止或弱化**仍在維持**的危險干涉，並確保停止後的身體仍有穩定的生理支持；不是遠端按鍵就憑空回復所有已成形的器官。
3. **治療與身體恢復**：對已形成的**真實物理／生理改變**，另以合法的生命、治療與重建術式逐步處理，所需材料、資源、風險、同意與時程待設計。**澄花的專業照護不是凡凡反運算能力可以替代的。**
4. **臨床確認與後續照護**：病患確認恢復自主、知情選擇與安全生活，仍可能需要復健、追蹤或社會支持；「能恢復人類」不等於免成本、無後遺症、所有人瞬間同時痊癒。

**本作既有界線：** 反運算不能倒轉時間、抹除已發生的物理傷害、消除曾經造成的 The Fading 全域負擔；不得預設隨手解除「真正異形」就能讓其憑空變回人類。若救治另需新魔法干涉，也可能繼續增加世界負擔，不是零代價神術。

## 3. 建議的中期章節節拍（事件先後方向已選，細節均 PROPOSED）

| 節拍 | 劇情與主角作用 | 凡凡成長 |
|---|---|---|
| 1. 「家族的驕傲」 | 在學院日常展示凡凡的聰明、過度分析、完整詠唱與真誠溫柔；介紹家族的善意研究史。 | 真心以家人為榮，不預設家族可疑。 |
| 2. 「更強的可能」 | 家族公開增幅療程初期成果；有人出於自願與具體需求參與，**先讓受試者成為有姓名與生活的人**。 | 凡凡感到高興，將家族成就視為改善世界的一步。 |
| 3. 「不在統計裡的人」 | 澄花發現部分病患異常；Ruby、律展開調查。資料存在不一致，家族擔憂冒然停機。 | 凡凡因信任研究程序而與同伴意見相左。 |
| 4. 「不讓你們通過」 | 凡凡在研究設施前短暫擋下主角團：他真心認為貿然解除療程可能讓病患更危險；**可演成非致死、帶任務目標的 Boss 戰（僅提案）**。 | 想用完整答案才能做決定的缺點暴露；與夥伴信任受損。 |
| 5. 「代價的證據」 | 更嚴重的異形化出現；證明領導者隱瞞風險或違反受試者意願，部分研究員提出反對。 | 凡凡主動重查家族數據，承認自己信任得過於輕率。 |
| 6. 「考倒我了」 | 家族領導層堅持升級方案，凡凡拒絕把人當成可犧牲的研究變數。 | **不是被同伴說服就立即轉陣營，而是因自身證據和溫柔做出選擇**，主動回歸阻止家族。 |
| 7. 「恢復的方法」 | 凡凡完成關鍵解析、提出可執行的針對性反運算與恢復方案；律與 Ruby 爭取救援時間，澄花主導治療／追蹤。 | 從追求完美答案，成長為能在不確定中為眼前的人負責。**確認至少呈現真實的成功恢復案例**，不能只留一句將來可治。 |
| 8. 「一起善後」 | 事件平息後隊伍陪凡凡公開資料、協助病患取得救治、家族內部改革或責任調查。 | 凡凡不必拋棄對家人的愛，也不免除自身判斷失誤與家族行為的責任。 |

**敘事節奏：** 發生對立前先花足夠篇幅建立日常友情與家族愛；不要把他一開始就寫成陰沉的臥底。對立應有合理的錯誤判斷與實際後果，回歸不能靠洗腦解除或單次口頭道歉。經過事件，澄花及其他人不必立刻完全原諒他，仍可以在共同救助中慢慢修復信任。

## 4. 必須讓主角團每人有不可取代的工作

- **凡凡**：完成致病術式結構與有效共鳴的解析，制定逆向解除和恢復方法；承認過去錯誤、主動公開可驗證數據並持續協助救治。
- **橘澄花**：患者評估、治療、恢復期追蹤與知情同意的代表；她不是凡凡的附屬醫療道具，也不能被取消原本《無法治癒的一切》的主線。
- **雨宮律**：保護撤離與承受危險，展現可以在朋友立場不同時堅定維護底線，但不靠劍術處理一切。
- **星煌露比**：以控制和臨場應變支援撤離及反制窗口；守護朋友而不提早暴露其身分秘密。
- **受試者與家族中的反對派**：保有選擇、發聲、參與療程改革的主體性；並非用來襯托主角強大的無名怪物。

## 5. 角色對話氛圍（PROPOSED／非定稿台詞）

> 研究室前，凡凡握著法杖：「我不明白……你們也知道，沒有完整解除程序就讓療程中斷，可能會害死他們。請不要進去。」

> 數據被隱瞞的證據出現時，他低聲說：「原來如此。不是沒有答案……是有人決定，不讓那些人知道問題。」

> 面對家族領導者的「他們終有一天會理解」時，凡凡回答：「那麼，他們自己願意嗎？我不明白。若我們的理想是理解他人，為何不肯聽他們說話？」

> 第一名恢復者詢問自己能否回家，凡凡停頓：「考倒我了。我無法保證以後沒有難題……但我會和大家一起，把剩下的事做好。」

> 善後時主角團沒有只說「我們原諒你」，而是陪他做艱難的實際工作：照護、重建紀錄、面對被害者與必要的制度調查。
